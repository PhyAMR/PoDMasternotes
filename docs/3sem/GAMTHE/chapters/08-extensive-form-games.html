8  Extensive-form games

In many interactions some players move first and others react. The bi-matrix hides this time structure, so we need a richer representation: the extensive form, a game tree annotated with who moves where and what they know. This chapter introduces the tree, information sets, the redefinition of strategy as a complete contingent plan, behavioural strategies, and the correspondence between extensive and normal forms.

8.1 Dynamic games

A dynamic game has players moving at different times. Complete information is kept — payoffs are common knowledge — but a new distinction appears:

  • perfect information: every player, when moving, knows everything that happened before;
  • imperfect information: some moves are effectively simultaneous, or Nature moves and its choice is not observed.

The sequential Battle of the Sexes. In the static version Ann and Brian choose without knowing each other’s choice — not very realistic. Suppose instead Ann picks the movie first and phones Brian. Being fully informed, Ann knows that whatever she picks, Brian’s best response is to follow; since she prefers R, she picks R. There is no coordination problem any more. To represent this we need to connect each choice to the knowledge available when it is made — Brian’s call might not go through, for example.

8.2 The game tree

An extensive-form game specifies:

  1. the set of players;
  2. their payoff functions over terminal outcomes;
  3. the order of moves;
  4. the actions available to each player when it is their turn;
  5. the information each player has when moving;
  6. the probability distributions of Nature’s moves;
  7. the common knowledge of all the above.

Items 1–2 are shared with the normal form, 3–5 add the time dimension, 6–7 express complete information. Graphically: decision nodes are labelled by the player who moves, branches by actions, and terminal nodes by payoff vectors.

Figure: the Battle of the Sexes in extensive form. Payoffs are (Ann, Brian). Left: Brian observes Ann’s choice. Right: the dashed line joins nodes Brian cannot distinguish — one information set.

Dummy players. Players with a single available action (or who never move) can be omitted from the tree; they still appear in the payoff vectors.

8.3 Information sets

Label nodes \(x_0\) (the root), \(x_1, x_2, \dots\); each node is either terminal (carrying payoffs) or the parent of other nodes. In the sequential Battle of the Sexes, Brian moves at \(x_1\) (after \(R\)) or \(x_2\) (after \(S\)) with the same actions but different consequences — and he knows which node he is at.

Each player \(i\) has a collection \(H_i\) of information sets. The information set \(h_i(x) \in H_i\) associated with a node \(x\) where \(i\) moves contains all nodes that \(i\) cannot distinguish from \(x\); by convention \(x \in h_i(x)\). If \(h_i(x) = \{x\}\) is a singleton, \(i\) knows exactly where they are. All nodes in the same information set must have the same set of available actions: \(x' \in h_i(x) \Rightarrow A(x') = A(x)\).

In the simultaneous Battle of the Sexes, Brian’s information set is \(\{x_1, x_2\}\): he does not know Ann’s choice. Graphically, nodes in the same set are joined by a dashed line (or enclosed in an oval).

Remark (Equalising action sets). If two indistinguishable nodes seem to offer different actions, add “forbidden” actions with payoff \(-M\), where \(M\) is huge (formally \(-\infty\), or below the minimum payoff). The game changes, but every strategy using the forbidden action becomes strictly dominated, so nothing of substance is altered.

A dynamic game has perfect information if all information sets are singletons and Nature never moves. Otherwise it has imperfect information: either exogenous uncertainty (Nature’s moves, as in single-person problems with lotteries) or endogenous uncertainty (unobserved, effectively simultaneous moves of other players). In both cases players must form beliefs.

8.4 Strategies in dynamic games

In static games a pure strategy is an action. In dynamic games the history matters through information sets.

A pure strategy of player \(i\) specifies an action at every information set of \(i\) — including those that will not be reached given the strategy itself. It is a complete program: a countermove for every possible situation.

In the sequential Battle of the Sexes Brian has two actions but four strategies, written \((a_R, a_S)\) = (reply to \(R\), reply to \(S\)): \((s,s)\) “go to S no matter what”, \((r,r)\) “go to R no matter what”, \((r,s)\) “do what Ann does”, \((s,r)\) “avoid Ann”.

If the static Battle of the Sexes is played on two consecutive nights with the first outcome observed, a strategy is a quintuple \((a_1, a_{2}^{Rr}, a_{2}^{Rs}, a_{2}^{Sr}, a_{2}^{Ss})\): the first-night move and the second-night reply to each of the four possible first-night outcomes. For instance \((r, s, r, r, r)\) means “R on the first night; S on the second if the first outcome was \(Rr\), otherwise R”. The count explodes quickly: two sequential moves with \(|A_1| = |A_2| = 3\) already give player 2 \(3^3 = 27\) strategies. Beyond small examples strategies are described implicitly.

8.5 Mixed and behavioural strategies

A mixed strategy is still a probability distribution over the (now large) set of pure strategies: the randomisation happens once, at the start, and the player then sticks to the drawn plan. Alternatively, a player can randomise as the game unfolds.

A behavioural strategy of player \(i\) specifies, for each information set \(h_i \in H_i\), an independent probability distribution \(\sigma_i(\cdot \mid h_i)\) over the actions \(A_i(h_i)\) available there.

Think of a strategy as a handbook of instructions. A mixed strategy picks one of several handbooks at random; a behavioural strategy is a single handbook whose every page gives a random instruction. In the sequential Battle of the Sexes, a mixed strategy of Brian assigns \(p_{rr}, p_{rs}, p_{sr}, p_{ss}\); the equivalent behavioural strategy has \[\sigma_B(r \mid x_1) = p_{rr} + p_{rs}, \qquad \sigma_B(r \mid x_2) = p_{rr} + p_{sr}.\]

In a finite game with perfect recall — no player ever forgets information they previously knew, including their own past actions — every mixed strategy has an outcome-equivalent behavioural strategy and vice versa.

Perfect recall holds in virtually every game of interest. When it fails, the two notions can differ.

Andrew drives home on a highway at night. Exiting at the first junction leads into a bad neighbourhood (payoff \(0\)); exiting at the second takes him home (payoff \(4\)); missing both leads to a long detour (payoff \(1\)). Andrew is tired and cannot tell the two junctions apart: his single information set is \(\{x_0, x_1\}\), so the same action must be chosen at both.

  • Pure and mixed strategies. “Exit” gives \(0\), “continue” gives \(1\); any mixture yields at most \(1\).
  • Behavioural strategy. Exit with probability \(p\) at each junction, independently: \[\mathbb E[u] = p \cdot 0 + (1-p)p \cdot 4 + (1-p)^2 \cdot 1 = -3p^2 + 2p + 1,\] maximised at \(p^* = \tfrac13\) with \(\mathbb E[u] = \tfrac43 > 1\).

Randomising at each node beats every mixture over plans. A further paradox appears at the action stage: if Andrew believes he is at the first junction with probability \(q\), the expected payoff becomes \(-3qp^2 - qp + 3p + 1\), whose maximiser equals the planning-stage \(p^* = \tfrac13\) only when \(q = 1\).

8.6 From extensive to normal form

Enumerating strategies turns any extensive-form game into a normal-form one. For the sequential Battle of the Sexes:

Ann \ Brian rr rs sr ss
R 2, 1 2, 1 0, 0 0, 0
S 0, 0 1, 2 0, 0 1, 2

The simultaneous version gives back the familiar \(2 \times 2\) matrix. The correspondence is many-to-one: different trees can share a normal form, for instance when some terminal nodes carry identical payoffs, so that the order of moves does not matter.

Going back to the normal form seems to throw away the dynamics. Yet it is exactly what is needed for an inherently static concept like Nash equilibrium, which is the subject of the next chapter — together with the reason why it is not enough.

8.7 How large is the normal form?

A pure strategy specifies an action at every information set of the player, reached or not. If player \(i\) has information sets \(h_1, \dots, h_K\) with \(|A(h_k)|\) actions each, then \[|S_i| = \prod_{k=1}^K |A(h_k)|,\] which explodes with the depth of the tree. In a game where player 2 answers each of player 1’s three moves with \(S\) or \(N\), player 2 has \(2^3 = 8\) strategies, even though only one answer is ever used.

Two simplifications are standard:

  • Reduced normal form. Strategies that differ only at information sets made unreachable by the player’s own earlier moves are payoff-equivalent and can be merged. A player who ends the game at the root need not say what they would do later. Many textbooks still list them, because subgame perfection does care about those plans.
  • Simultaneous moves inside a tree. Moves made without observing each other are drawn in any order, with the later mover’s nodes joined in one information set. The choice of who is drawn first is cosmetic.

The normal form is the right tool for finding all Nash equilibria, including those supported by unreasonable plans off the path of play. The extensive form is the right tool for discarding them (Chapter 9).

8.8 Exercises

Problems from Badia and Marchioro (BM), Chapters 3 and 4. Their subgame-perfect equilibria are found in Chapter 9.

(BM 3.1) A student U chooses project quality \(x \in \{0, 1, 2\}\); the professor P then accepts (S) or rejects (N). If accepted, each gets \(m - e_j\) with mark \(m = 18 + 6x\), \(e_U = 4^x\) and \(e_P = 15\); a rejection gives \(0\) to both. Draw the tree, write the normal form and find all pure NE.

Solution. Accepted payoffs (U, P): \(x = 0\): \((17, 3)\); \(x = 1\): \((20, 9)\); \(x = 2\): \((14, 15)\). P has one information set per \(x\), hence \(2^3 = 8\) strategies (an answer to \(0\), \(1\) and \(2\)). The normal form is \(3 \times 8\); marking best responses gives 7 pure NE: \((0, SNS)\), \((0, SNN)\), \((1, SSS)\), \((1, SSN)\), \((1, NSS)\), \((1, NSN)\), \((2, NNS)\). Several rely on P rejecting projects that are never submitted. \((2, NNS)\), for instance, is the “strict professor” who accepts only top quality.

(BM 3.2) Miss 1 and Mister 2 start with \(u_1 = 1\), \(u_2 = -1\). Miss 1 plays A (multiply both by \(3\)) or B (multiply both by \(2\), then add \(5\) to \(u_2\)). Mister 2 observes and either Drops (D, game ends) or Continues (C), after which Miss 1 plays A or B once more. Draw the tree and count the pure strategies.

Solution. After A: \((3, -3)\); after B: \((2, 3)\). Continuing from \((3, -3)\) leads to \((9, -9)\) by A or \((6, -1)\) by B; continuing from \((2, 3)\) leads to \((6, 9)\) by A or \((4, 11)\) by B. Miss 1 moves at three nodes (the root and the two continuation nodes): \(2^3 = 8\) strategies. Mister 2 moves at two: \(2^2 = 4\) strategies. In reduced normal form, Miss 1’s plans at the continuation node after the move she did not make can be merged, leaving \(2 \times 2 = 4\) classes.

(BM 3.4) Javier and Krista buy a house. In September J buys Atlas (\(A\): J \(10\), K \(5\)) or waits (\(X\)). In October K buys Bellevue (\(B\): \(15\), \(28\)) or Cicada (\(C\): \(5\), \(12\)), or waits (\(X\)). In November J must buy Daffodil (\(D\): \(18\), \(15\)), Ember (\(E\): \(8\), \(35\)) or Floral (\(F\): \(40\), \(10\)). Write the normal form and find all pure NE.

Solution. J has \(2 \times 3 = 6\) strategies (AD, AE, AF, XD, XE, XF) and K has \(3\) (B, C, X). Rows AD, AE, AF give \((10, 5)\) in every column. Against B, C, X: XD gives \((15, 28)\), \((5, 12)\), \((18, 15)\); XE gives \((15, 28)\), \((5, 12)\), \((8, 35)\); XF gives \((15, 28)\), \((5, 12)\), \((40, 10)\). The pure NE are \((AD, C)\), \((AE, C)\), \((AF, C)\), \((XD, B)\) and \((XF, B)\). In the first three Krista’s choice of \(C\) is a (non-credible) threat that makes waiting unattractive to J.

(BM 4.6) The Count chooses Sword or Pistol; then the Duke chooses First blood or Last blood. With swords the Count wins with \(0.4\). With pistols the Count wins with \(0.7\), the Duke with \(0.2\), and both are shot with \(0.1\). At first blood the loser survives dishonoured (\(-20\)); at last blood the loser dies (\(-100\)); being shot is \(-100\); winning is \(+10\). Compute the expected payoffs, the normal form and the NE.

Solution. Expected payoffs (Count, Duke): \(SF\) \((-8, -2)\), \(SL\) \((-56, -34)\), \(PF\) \((-7, -22)\), \(PL\) \((-23, -78)\). For instance, \(PF\) gives the Duke \(0.2\cdot10 + 0.7(-20) + 0.1(-100) = -22\). (The printed solution has slightly different Duke payoffs; the conclusions are the same.) The Duke’s strategies say what to answer to S and to P: FF, FL, LF, LL. The pure NE are \((S, FL)\), \((P, FF)\) and \((P, LF)\). \((S, FL)\) rests on the Duke threatening last blood if pistols are chosen.

(BM 4.7) David picks a cake A, B or C; Emily, seeing it, shops at the Farmer’s market (F) or Grocery (G). The cake succeeds with probability \(p_{AF} = 0.5\), \(p_{AG} = 0.2\), \(p_{BF} = 0.8\), \(p_{BG} = 0.4\), \(p_{CF} = 0.7\), \(p_{CG} = 0.9\). Emily gets \(1\) for a success; David gets \(3\), \(2\), \(1\) times that for A, B, C. Write the “flat” simultaneous version and the true sequential normal form, and compare.

Solution. Flat: \((A, F) = (1.5, 0.5)\), \((A, G) = (0.6, 0.2)\), \((B, F) = (1.6, 0.8)\), \((B, G) = (0.8, 0.4)\), \((C, F) = (0.7, 0.7)\), \((C, G) = (0.9, 0.9)\). \(A\) is strictly dominated by \(B\); the flat game has NE \((B, F)\) and \((C, G)\). Sequentially, Emily’s strategies are pairs (answer to B, answer to C), ignoring A: the NE are \((B, FF)\), \((B, FG)\) and \((C, GG)\). The extra NE of the sequential form are again sustained by off-path plans.

From the course material:

Two players start with two peas each and alternate, A first. A move transfers to the opponent a positive number of peas never transferred before by anyone. A player who cannot move loses. Draw the tree and determine the winner.

Solution. Write states as (peas of A, peas of B; amounts used). A can open with 1 or 2.

  • A gives 2 → \((0, 4; \{2\})\). B replies by giving 1 → \((1, 3; \{1,2\})\): A’s only amount is 1, already used, so A loses.
  • A gives 1 → \((1, 3; \{1\})\). B replies by giving 2 → \((3, 1; \{1,2\})\): A’s only new feasible amount is 3 → \((0, 4; \{1,2,3\})\); B gives 4 → \((4, 0; \{1,2,3,4\})\), and A cannot give a new amount ≤ 4, so A loses. (B must avoid giving 3 instead, which would let A win by giving 2.)

Every opening loses against correct play: B wins. This is backward induction on a game of perfect information (Chapter 9).

In the sequential Battle of the Sexes, write Brian’s behavioural strategy equivalent to the mixed strategy \(p_{rr} = 0.1\), \(p_{rs} = 0.5\), \(p_{sr} = 0.2\), \(p_{ss} = 0.2\).

Solution. \(\sigma_B(r \mid x_1) = p_{rr} + p_{rs} = 0.6\) and \(\sigma_B(r \mid x_2) = p_{rr} + p_{sr} = 0.3\). (Many mixed strategies map to the same behavioural strategy: only these two marginals matter for outcomes.)

## Information sets

Label nodes $x_0$ (the root), $x_1, x_2, \dots$; each node is either terminal (carrying payoffs) or the parent of other nodes. In the sequential Battle of the Sexes, Brian moves at $x_1$ (after $R$) or $x_2$ (after $S$) with the same actions but different consequences — and he *knows* which node he is at.

::: {.definition name="Information set"}

If $h_i(x) = \{x\}$ is a singleton, $i$ knows exactly where they are. All nodes in the same information set must have the same set of available actions: $x' \in h_i(x) \Rightarrow A(x') = A(x)$.
:::

In the simultaneous Battle of the Sexes, Brian's information set is $\{x_1, x_2\}$: he does not know Ann's choice. Graphically, nodes in the same set are joined by a dashed line (or enclosed in an oval).

::: {.remark name="Equalising action sets"}

The game changes, but every strategy using the forbidden action becomes strictly dominated, so nothing of substance is altered.
:::

A dynamic game has **perfect information** if all information sets are singletons and Nature never moves. Otherwise it has **imperfect information**: either *exogenous* uncertainty (Nature's moves, as in single-person problems with lotteries) or *endogenous* uncertainty (unobserved, effectively simultaneous moves of other players). In both cases players must form beliefs.
:::

## Strategies in dynamic games

In static games a pure strategy is an action. In dynamic games the history matters through information sets.

::: {.definition name="Pure strategy (extensive form)"}
A pure strategy of player $i$ specifies an action at **every** information set of $i$ — including those that will not be reached given the strategy itself. It is a complete program: a countermove for every possible situation.
:::

In the sequential Battle of the Sexes Brian has two actions but **four** strategies, written $(a_R, a_S)$ = (reply to $R$, reply to $S$): $(s,s)$ "go to S no matter what", $(r,r)$ "go to R no matter what", $(r,s)$ "do what Ann does", $(s,r)$ "avoid Ann".

If the static Battle of the Sexes is played on two consecutive nights with the first outcome observed, a strategy is a quintuple $(a_1, a_{2}^{Rr}, a_{2}^{Rs}, a_{2}^{Sr}, a_{2}^{Ss})$: the first-night move and the second-night reply to each of the four possible first-night outcomes. For instance $(r, s, r, r, r)$ means "R on the first night; S on the second if the first outcome was $Rr$, otherwise R". The count explodes quickly: two sequential moves with $|A_1| = |A_2| = 3$ already give player 2 $3^3 = 27$ strategies. Beyond small examples strategies are described implicitly.

## Mixed and behavioural strategies

A **mixed strategy** is still a probability distribution over the (now large) set of pure strategies: the randomisation happens once, at the start, and the player then sticks to the drawn plan. Alternatively, a player can randomise *as the game unfolds*.

::: {.definition name="Behavioural strategy"}
A **behavioural strategy** of player $i$ specifies, for each information set $h_i \in H_i$, an independent probability distribution $\sigma_i(\cdot \mid h_i)$ over the actions $A_i(h_i)$ available there.
:::

Think of a strategy as a handbook of instructions. A mixed strategy picks one of several handbooks at random; a behavioural strategy is a single handbook whose every page gives a random instruction. In the sequential Battle of the Sexes, a mixed strategy of Brian assigns $p_{rr}, p_{rs}, p_{sr}, p_{ss}$; the equivalent behavioural strategy has
$$\sigma_B(r \mid x_1) = p_{rr} + p_{rs}, \qquad \sigma_B(r \mid x_2) = p_{rr} + p_{sr}.$$

::: {.theorem name="Kuhn, 1953"}
In a finite game with **perfect recall** — no player ever forgets information they previously knew, including their own past actions — every mixed strategy has an outcome-equivalent behavioural strategy and vice versa.
:::

Perfect recall holds in virtually every game of interest. When it fails, the two notions can differ.

::: {.example name="The absent-minded driver"}
Andrew drives home on a highway at night. Exiting at the first junction leads into a bad neighbourhood (payoff $0$); exiting at the second takes him home (payoff $4$); missing both leads to a long detour (payoff $1$). Andrew is tired and cannot tell the two junctions apart: his single information set is $\{x_0, x_1\}$, so the same action must be chosen at both.

- **Pure and mixed strategies.** "Exit" gives $0$, "continue" gives $1$; any mixture yields at most $1$.
- **Behavioural strategy.** Exit with probability $p$ at each junction, independently:
$$\mathbb E[u] = p \cdot 0 + (1-p)p \cdot 4 + (1-p)^2 \cdot 1 = -3p^2 + 2p + 1,$$
maximised at $p^* = \tfrac13$ with $\mathbb E[u] = \tfrac43 > 1$.

Randomising at each node beats every mixture over plans. A further paradox appears at the *action stage*: if Andrew believes he is at the first junction with probability $q$, the expected payoff becomes $-3qp^2 - qp + 3p + 1$, whose maximiser equals the planning-stage $p^* = \tfrac13$ only when $q = 1$.
:::

## From extensive to normal form

Enumerating strategies turns any extensive-form game into a normal-form one. For the sequential Battle of the Sexes:

| Ann \\ Brian | rr | rs | sr | ss |
|:--:|:--:|:--:|:--:|:--:|
| **R** | 2, 1 | 2, 1 | 0, 0 | 0, 0 |
| **S** | 0, 0 | 1, 2 | 0, 0 | 1, 2 |

The simultaneous version gives back the familiar $2 \times 2$ matrix. The correspondence is many-to-one: different trees can share a normal form, for instance when some terminal nodes carry identical payoffs, so that the order of moves does not matter.

::: {.callout-note}
Going back to the normal form seems to throw away the dynamics. Yet it is exactly what is needed for an inherently static concept like Nash equilibrium, which is the subject of the next chapter — together with the reason why it is not enough.
:::

## How large is the normal form?

A pure strategy specifies an action at **every** information set of the player, reached or not. If player $i$ has information sets $h_1, \dots, h_K$ with $|A(h_k)|$ actions each, then
$$|S_i| = \prod_{k=1}^K |A(h_k)|,$$
which explodes with the depth of the tree. In a game where player 2 answers each of player 1's three moves with $S$ or $N$, player 2 has $2^3 = 8$ strategies, even though only one answer is ever used.

Two simplifications are standard:

- **Reduced normal form.** Strategies that differ only at information sets made unreachable by the player's *own* earlier moves are payoff-equivalent and can be merged. A player who ends the game at the root need not say what they would do later. Many textbooks still list them, because subgame perfection *does* care about those plans.
- **Simultaneous moves inside a tree.** Moves made without observing each other are drawn in any order, with the later mover's nodes joined in one information set. The choice of who is drawn first is cosmetic.

The normal form is the right tool for finding *all* Nash equilibria, including those supported by unreasonable plans off the path of play. The extensive form is the right tool for discarding them (Chapter 9).

## Exercises

Problems from Badia and Marchioro (BM), Chapters 3 and 4. Their subgame-perfect equilibria are found in Chapter 9.

::: {.exercise}
**(BM 3.1)** A student U chooses project quality $x \in \{0, 1, 2\}$; the professor P then accepts (S) or rejects (N). If accepted, each gets $m - e_j$ with mark $m = 18 + 6x$, $e_U = 4^x$ and $e_P = 15$; a rejection gives $0$ to both. Draw the tree, write the normal form and find all pure NE.
:::

::: {.solution}
Accepted payoffs (U, P): $x = 0$: $(17, 3)$; $x = 1$: $(20, 9)$; $x = 2$: $(14, 15)$. P has one information set per $x$, hence $2^3 = 8$ strategies (an answer to $0$, $1$ and $2$). The normal form is $3 \times 8$; marking best responses gives **7 pure NE**: $(0, SNS)$, $(0, SNN)$, $(1, SSS)$, $(1, SSN)$, $(1, NSS)$, $(1, NSN)$, $(2, NNS)$. Several rely on P rejecting projects that are never submitted. $(2, NNS)$, for instance, is the "strict professor" who accepts only top quality.
:::

::: {.exercise}
**(BM 3.2)** Miss 1 and Mister 2 start with $u_1 = 1$, $u_2 = -1$. Miss 1 plays A (multiply both by $3$) or B (multiply both by $2$, then add $5$ to $u_2$). Mister 2 observes and either Drops (D, game ends) or Continues (C), after which Miss 1 plays A or B once more. Draw the tree and count the pure strategies.
:::

::: {.solution}
After A: $(3, -3)$; after B: $(2, 3)$. Continuing from $(3, -3)$ leads to $(9, -9)$ by A or $(6, -1)$ by B; continuing from $(2, 3)$ leads to $(6, 9)$ by A or $(4, 11)$ by B. Miss 1 moves at three nodes (the root and the two continuation nodes): $2^3 = 8$ strategies. Mister 2 moves at two: $2^2 = 4$ strategies. In reduced normal form, Miss 1's plans at the continuation node after the move she did not make can be merged, leaving $2 \times 2 = 4$ classes.
:::

::: {.exercise}
**(BM 3.4)** Javier and Krista buy a house. In September J buys Atlas ($A$: J $10$, K $5$) or waits ($X$). In October K buys Bellevue ($B$: $15$, $28$) or Cicada ($C$: $5$, $12$), or waits ($X$). In November J must buy Daffodil ($D$: $18$, $15$), Ember ($E$: $8$, $35$) or Floral ($F$: $40$, $10$). Write the normal form and find all pure NE.
:::

::: {.solution}
J has $2 \times 3 = 6$ strategies (AD, AE, AF, XD, XE, XF) and K has $3$ (B, C, X). Rows AD, AE, AF give $(10, 5)$ in every column. Against B, C, X: XD gives $(15, 28)$, $(5, 12)$, $(18, 15)$; XE gives $(15, 28)$, $(5, 12)$, $(8, 35)$; XF gives $(15, 28)$, $(5, 12)$, $(40, 10)$. The pure NE are $(AD, C)$, $(AE, C)$, $(AF, C)$, $(XD, B)$ and $(XF, B)$. In the first three Krista's choice of $C$ is a (non-credible) threat that makes waiting unattractive to J.
:::

::: {.exercise}
**(BM 4.6)** The Count chooses Sword or Pistol; then the Duke chooses First blood or Last blood. With swords the Count wins with $0.4$. With pistols the Count wins with $0.7$, the Duke with $0.2$, and both are shot with $0.1$. At first blood the loser survives dishonoured ($-20$); at last blood the loser dies ($-100$); being shot is $-100$; winning is $+10$. Compute the expected payoffs, the normal form and the NE.
:::

::: {.solution}
Expected payoffs (Count, Duke): $SF$ $(-8, -2)$, $SL$ $(-56, -34)$, $PF$ $(-7, -22)$, $PL$ $(-23, -78)$. For instance, $PF$ gives the Duke $0.2\cdot10 + 0.7(-20) + 0.1(-100) = -22$. (The printed solution has slightly different Duke payoffs; the conclusions are the same.) The Duke's strategies say what to answer to S and to P: FF, FL, LF, LL. The pure NE are $(S, FL)$, $(P, FF)$ and $(P, LF)$. $(S, FL)$ rests on the Duke threatening last blood if pistols are chosen.
:::

::: {.exercise}
**(BM 4.7)** David picks a cake A, B or C; Emily, seeing it, shops at the Farmer's market (F) or Grocery (G). The cake succeeds with probability $p_{AF} = 0.5$, $p_{AG} = 0.2$, $p_{BF} = 0.8$, $p_{BG} = 0.4$, $p_{CF} = 0.7$, $p_{CG} = 0.9$. Emily gets $1$ for a success; David gets $3$, $2$, $1$ times that for A, B, C. Write the "flat" simultaneous version and the true sequential normal form, and compare.
:::

::: {.solution}
Flat: $(A, F) = (1.5, 0.5)$, $(A, G) = (0.6, 0.2)$, $(B, F) = (1.6, 0.8)$, $(B, G) = (0.8, 0.4)$, $(C, F) = (0.7, 0.7)$, $(C, G) = (0.9, 0.9)$. $A$ is strictly dominated by $B$; the flat game has NE $(B, F)$ and $(C, G)$. Sequentially, Emily's strategies are pairs (answer to B, answer to C), ignoring A: the NE are $(B, FF)$, $(B, FG)$ and $(C, GG)$. The extra NE of the sequential form are again sustained by off-path plans.
:::

From the course material:

::: {.exercise}
Two players start with two peas each and alternate, A first. A move transfers to the opponent a positive number of peas never transferred before by anyone. A player who cannot move loses. Draw the tree and determine the winner.
:::

::: {.solution}
Write states as (peas of A, peas of B; amounts used). A can open with 1 or 2.

- **A gives 2** → $(0, 4; \{2\})$. B replies by giving 1 → $(1, 3; \{1,2\})$: A's only amount is 1, already used, so A loses.
- **A gives 1** → $(1, 3; \{1\})$. B replies by giving 2 → $(3, 1; \{1,2\})$: A's only new feasible amount is 3 → $(0, 4; \{1,2,3\})$; B gives 4 → $(4, 0; \{1,2,3,4\})$, and A cannot give a new amount ≤ 4, so A loses. (B must avoid giving 3 instead, which would let A win by giving 2.)

Every opening loses against correct play: **B wins**. This is backward induction on a game of perfect information (Chapter 9).
:::

::: {.exercise}
In the sequential Battle of the Sexes, write Brian's behavioural strategy equivalent to the mixed strategy $p_{rr} = 0.1$, $p_{rs} = 0.5$, $p_{sr} = 0.2$, $p_{ss} = 0.2$.
:::

::: {.solution}
$\sigma_B(r \mid x_1) = p_{rr} + p_{rs} = 0.6$ and $\sigma_B(r \mid x_2) = p_{rr} + p_{sr} = 0.3$. (Many mixed strategies map to the same behavioural strategy: only these two marginals matter for outcomes.)
:::
