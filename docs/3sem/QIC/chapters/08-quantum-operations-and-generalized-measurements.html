8  Quantum operations and generalized measurements

The postulates of Chapter 4 describe isolated systems. Real qubits interact with an environment: they decohere, lose energy, get entangled with ancillas. The same mathematics describes a system that is only part of a larger system evolving unitarily. This chapter derives the Kraus representation of the most general physical evolution (a quantum channel, or superoperator), characterises it axiomatically, and does the same for measurements: generalized measurements and POVMs, which can outperform projective measurements, for example in distinguishing non-orthogonal states.

8.1 From unitaries on a larger system to superoperators

Let the system \(A\) start in \(\ket\psi_A\) and an environment (or ancilla) \(B\) in a fixed state \(\ket 0_B\), and let them interact through a unitary \(\hat U_{AB}\). Expanding the output in a basis \(\{\ket k_B\}\) of \(B\), \[\ket\Phi_{AB} = \hat U_{AB}\ket\psi_A\ket 0_B = \sum_{k=0}^{d_B-1}\bigl(\hat E_k\ket\psi_A\bigr)\ket k_B, \qquad \hat E_k = {}_B\!\braket{k|\hat U_{AB}|0}_B .\] The state of \(A\) alone is \[\hat\rho_A' = \mathrm{Tr}_B\bigl[\ket\Phi_{AB}\bra\Phi\bigr] = \sum_k\hat E_k\,\hat\rho_A\,\hat E_k^\dagger, \qquad \sum_k\hat E_k^\dagger\hat E_k = \hat{\mathbb 1}_A,\] where the normalisation follows from unitarity: \(\sum_k\hat E_k^\dagger\hat E_k = \braket{0|\hat U^\dagger\hat U|0}_B = \hat{\mathbb 1}\). By linearity the formula holds for mixed \(\hat\rho_A\) too. The operators \(\hat E_k\) are the Kraus operators.

Figure: system and ancilla interact unitarily. Ignoring the ancilla gives a quantum channel on \(A\); measuring it gives a generalized measurement.

8.2 Superoperators

A superoperator is a map \(\chi : \hat\rho \mapsto \hat\rho' = \chi(\hat\rho)\) on density operators that is

  1. linear: \(\chi(p_1\hat\rho_1 + p_2\hat\rho_2) = p_1\chi(\hat\rho_1) + p_2\chi(\hat\rho_2)\) (it respects mixtures);
  2. Hermiticity preserving: \(\chi(\hat\rho)^\dagger = \chi(\hat\rho)\);
  3. trace preserving: \(\mathrm{Tr}\,\chi(\hat\rho) = 1\);
  4. completely positive: \(\hat{\mathbb 1}_R\otimes\chi\) maps positive operators to positive operators for every reference system \(R\).

Complete positivity is stronger than positivity, and physically necessary: the system may be entangled with a distant partner \(R\) untouched by the evolution, and the joint state must remain a state. The transpose is positive but not completely positive — applied to half of \(\ket{\Phi^+}\) it produces an operator with a negative eigenvalue (the partial transpose of Chapter 7). It is not a physical evolution.

A map \(\chi\) satisfies 1–4 if and only if it can be written as \[\chi(\hat\rho) = \sum_k\hat E_k\,\hat\rho\,\hat E_k^\dagger, \qquad \sum_k\hat E_k^\dagger\hat E_k = \hat{\mathbb 1},\] with at most \(d^2\) Kraus operators. Every such map arises from a unitary on the system plus an ancilla (Stinespring dilation).

The Kraus operators are not unique: \(\{\hat E_k\}\) and \(\{\hat F_j = \sum_k u_{jk}\hat E_k\}\), with \(u\) unitary, describe the same channel — a different basis for the environment. A unitary evolution is the special case of a single Kraus operator.

With probability \(1 - p\) the qubit is untouched; with probability \(p\) it is replaced by the maximally mixed state: \[\chi(\hat\rho) = (1 - p)\hat\rho + p\,\frac{\hat{\mathbb 1}}{2} = \Bigl(1 - \frac{3p}{4}\Bigr)\hat\rho + \frac p4\bigl(\hat\sigma_x\hat\rho\hat\sigma_x + \hat\sigma_y\hat\rho\hat\sigma_y + \hat\sigma_z\hat\rho\hat\sigma_z\bigr),\] using \(\tfrac{\hat{\mathbb 1}}{2} = \tfrac14(\hat\rho + \sum_j\hat\sigma_j\hat\rho\hat\sigma_j)\). Kraus operators: \(\sqrt{1 - 3p/4}\,\hat{\mathbb 1}\) and \(\tfrac{\sqrt p}{2}\hat\sigma_j\). On the Bloch ball, \(\vec r \mapsto (1-p)\vec r\): a uniform contraction towards the centre.

Other standard qubit channels: dephasing (\(\hat E_0 = \sqrt{1-p}\,\hat{\mathbb 1}\), \(\hat E_1 = \sqrt p\,\hat\sigma_z\); shrinks \(r_x, r_y\), keeps \(r_z\) — loss of coherence, \(T_2\)) and amplitude damping (\(\hat E_0 = \ket 0\bra 0 + \sqrt{1-\gamma}\ket 1\bra 1\), \(\hat E_1 = \sqrt\gamma\ket 0\bra 1\); relaxation of \(\ket 1\) to \(\ket 0\), \(T_1\)).

8.3 Generalized measurements

Measuring the ancilla instead of discarding it turns the same construction into a measurement on \(A\). If after \(\hat U_{AB}\ket\psi_A\ket 0_B = \sum_k\hat M_k\ket\psi_A\ket k_B\) we measure \(B\) with the projectors \(\hat P_k = \hat{\mathbb 1}_A\otimes\ket k\bra k_B\), outcome \(k\) occurs with probability \[p_k = \braket{\psi|\hat M_k^\dagger\hat M_k|\psi},\] and \(A\) is left in \(\hat M_k\ket\psi/\sqrt{p_k}\).

A generalized measurement is a set of operators \(\{\hat M_k\}\) (not necessarily Hermitian, not necessarily projectors) with \[\sum_k\hat M_k^\dagger\hat M_k = \hat{\mathbb 1}.\] Outcome \(k\) occurs with probability \(p_k = \mathrm{Tr}[\hat M_k^\dagger\hat M_k\hat\rho]\), and the post-measurement state is \(\hat\rho_k' = \hat M_k\hat\rho\hat M_k^\dagger/p_k\).

Projective measurements are the special case \(\hat M_k = \hat\Pi_k\). Conversely, the derivation shows that projective measurements plus unitaries are equivalent to generalized measurements, provided ancillary systems are added (Naimark’s theorem).

If only the outcome statistics matter, not the post-measurement state, a measurement is described by its POVM (positive operator-valued measure) elements \[\hat F_k = \hat M_k^\dagger\hat M_k, \qquad \hat F_k \geq 0, \qquad \sum_k\hat F_k = \hat{\mathbb 1}, \qquad p_k = \mathrm{Tr}[\hat F_k\hat\rho].\]

Any set of positive operators summing to the identity is a valid POVM (take \(\hat M_k = \sqrt{\hat F_k}\)). Unlike projectors, POVM elements need not be orthogonal, and there can be more outcomes than the dimension of the space.

A source emits \(\ket 0\) or \(\ket +\), which are not orthogonal: no measurement can identify them with certainty every time. A projective measurement always risks misidentification. The POVM \[\hat F_+ = c\,\ket 1\bra 1, \qquad \hat F_0 = c\,\ket -\bra -, \qquad \hat F_? = \hat{\mathbb 1} - \hat F_+ - \hat F_0, \qquad c = \frac{1}{1 + |\braket{0|+}|} = 2 - \sqrt 2,\] never errs: outcome “\(+\)” can only occur for \(\ket +\) (since \(\braket{1|0} = 0\)), outcome “\(0\)” only for \(\ket 0\); the price is an inconclusive outcome “?”. The success probability \(1 - |\braket{0|+}| = 1 - \tfrac{1}{\sqrt2} \approx 0.29\) is optimal (Ivanovic–Dieks–Peres). This trick underlies the B92 and SARG04 QKD protocols (Chapter 10).

8.4 Postulates for interacting systems

  1. States are density operators \(\hat\rho\).
  2. Evolution is described by superoperators, \(\chi(\hat\rho) = \sum_k\hat E_k\hat\rho\hat E_k^\dagger\) with \(\sum_k\hat E_k^\dagger\hat E_k = \hat{\mathbb 1}\).
  3. Measurements are sets \(\{\hat M_k\}\) with \(\sum_k\hat M_k^\dagger\hat M_k = \hat{\mathbb 1}\); outcome \(k\) has probability \(p_k = \mathrm{Tr}[\hat M_k^\dagger\hat M_k\hat\rho]\).
  4. Collapse: after outcome \(k\), \(\hat\rho \mapsto \hat M_k\hat\rho\hat M_k^\dagger/p_k\).

These are not new axioms: they follow from the isolated-system postulates applied to the system plus its environment.

8.5 Exercises

A qubit \(\ket\psi_A = \cos\tfrac\theta2\ket 0 + i\sin\tfrac\theta2\ket 1\) interacts with a qutrit ancilla in \(\ket 0_B\) via \(\hat U\ket 0\ket 0 = \tfrac12\ket 0(\ket 0 + \ket 2) + \tfrac{1}{\sqrt2}\ket 1\ket 2\), \(\hat U\ket 1\ket 0 = \tfrac12\ket 0(\ket 0 - \ket 2) + \tfrac{1}{\sqrt 2}\ket 1\ket 1\). (a) Find the Kraus operators. (b) The ancilla is measured in \(\{\ket 0, \ket 1, \ket 2\}\): find the outcome probabilities and the post-measurement state for outcome \(2\).

Solution.

  1. \(\hat E_k = \braket{k|\hat U|0}_B\): \(\hat E_0 = \tfrac12\ket 0(\bra 0 + \bra 1)\), \(\hat E_1 = \tfrac{1}{\sqrt2}\ket 1\bra 1\), \(\hat E_2 = \tfrac12\ket 0(\bra 0 - \bra 1) + \tfrac{1}{\sqrt2}\ket 1\bra 0\). One checks \(\sum_k\hat E_k^\dagger\hat E_k = \hat{\mathbb 1}\). (b) With \(c = \cos\tfrac\theta2\), \(s = \sin\tfrac\theta2\): \(\hat E_0\ket\psi = \tfrac12(c + is)\ket 0\), so \(p_0 = \tfrac14\); \(\hat E_1\ket\psi = \tfrac{is}{\sqrt2}\ket 1\), so \(p_1 = \tfrac{s^2}{2}\); \(\hat E_2\ket\psi = \tfrac12(c - is)\ket 0 + \tfrac{c}{\sqrt2}\ket 1\), so \(p_2 = \tfrac14 + \tfrac{c^2}{2}\). The post-measurement state for outcome 2 is \(\bigl[\tfrac12(c - is)\ket 0 + \tfrac{c}{\sqrt2}\ket 1\bigr]/\sqrt{p_2}\).

Show that the depolarizing channel contracts every Bloch vector by \(1 - p\), and that the dephasing channel maps \((r_x, r_y, r_z) \mapsto ((1-2p)r_x, (1-2p)r_y, r_z)\).

Solution. Depolarizing: \((1-p)\tfrac12(\hat{\mathbb 1} + \vec r\cdot\hat{\vec\sigma}) + p\tfrac{\hat{\mathbb 1}}2 = \tfrac12(\hat{\mathbb 1} + (1-p)\vec r\cdot\hat{\vec\sigma})\). Dephasing: \(\hat\sigma_z\hat\sigma_{x,y}\hat\sigma_z = -\hat\sigma_{x,y}\) and \(\hat\sigma_z\hat\sigma_z\hat\sigma_z = \hat\sigma_z\), so \((1-p)\hat\rho + p\hat\sigma_z\hat\rho\hat\sigma_z\) multiplies \(r_x, r_y\) by \(1 - 2p\) and leaves \(r_z\).

## Superoperators

::: {.definition name="Superoperator (quantum channel)"}
A **superoperator** is a map $\chi : \hat\rho \mapsto \hat\rho' = \chi(\hat\rho)$ on density operators that is

1. **linear:** $\chi(p_1\hat\rho_1 + p_2\hat\rho_2) = p_1\chi(\hat\rho_1) + p_2\chi(\hat\rho_2)$ (it respects mixtures);
2. **Hermiticity preserving:** $\chi(\hat\rho)^\dagger = \chi(\hat\rho)$;
3. **trace preserving:** $\mathrm{Tr}\,\chi(\hat\rho) = 1$;
4. **completely positive:** $\hat{\mathbb 1}_R\otimes\chi$ maps positive operators to positive operators for every reference system $R$.
:::

Complete positivity is stronger than positivity, and physically necessary: the system may be entangled with a distant partner $R$ untouched by the evolution, and the joint state must remain a state. The transpose is positive but not completely positive — applied to half of $\ket{\Phi^+}$ it produces an operator with a negative eigenvalue (the partial transpose of Chapter 7). It is not a physical evolution.

::: {.theorem name="Kraus representation"}
A map $\chi$ satisfies 1–4 if and only if it can be written as
$$\chi(\hat\rho) = \sum_k\hat E_k\,\hat\rho\,\hat E_k^\dagger, \qquad \sum_k\hat E_k^\dagger\hat E_k = \hat{\mathbb 1},$$
with at most $d^2$ Kraus operators. Every such map arises from a unitary on the system plus an ancilla (Stinespring dilation).
:::

The Kraus operators are not unique: $\{\hat E_k\}$ and $\{\hat F_j = \sum_k u_{jk}\hat E_k\}$, with $u$ unitary, describe the same channel — a different basis for the environment. A unitary evolution is the special case of a single Kraus operator.

::: {.example name="Depolarizing channel"}
With probability $1 - p$ the qubit is untouched; with probability $p$ it is replaced by the maximally mixed state:
$$\chi(\hat\rho) = (1 - p)\hat\rho + p\,\frac{\hat{\mathbb 1}}{2} = \Bigl(1 - \frac{3p}{4}\Bigr)\hat\rho + \frac p4\bigl(\hat\sigma_x\hat\rho\hat\sigma_x + \hat\sigma_y\hat\rho\hat\sigma_y + \hat\sigma_z\hat\rho\hat\sigma_z\bigr),$$
using $\tfrac{\hat{\mathbb 1}}{2} = \tfrac14(\hat\rho + \sum_j\hat\sigma_j\hat\rho\hat\sigma_j)$. Kraus operators: $\sqrt{1 - 3p/4}\,\hat{\mathbb 1}$ and $\tfrac{\sqrt p}{2}\hat\sigma_j$. On the Bloch ball, $\vec r \mapsto (1-p)\vec r$: a uniform contraction towards the centre.

## Generalized measurements

Measuring the ancilla instead of discarding it turns the same construction into a measurement on $A$. If after $\hat U_{AB}\ket\psi_A\ket 0_B = \sum_k\hat M_k\ket\psi_A\ket k_B$ we measure $B$ with the projectors $\hat P_k = \hat{\mathbb 1}_A\otimes\ket k\bra k_B$, outcome $k$ occurs with probability
$$p_k = \braket{\psi|\hat M_k^\dagger\hat M_k|\psi},$$
and $A$ is left in $\hat M_k\ket\psi/\sqrt{p_k}$.

::: {.definition name="Generalized measurement"}
A **generalized measurement** is a set of operators $\{\hat M_k\}$ (not necessarily Hermitian, not necessarily projectors) with
$$\sum_k\hat M_k^\dagger\hat M_k = \hat{\mathbb 1}.$$
Outcome $k$ occurs with probability $p_k = \mathrm{Tr}[\hat M_k^\dagger\hat M_k\hat\rho]$, and the post-measurement state is $\hat\rho_k' = \hat M_k\hat\rho\hat M_k^\dagger/p_k$.
:::

Projective measurements are the special case $\hat M_k = \hat\Pi_k$. Conversely, the derivation shows that **projective measurements plus unitaries are equivalent to generalized measurements, provided ancillary systems are added** (Naimark's theorem).

::: {.definition name="POVM"}
If only the outcome statistics matter, not the post-measurement state, a measurement is described by its **POVM** (positive operator-valued measure) elements
$$\hat F_k = \hat M_k^\dagger\hat M_k, \qquad \hat F_k \geq 0, \qquad \sum_k\hat F_k = \hat{\mathbb 1}, \qquad p_k = \mathrm{Tr}[\hat F_k\hat\rho].$$
:::

Any set of positive operators summing to the identity is a valid POVM (take $\hat M_k = \sqrt{\hat F_k}$). Unlike projectors, POVM elements need not be orthogonal, and there can be more outcomes than the dimension of the space.

::: {.example name="Unambiguous discrimination of non-orthogonal states"}
A source emits $\ket 0$ or $\ket +$, which are not orthogonal: no measurement can identify them with certainty every time. A projective measurement always risks misidentification. The POVM
$$\hat F_+ = c\,\ket 1\bra 1, \qquad \hat F_0 = c\,\ket -\bra -, \qquad \hat F_? = \hat{\mathbb 1} - \hat F_+ - \hat F_0, \qquad c = \frac{1}{1 + |\braket{0|+}|} = 2 - \sqrt 2,$$
never errs: outcome "$+$" can only occur for $\ket +$ (since $\braket{1|0} = 0$), outcome "$0$" only for $\ket 0$; the price is an inconclusive outcome "?". The success probability $1 - |\braket{0|+}| = 1 - \tfrac{1}{\sqrt2} \approx 0.29$ is optimal (Ivanovic–Dieks–Peres). This trick underlies the B92 and SARG04 QKD protocols (Chapter 10).
:::

## Postulates for interacting systems

1. **States** are density operators $\hat\rho$.
2. **Evolution** is described by superoperators, $\chi(\hat\rho) = \sum_k\hat E_k\hat\rho\hat E_k^\dagger$ with $\sum_k\hat E_k^\dagger\hat E_k = \hat{\mathbb 1}$.
3. **Measurements** are sets $\{\hat M_k\}$ with $\sum_k\hat M_k^\dagger\hat M_k = \hat{\mathbb 1}$; outcome $k$ has probability $p_k = \mathrm{Tr}[\hat M_k^\dagger\hat M_k\hat\rho]$.
4. **Collapse:** after outcome $k$, $\hat\rho \mapsto \hat M_k\hat\rho\hat M_k^\dagger/p_k$.

These are not new axioms: they follow from the isolated-system postulates applied to the system plus its environment.

$\hat U\ket 0\ket 0 = \tfrac12\ket 0(\ket 0 + \ket 2) + \tfrac{1}{\sqrt2}\ket 1\ket 2$, $\hat U\ket 1\ket 0 = \tfrac12\ket 0(\ket 0 - \ket 2) + \tfrac{1}{\sqrt 2}\ket 1\ket 1$.
(a) Find the Kraus operators. (b) The ancilla is measured in $\{\ket 0, \ket 1, \ket 2\}$: find the outcome probabilities and the post-measurement state for outcome $2$.

One checks $\sum_k\hat E_k^\dagger\hat E_k = \hat{\mathbb 1}$. (b) With $c = \cos\tfrac\theta2$, $s = \sin\tfrac\theta2$: $\hat E_0\ket\psi = \tfrac12(c + is)\ket 0$, so $p_0 = \tfrac14$; $\hat E_1\ket\psi = \tfrac{is}{\sqrt2}\ket 1$, so $p_1 = \tfrac{s^2}{2}$; $\hat E_2\ket\psi = \tfrac12(c - is)\ket 0 + \tfrac{c}{\sqrt2}\ket 1$, so $p_2 = \tfrac14 + \tfrac{c^2}{2}$. The post-measurement state for outcome 2 is $\bigl[\tfrac12(c - is)\ket 0 + \tfrac{c}{\sqrt2}\ket 1\bigr]/\sqrt{p_2}$.
:::

::: {.exercise}
Show that the depolarizing channel contracts every Bloch vector by $1 - p$, and that the dephasing channel maps $(r_x, r_y, r_z) \mapsto ((1-2p)r_x, (1-2p)r_y, r_z)$.
:::

::: {.solution}
Depolarizing: $(1-p)\tfrac12(\hat{\mathbb 1} + \vec r\cdot\hat{\vec\sigma}) + p\tfrac{\hat{\mathbb 1}}2 = \tfrac12(\hat{\mathbb 1} + (1-p)\vec r\cdot\hat{\vec\sigma})$. :::
