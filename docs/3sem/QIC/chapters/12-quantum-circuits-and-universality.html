12  Quantum circuits and universality

To talk about quantum computation we need a model of computation. The standard one is the circuit model: a register of qubits, a sequence of elementary gates, a final measurement. This chapter recalls the classical background — universal gate sets, complexity classes, reversible computation — then introduces quantum gates, proves that a small set of them is universal, and shows the first glimpse of quantum speed-up through quantum parallelism and the Deutsch–Jozsa algorithm.

12.1 Classical circuits and complexity

A classical computation evaluates a Boolean function \(f : \{0,1\}^n \to \{0,1\}^m\) with a circuit of elementary gates (AND, OR, NOT, XOR, FANOUT). A gate set is universal if every Boolean function can be built from it: \(\{\text{AND}, \text{OR}, \text{NOT}\}\) is universal (write \(f\) in disjunctive normal form), and so is NAND alone (with FANOUT).

The cost of a computation is measured by how the number of gates (time) or memory (space) scales with the input size \(n\):

  • P: problems solvable by a deterministic algorithm in time polynomial in \(n\) — “efficiently solvable”;
  • NP: problems whose solutions can be verified in polynomial time (factoring, satisfiability, travelling salesman decision version); whether \(\mathrm P = \mathrm{NP}\) is open;
  • BPP: solvable in polynomial time by a randomised algorithm with error probability \(\leq \tfrac13\);
  • PSPACE: solvable with polynomial memory;
  • BQP: solvable in polynomial time by a quantum computer with bounded error.

Known inclusions: \(\mathrm P \subseteq \mathrm{BPP} \subseteq \mathrm{BQP} \subseteq \mathrm{PSPACE}\). Factoring is in NP (and coNP) and in BQP (Shor, Chapter 13), but no classical polynomial algorithm is known; it is not believed to be NP-complete. Quantum computers are not expected to solve NP-complete problems efficiently.

12.2 Reversible computation

Quantum evolution is unitary, hence reversible; classical gates such as AND are not (two input bits, one output bit: information is erased). Landauer’s principle states that erasing one bit dissipates at least \(k_BT\ln 2\) of heat, so irreversibility has a physical cost.

The Toffoli (controlled-controlled-NOT) gate maps \((a, b, c) \mapsto (a, b, c \oplus ab)\). It is reversible (it is its own inverse) and universal for classical computation: with \(c = 1\) it computes NAND, with \(a = 1\), \(c = 0\) it copies \(b\) (FANOUT).

Any irreversible circuit can be made reversible with ancilla bits: \((x, 0, 0) \mapsto (x, f(x), g(x))\), where \(g(x)\) is “garbage”. Bennett’s trick removes the garbage: compute \(f\), copy the result with CNOTs onto a fresh register, and run the computation backwards. The resulting map \[(x, y) \mapsto (x, y \oplus f(x))\] is the canonical reversible form of any function, with only polynomial overhead. Its quantum version is the oracle \(\hat U_f\) below.

12.3 The quantum circuit model

A quantum computation acts on \(n\) qubits, initialised in \(\ket{0}^{\otimes n}\), applies a sequence of gates (unitaries acting on one or two qubits at a time), and ends with measurements in the computational basis. Common gates:

gate matrix / action
Pauli \(X, Y, Z\) bit flip, \(Y = iXZ\), phase flip
Hadamard \(H\) \(\tfrac{1}{\sqrt2}\begin{pmatrix}1 & 1\\1 & -1\end{pmatrix}\)
phase \(S\) \(\mathrm{diag}(1, i)\)
\(T\) (\(\pi/8\)) \(\mathrm{diag}(1, e^{i\pi/4})\)
rotation \(R_{\vec n}(\theta)\) \(e^{-i\theta\,\vec n\cdot\hat{\vec\sigma}/2}\)
CNOT \(\ket{a, b} \mapsto \ket{a, b\oplus a}\)
controlled-\(U\) \(\ket 0\bra 0\otimes\hat{\mathbb 1} + \ket 1\bra 1\otimes\hat U\)
Toffoli \(\ket{a,b,c} \mapsto \ket{a, b, c\oplus ab}\)

The CNOT creates entanglement from product states. The basic example prepares Bell states:

Figure: Hadamard followed by CNOT maps \(\ket{00}, \ket{01}, \ket{10}, \ket{11}\) to \(\ket{\Phi^+}, \ket{\Psi^+}, \ket{\Phi^-}, \ket{\Psi^-}\); run backwards, it is the Bell-state measurement of Chapter 11.

12.4 Universality

Single-qubit gates together with CNOT are universal: any unitary on \(n\) qubits can be written exactly as a product of them.

Proof sketch. (1) Any \(d\times d\) unitary is a product of at most \(d(d-1)/2\) two-level unitaries, each acting non-trivially only on two basis states (a Givens-rotation argument, like Gaussian elimination). (2) A two-level unitary on basis states \(\ket s\), \(\ket t\) is implemented by permuting the basis with CNOT/Toffoli gates along a Gray code from \(s\) to \(t\), applying a multi-controlled single-qubit gate, and undoing the permutation. (3) Multi-controlled gates reduce to Toffolis and controlled-\(U\) gates; controlled-\(U\) reduces to CNOTs and single-qubit gates via the decomposition \(U = e^{i\alpha}AXBXC\) with \(ABC = \hat{\mathbb 1}\). \(\square\)

The construction can need exponentially many gates: universality says every unitary is possible, not that it is efficient. Indeed most unitaries require exponentially many gates; quantum algorithms are the rare ones that do not.

Real hardware offers a finite set of gates. A continuum of unitaries cannot be reached exactly, but can be approximated.

The finite set \(\{H, T, \text{CNOT}\}\) (with \(S = T^2\)) is universal in the approximate sense: any unitary can be approximated to accuracy \(\varepsilon\). Moreover, by the Solovay–Kitaev theorem, a single-qubit gate needs only \(O(\log^c(1/\varepsilon))\) gates from the set, with \(c \approx 2\): approximation is cheap.

\(H\) and \(T\) generate rotations about two non-parallel axes by angles that are irrational multiples of \(\pi\), which fill the Bloch sphere densely. A circuit of \(m\) gates approximated to \(\varepsilon/m\) each has total error at most \(\varepsilon\) (errors add up linearly for unitaries).

12.5 Quantum parallelism and the first algorithm

Given a classical function \(f : \{0,1\}^n \to \{0,1\}\), define the reversible oracle \[\hat U_f\ket x\ket y = \ket x\ket{y \oplus f(x)} .\] Applied to a uniform superposition — prepared with \(n\) Hadamards, \(H^{\otimes n}\ket{0}^{\otimes n} = 2^{-n/2}\sum_x\ket x\) — it gives \[\hat U_f\,\frac{1}{2^{n/2}}\sum_x\ket x\ket 0 = \frac{1}{2^{n/2}}\sum_x\ket x\ket{f(x)}:\] all \(2^n\) values of \(f\) in a single evaluation. This quantum parallelism is not directly useful — measuring returns one random pair \((x, f(x))\) — but interference can extract global properties of \(f\).

Phase kickback. With the target in \(\ket - = (\ket 0 - \ket 1)/\sqrt2\), \[\hat U_f\ket x\ket - = (-1)^{f(x)}\ket x\ket - ,\] so the function value appears as a phase on the control register.

Promise: \(f : \{0,1\}^n \to \{0,1\}\) is either constant or balanced (equal to \(1\) on exactly half the inputs). Classically, a deterministic algorithm may need \(2^{n-1} + 1\) evaluations. Quantum:

  1. start in \(\ket{0}^{\otimes n}\ket 1\) and apply \(H^{\otimes(n+1)}\): \(2^{-n/2}\sum_x\ket x\ket -\);
  2. apply \(\hat U_f\): \(2^{-n/2}\sum_x(-1)^{f(x)}\ket x\ket -\);
  3. apply \(H^{\otimes n}\) to the first register, using \(H^{\otimes n}\ket x = 2^{-n/2}\sum_z(-1)^{x\cdot z}\ket z\); the amplitude of \(\ket{0}^{\otimes n}\) is \[\frac{1}{2^n}\sum_x(-1)^{f(x)} = \begin{cases}\pm 1 & f \text{ constant},\\ 0 & f\text{ balanced};\end{cases}\]
  4. measure: all zeros iff \(f\) is constant.

One query decides with certainty. For \(n = 1\) this is Deutsch’s algorithm (is \(f(0) = f(1)\)?). The separation disappears against randomised classical algorithms with small error, but the structure — superposition, oracle with phase kickback, interference by a Fourier-type transform — is the template of Shor’s algorithm.

12.6 Exercises

Show that CNOT \(= (\hat{\mathbb 1}\otimes H)\,\mathrm{CZ}\,(\hat{\mathbb 1}\otimes H)\), where CZ \(= \mathrm{diag}(1, 1, 1, -1)\), and that CZ is symmetric in its two qubits.

Solution. CZ applies \(Z\) to the target when the control is \(1\). Since \(HZH = X\), conjugating the target by \(H\) turns controlled-\(Z\) into controlled-\(X\). CZ is diagonal with a \(-1\) only on \(\ket{11}\), which is symmetric under exchanging the qubits: “control” and “target” are interchangeable.

Construct a circuit of CNOTs that swaps two qubits.

Solution. Three alternating CNOTs: \(\mathrm{SWAP} = \mathrm{CNOT}_{12}\,\mathrm{CNOT}_{21}\,\mathrm{CNOT}_{12}\). On basis states: \((a,b) \to (a, a\oplus b) \to (b, a\oplus b) \to (b, a)\), the XOR-swap trick.

## Quantum parallelism and the first algorithm

Given a classical function $f : \{0,1\}^n \to \{0,1\}$, define the reversible **oracle**
$$\hat U_f\ket x\ket y = \ket x\ket{y \oplus f(x)} .$$
Applied to a uniform superposition — prepared with $n$ Hadamards, $H^{\otimes n}\ket{0}^{\otimes n} = 2^{-n/2}\sum_x\ket x$ — it gives
$$\hat U_f\,\frac{1}{2^{n/2}}\sum_x\ket x\ket 0 = \frac{1}{2^{n/2}}\sum_x\ket x\ket{f(x)}:$$
all $2^n$ values of $f$ in a single evaluation. This **quantum parallelism** is not directly useful — measuring returns one random pair $(x, f(x))$ — but interference can extract *global* properties of $f$.

**Phase kickback.** With the target in $\ket - = (\ket 0 - \ket 1)/\sqrt2$,
$$\hat U_f\ket x\ket - = (-1)^{f(x)}\ket x\ket - ,$$
so the function value appears as a phase on the control register.

::: {.example name="Deutsch–Jozsa algorithm"}
Promise: $f : \{0,1\}^n \to \{0,1\}$ is either **constant** or **balanced** (equal to $1$ on exactly half the inputs). Classically, a deterministic algorithm may need $2^{n-1} + 1$ evaluations. Quantum:

1. start in $\ket{0}^{\otimes n}\ket 1$ and apply $H^{\otimes(n+1)}$: $2^{-n/2}\sum_x\ket x\ket -$;
2. apply $\hat U_f$: $2^{-n/2}\sum_x(-1)^{f(x)}\ket x\ket -$;
3. apply $H^{\otimes n}$ to the first register, using $H^{\otimes n}\ket x = 2^{-n/2}\sum_z(-1)^{x\cdot z}\ket z$; the amplitude of $\ket{0}^{\otimes n}$ is
$$\frac{1}{2^n}\sum_x(-1)^{f(x)} = \begin{cases}\pm 1 & f \text{ constant},\\ 0 & f\text{ balanced};\end{cases}$$
4. measure: all zeros iff $f$ is constant.

**One** query decides with certainty. For $n = 1$ this is Deutsch's algorithm (is $f(0) = f(1)$?). The separation disappears against randomised classical algorithms with small error, but the structure — superposition, oracle with phase kickback, interference by a Fourier-type transform — is the template of Shor's algorithm.
:::
