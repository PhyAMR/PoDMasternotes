2  Operators and observables

Chapter 1 described measurements as choices of an orthonormal basis. Physics usually phrases them differently: one measures a quantity — energy, spin along an axis, polarisation — represented by a Hermitian operator whose eigenvalues are the possible outcomes. This chapter develops the operator toolkit (matrix elements, ket-bra notation, projectors, spectral decomposition), proves the expectation-value formula, and studies the Pauli matrices, which generate all qubit observables.

2.1 Linear operators and their matrices

A linear operator \(\hat M\) on \(\mathcal H\) maps vectors to vectors, \(\hat M(a\ket\psi + b\ket\phi) = a\hat M\ket\psi + b\hat M\ket\phi\). In an orthonormal basis \(\{\ket k\}\) it is fixed by its action on basis vectors, \[\hat M\ket k = \sum_{j=0}^{d-1} M_{jk}\ket j, \qquad M_{jk} = \braket{j|\hat M|k}.\]

The matrix element follows by taking the scalar product with \(\bra j\): \(\braket{j|\hat M|k} = \sum_\ell M_{\ell k}\braket{j|\ell} = M_{jk}\). Acting on a generic state, \(\hat M\ket\psi = \sum_{j,k} M_{jk}\psi_k\ket j\): the components transform as \(\psi'_j = \sum_k M_{jk}\psi_k\), ordinary matrix–vector multiplication.

2.2 Ket-bra notation

The outer product \(\ket\phi\bra\psi\) is the operator \(\ket\chi \mapsto \ket\phi\braket{\psi|\chi}\). Any operator can be written as \[\hat M = \sum_{j,k=0}^{d-1} M_{jk}\,\ket j\bra k,\] since applying the right-hand side to \(\ket k\) returns \(\sum_j M_{jk}\ket j\). The adjoint is defined by \(\braket{\phi|\hat M^\dagger|\psi} = \braket{\psi|\hat M|\phi}^*\), i.e. \((M^\dagger)_{jk} = M_{kj}^*\), and \((\ket\phi\bra\psi)^\dagger = \ket\psi\bra\phi\).

2.3 Projectors and completeness

An operator \(\hat P\) is an (orthogonal) projector if \(\hat P^2 = \hat P\) and \(\hat P^\dagger = \hat P\). For a unit vector \(\ket u\), \(\hat P_u = \ket u\bra u\) projects onto the line spanned by \(\ket u\): \(\hat P_u\ket\psi = \braket{u|\psi}\,\ket u\).

In the real plane, projecting \(\vec v\) onto a unit vector \(\hat u\) gives \((\hat u\cdot\vec v)\hat u\) — exactly \(\ket u\braket{u|v}\). The projectors onto the vectors of an orthonormal basis sum to the identity: \[\sum_{k=0}^{d-1}\ket k\bra k = \hat{\mathbb 1} \qquad \text{(completeness relation)}.\] Inserting this “resolution of the identity” is the single most useful trick in the formalism; for instance it proves the cyclic property of the trace, \(\mathrm{Tr}[\hat A_1 \cdots \hat A_N] = \mathrm{Tr}[\hat A_N \hat A_1 \cdots \hat A_{N-1}]\), where \(\mathrm{Tr}\,\hat A = \sum_k\braket{k|\hat A|k}\).

2.4 Observables and the spectral theorem

\(\hat A\) is Hermitian (self-adjoint) if \(\hat A^\dagger = \hat A\). Physical quantities — observables — are represented by Hermitian operators.

A Hermitian operator has real eigenvalues \(a\) and an orthonormal basis of eigenvectors \(\ket a\), \(\hat A\ket a = a\ket a\), so that \[\hat A = \sum_a a\,\ket a\bra a = \sum_a a\,\hat\Pi_a,\] where, for degenerate eigenvalues, \(\hat\Pi_a\) is the projector onto the whole eigenspace.

Measuring \(\hat A\) on \(\ket\psi\) yields one of the eigenvalues \(a\), with probability \[p_a = \braket{\psi|\hat\Pi_a|\psi} = |\braket{a|\psi}|^2 \ \text{(non-degenerate case)},\] and the state collapses to \(\hat\Pi_a\ket\psi/\sqrt{p_a}\).

Measuring an observable is thus measuring in its eigenbasis and labelling each outcome with the eigenvalue. The labels matter for averages.

The mean value of the outcomes is \[\langle \hat A\rangle = \sum_a a\,p_a = \braket{\psi|\hat A|\psi}.\]

Proof. \(\braket{\psi|\hat A|\psi} = \sum_a a\braket{\psi|a}\braket{a|\psi} = \sum_a a\,|\braket{a|\psi}|^2 = \sum_a a\,p_a\). \(\square\)

The variance is \((\Delta A)^2 = \langle \hat A^2\rangle - \langle\hat A\rangle^2\); it vanishes iff \(\ket\psi\) is an eigenvector of \(\hat A\).

2.5 Pauli matrices

\[\hat\sigma_x = \begin{pmatrix} 0 & 1 \\ 1 & 0\end{pmatrix}, \qquad \hat\sigma_y = \begin{pmatrix} 0 & -i \\ i & 0\end{pmatrix}, \qquad \hat\sigma_z = \begin{pmatrix} 1 & 0 \\ 0 & -1\end{pmatrix}.\]

In ket-bra form: \(\hat\sigma_x = \ket 0\bra 1 + \ket 1\bra 0\) (bit flip), \(\hat\sigma_y = i\ket 1\bra 0 - i\ket 0\bra 1\), \(\hat\sigma_z = \ket 0\bra 0 - \ket 1\bra 1\) (phase flip).

  1. Each has eigenvalues \(\pm 1\); the eigenvectors are \(\ket\pm\) for \(\hat\sigma_x\), \(\ket{\pm i}\) for \(\hat\sigma_y\), \(\ket 0, \ket 1\) for \(\hat\sigma_z\): \(\hat\sigma_x = \ket+\bra+ - \ket-\bra-\), etc.
  2. \(\{\hat\sigma_j, \hat\sigma_k\} = \hat\sigma_j\hat\sigma_k + \hat\sigma_k\hat\sigma_j = 2\delta_{jk}\hat{\mathbb 1}\): they square to the identity and anticommute.
  3. \([\hat\sigma_j, \hat\sigma_k] = 2i\epsilon_{jk\ell}\hat\sigma_\ell\), so \(\hat\sigma_j\hat\sigma_k = \delta_{jk}\hat{\mathbb 1} + i\epsilon_{jk\ell}\hat\sigma_\ell\).
  4. \(\mathrm{Tr}\,\hat\sigma_j = 0\) and \(\mathrm{Tr}[\hat\sigma_j\hat\sigma_k] = 2\delta_{jk}\).
  5. \(\{\hat{\mathbb 1}, \hat\sigma_x, \hat\sigma_y, \hat\sigma_z\}\) is a basis of all \(2\times 2\) complex matrices; with real coefficients, of all \(2\times2\) Hermitian matrices.
  1. follows from (2) and cyclicity: for \(j \neq k\), \(\mathrm{Tr}[\hat\sigma_j\hat\sigma_k] = -\mathrm{Tr}[\hat\sigma_k\hat\sigma_j] = -\mathrm{Tr}[\hat\sigma_j\hat\sigma_k]\).

2.6 The generic qubit observable

For a unit vector \(\vec n = (\sin\theta\cos\varphi, \sin\theta\sin\varphi, \cos\theta)\) define the spin component along \(\vec n\): \[\vec n\cdot\hat{\vec\sigma} = n_x\hat\sigma_x + n_y\hat\sigma_y + n_z\hat\sigma_z = \begin{pmatrix}\cos\theta & e^{-i\varphi}\sin\theta \\ e^{i\varphi}\sin\theta & -\cos\theta\end{pmatrix}.\]

\((\vec r\cdot\hat{\vec\sigma})^2 = |\vec r|^2\,\hat{\mathbb 1}\) for any real \(\vec r\), so \(\vec n\cdot\hat{\vec\sigma}\) has eigenvalues \(\pm 1\), with eigenvectors \[\ket{+_{\vec n}} = \cos\tfrac\theta2\ket 0 + e^{i\varphi}\sin\tfrac\theta2\ket 1, \qquad \ket{-_{\vec n}} = \sin\tfrac\theta2\ket 0 - e^{i\varphi}\cos\tfrac\theta2\ket 1 .\]

The \(+1\) eigenvector of \(\vec n\cdot\hat{\vec\sigma}\) is precisely the qubit state whose Bloch vector is \(\vec n\), and the \(-1\) eigenvector the antipodal one. Every qubit observable has the form \(a\hat{\mathbb 1} + b\,\vec n\cdot\hat{\vec\sigma}\); measuring it is measuring “spin along \(\vec n\)”. For a state with Bloch vector \(\vec r\), \(\langle\vec n\cdot\hat{\vec\sigma}\rangle = \vec n\cdot\vec r\); in particular \(\langle\hat\sigma_x\rangle = r_x\), \(\langle\hat\sigma_y\rangle = r_y\), \(\langle\hat\sigma_z\rangle = r_z\) — the Bloch vector is the vector of Pauli expectation values.

2.7 Exercises

Show that \(\mathrm{Tr}[(\vec r\cdot\hat{\vec\sigma})(\vec s\cdot\hat{\vec\sigma})] = 2\,\vec r\cdot\vec s\) and \((\vec r\cdot\hat{\vec\sigma})^2 = |\vec r|^2\hat{\mathbb 1}\).

Solution. \((\vec r\cdot\hat{\vec\sigma})(\vec s\cdot\hat{\vec\sigma}) = \sum_{jk} r_j s_k\hat\sigma_j\hat\sigma_k = \sum_{jk} r_j s_k(\delta_{jk}\hat{\mathbb 1} + i\epsilon_{jk\ell}\hat\sigma_\ell) = (\vec r\cdot\vec s)\hat{\mathbb 1} + i(\vec r\times\vec s)\cdot\hat{\vec\sigma}\). Taking the trace kills the Pauli term: \(2\vec r\cdot\vec s\). With \(\vec s = \vec r\) the cross product vanishes: \(|\vec r|^2\hat{\mathbb 1}\).

Compute \(\langle\hat\sigma_x\rangle\), \(\langle\hat\sigma_y\rangle\), \(\langle\hat\sigma_z\rangle\) for \(\ket\psi = \cos\tfrac\theta2\ket 0 + e^{i\varphi}\sin\tfrac\theta2\ket 1\) and check that they are the Cartesian components of the Bloch vector.

Solution. \(\langle\hat\sigma_z\rangle = \cos^2\tfrac\theta2 - \sin^2\tfrac\theta2 = \cos\theta\). \(\langle\hat\sigma_x\rangle = 2\,\mathrm{Re}(\alpha^*\beta) = 2\cos\tfrac\theta2\sin\tfrac\theta2\cos\varphi = \sin\theta\cos\varphi\). \(\langle\hat\sigma_y\rangle = 2\,\mathrm{Im}(\alpha^*\beta) = \sin\theta\sin\varphi\).

## Observables and the spectral theorem

::: {.definition name="Hermitian operator and observable"}
$\hat A$ is **Hermitian** (self-adjoint) if $\hat A^\dagger = \hat A$. Physical quantities — **observables** — are represented by Hermitian operators.
:::

::: {.theorem name="Spectral decomposition"}
A Hermitian operator has real eigenvalues $a$ and an orthonormal basis of eigenvectors $\ket a$, $\hat A\ket a = a\ket a$, so that
$$\hat A = \sum_a a\,\ket a\bra a = \sum_a a\,\hat\Pi_a,$$
where, for degenerate eigenvalues, $\hat\Pi_a$ is the projector onto the whole eigenspace.
:::

::: {.definition name="Measurement of an observable"}
Measuring $\hat A$ on $\ket\psi$ yields one of the eigenvalues $a$, with probability
$$p_a = \braket{\psi|\hat\Pi_a|\psi} = |\braket{a|\psi}|^2 \ \text{(non-degenerate case)},$$
and the state collapses to $\hat\Pi_a\ket\psi/\sqrt{p_a}$.
:::

Measuring an observable is thus measuring in its eigenbasis and *labelling* each outcome with the eigenvalue. The labels matter for averages.

::: {.proposition name="Expectation value"}
The mean value of the outcomes is
$$\langle \hat A\rangle = \sum_a a\,p_a = \braket{\psi|\hat A|\psi}.$$
:::

*Proof.* $\braket{\psi|\hat A|\psi} = \sum_a a\braket{\psi|a}\braket{a|\psi} = \sum_a a\,|\braket{a|\psi}|^2 = \sum_a a\,p_a$. $\square$

The **variance** is $(\Delta A)^2 = \langle \hat A^2\rangle - \langle\hat A\rangle^2$; it vanishes iff $\ket\psi$ is an eigenvector of $\hat A$.

## Pauli matrices

$$\hat\sigma_x = \begin{pmatrix} 0 & 1 \\ 1 & 0\end{pmatrix}, \qquad \hat\sigma_y = \begin{pmatrix} 0 & -i \\ i & 0\end{pmatrix}, \qquad \hat\sigma_z = \begin{pmatrix} 1 & 0 \\ 0 & -1\end{pmatrix}.$$

In ket-bra form: $\hat\sigma_x = \ket 0\bra 1 + \ket 1\bra 0$ (bit flip), $\hat\sigma_y = i\ket 1\bra 0 - i\ket 0\bra 1$, $\hat\sigma_z = \ket 0\bra 0 - \ket 1\bra 1$ (phase flip).

::: {.proposition name="Algebra of Pauli matrices"}
1. Each has eigenvalues $\pm 1$; the eigenvectors are $\ket\pm$ for $\hat\sigma_x$, $\ket{\pm i}$ for $\hat\sigma_y$, $\ket 0, \ket 1$ for $\hat\sigma_z$: $\hat\sigma_x = \ket+\bra+ - \ket-\bra-$, etc.
2. $\{\hat\sigma_j, \hat\sigma_k\} = \hat\sigma_j\hat\sigma_k + \hat\sigma_k\hat\sigma_j = 2\delta_{jk}\hat{\mathbb 1}$: they square to the identity and anticommute.
3. $[\hat\sigma_j, \hat\sigma_k] = 2i\epsilon_{jk\ell}\hat\sigma_\ell$, so $\hat\sigma_j\hat\sigma_k = \delta_{jk}\hat{\mathbb 1} + i\epsilon_{jk\ell}\hat\sigma_\ell$.
4. $\mathrm{Tr}\,\hat\sigma_j = 0$ and $\mathrm{Tr}[\hat\sigma_j\hat\sigma_k] = 2\delta_{jk}$.
5. $\{\hat{\mathbb 1}, \hat\sigma_x, \hat\sigma_y, \hat\sigma_z\}$ is a basis of all $2\times 2$ complex matrices; with real coefficients, of all $2\times2$ Hermitian matrices.
:::

(4) follows from (2) and cyclicity: for $j \neq k$, $\mathrm{Tr}[\hat\sigma_j\hat\sigma_k] = -\mathrm{Tr}[\hat\sigma_k\hat\sigma_j] = -\mathrm{Tr}[\hat\sigma_j\hat\sigma_k]$.

## The generic qubit observable

For a unit vector $\vec n = (\sin\theta\cos\varphi, \sin\theta\sin\varphi, \cos\theta)$ define the spin component along $\vec n$:
$$\vec n\cdot\hat{\vec\sigma} = n_x\hat\sigma_x + n_y\hat\sigma_y + n_z\hat\sigma_z = \begin{pmatrix}\cos\theta & e^{-i\varphi}\sin\theta \\ e^{i\varphi}\sin\theta & -\cos\theta\end{pmatrix}.$$

::: {.proposition name="Eigen-decomposition of $\vec n\cdot\hat{\vec\sigma}$"}
$(\vec r\cdot\hat{\vec\sigma})^2 = |\vec r|^2\,\hat{\mathbb 1}$ for any real $\vec r$, so $\vec n\cdot\hat{\vec\sigma}$ has eigenvalues $\pm 1$, with eigenvectors
$$\ket{+_{\vec n}} = \cos\tfrac\theta2\ket 0 + e^{i\varphi}\sin\tfrac\theta2\ket 1, \qquad \ket{-_{\vec n}} = \sin\tfrac\theta2\ket 0 - e^{i\varphi}\cos\tfrac\theta2\ket 1 .$$
:::

The $+1$ eigenvector of $\vec n\cdot\hat{\vec\sigma}$ is precisely the qubit state whose Bloch vector is $\vec n$, and the $-1$ eigenvector the antipodal one. Every qubit observable has the form $a\hat{\mathbb 1} + b\,\vec n\cdot\hat{\vec\sigma}$; measuring it is measuring "spin along $\vec n$". For a state with Bloch vector $\vec r$, $\langle\vec n\cdot\hat{\vec\sigma}\rangle = \vec n\cdot\vec r$; in particular $\langle\hat\sigma_x\rangle = r_x$, $\langle\hat\sigma_y\rangle = r_y$, $\langle\hat\sigma_z\rangle = r_z$ — the Bloch vector *is* the vector of Pauli expectation values.

## Exercises

::: {.exercise}
Show that $\mathrm{Tr}[(\vec r\cdot\hat{\vec\sigma})(\vec s\cdot\hat{\vec\sigma})] = 2\,\vec r\cdot\vec s$ and $(\vec r\cdot\hat{\vec\sigma})^2 = |\vec r|^2\hat{\mathbb 1}$.

:::

:::

::: {.solution}
$\langle\hat\sigma_z\rangle = \cos^2\tfrac\theta2 - \sin^2\tfrac\theta2 = \cos\theta$. $\langle\hat\sigma_x\rangle = 2\,\mathrm{Re}(\alpha^*\beta) = 2\cos\tfrac\theta2\sin\tfrac\theta2\cos\varphi = \sin\theta\cos\varphi$. $\langle\hat\sigma_y\rangle = 2\,\mathrm{Im}(\alpha^*\beta) = \sin\theta\sin\varphi$.
