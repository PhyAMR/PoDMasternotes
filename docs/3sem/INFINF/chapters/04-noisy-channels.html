5  Noisy channels and coding

So far the channel was perfect: what the sender wrote, the receiver read. Real signals are corrupted by noise, and the receiver may get a string \(Y\) different from the transmitted \(Z\). Shannon’s second big theorem answers a question that seems, at first, to have a disappointing answer: can we communicate reliably over a noisy channel without letting the rate go to zero? Surprisingly, yes — up to a maximum rate, the channel capacity \(C = \max_{p(x)} I(X; Y)\). Achievability is proved by the beautiful random-coding argument, again built on typicality.

Along the way we meet, for the first time, the theme of Part II: decoding is an inference problem.

5.1 Decoding as an inference problem

The general scheme is:

\[X \xrightarrow{\ \text{encoder } E\ } Z = E(X) \xrightarrow{\ \text{channel } p(y\mid z)\ } Y \xrightarrow{\ \text{decoder } D\ } X' = D(Y).\]

The sender encodes the source \(X\) with a deterministic encoder \(E : \mathcal A_X \to \mathcal B^K\); the encoded message \(Z\) passes through a noisy channel, which outputs \(Y\) with probability \(p(y \mid z)\); the receiver applies a deterministic decoder \(D\) and obtains \(X'\). Because of noise the error probability \(P_e = P(X' \neq X)\) is in general non-zero. Since \(E\) is deterministic and injective, \(I(X;Y) = I(Z;Y)\).

A discrete memoryless channel (DMC) is a triple \((\mathcal A_Z, \mathcal A_Y, p(y \mid z))\): input alphabet, output alphabet, and a transition probability. Memoryless means that for a length-\(n\) transmission \[p(y^{(n)} \mid z^{(n)}) = \prod_{i=1}^{n} p(y_i \mid z_i).\]

A fair coin \(X \in \{h, t\}\) is encoded as \(Z \in \{0, 1\}\) (\(h \mapsto 0\), \(t \mapsto 1\)) and sent through a channel that flips the bit with probability \(f\): \[P(Y = Z) = 1 - f, \qquad P(Y \neq Z) = f .\] Decoding \(Y\) directly gives \(P_e = f\). With \(H(Z) = 1\) and \(H(Z \mid Y) = h_2(f)\), \[I(X; Y) = I(Z;Y) = 1 - h_2(f).\] At \(f = 0\) the received bit carries all the information; at \(f = 1/2\) none.

The BEC with erasure probability \(\varepsilon\) has \(\mathcal A_Y = \{0, 1, ?\}\), \(p(? \mid z) = \varepsilon\), \(p(z \mid z) = 1 - \varepsilon\). Each input is either received correctly or visibly lost — never silently corrupted. For uniform input, \(I(Z;Y) = 1 - \varepsilon\).

5.1.1 Estimators and Bayes risk

Reconstructing \(X\) from \(Y\) is an instance of a very general problem: a latent variable \(X\) and an observed variable \(Y\) are related by a joint distribution \(p_{XY}(x, y)\), and we want an estimator \(X' = D(Y)\), a deterministic function of the data. Its quality is measured by a loss \(\ell(x', x)\); for discrete messages the natural one is the 0–1 loss \[\ell(x', x) = 1 - \delta_{x', x}.\]

The posterior risk of \(D\) given the observation \(y\) is the expected loss under the posterior, \[r_D(y) = \sum_x p(x \mid y)\,\ell(D(y), x) = 1 - p\bigl(D(y) \mid y\bigr),\] i.e. the probability of error when \(y\) is received. The Bayes risk is its average over \(y\), \[r_D = \sum_y p(y)\,r_D(y) = \sum_{x,y} p(x, y)\,\ell(D(y), x) = P_e .\]

The decoder that minimises both the posterior risk and the Bayes risk under 0–1 loss is the maximum a posteriori (MAP) decoder \[D_{\text{MAP}}(y) = \arg\max_{x} p(x \mid y) = \arg\max_x p(y \mid x)\,p(x).\] If all messages are equiprobable it coincides with the maximum-likelihood decoder \(\arg\max_x p(y \mid x)\).

Proof. \(r_D(y) = 1 - p(D(y) \mid y)\) is minimised, for each \(y\) separately, by choosing \(D(y)\) to maximise \(p(\cdot \mid y)\). Minimising pointwise also minimises the average \(r_D\).

Other losses give other optimal estimators (squared loss → posterior mean, absolute loss → posterior median); we return to this in Part II.

5.2 Error-correcting codes

To fight noise the sender adds redundancy: codewords become longer, and we trade rate for accuracy. Ideally we would use non-confusable codewords, i.e. codewords \(z_i\) that the channel maps onto disjoint sets of outputs, so that every received \(y\) is compatible with exactly one \(z_i\).

If the code assigns codewords of length \(L\) to a set \(S\) of messages, the rate is \[R = \frac{\log_2 |S|}{L}\] — effective bits of information per transmitted binary digit. If \(|S| = 2^K\), then \(R = K/L\). An injective code needs \(2^L \geq |S|\), so \(R \leq 1\); adding redundancy (using only a subset of the \(2^L\) strings as codewords) lowers \(R\).

5.2.1 Repetition codes

Send each bit three times: \(h \mapsto 000\), \(t \mapsto 111\). Over a BSC the received block has the following probabilities:

sent \(\backslash\) received 000 001, 010, 100 011, 101, 110 111
000 \((1-f)^3\) \(f(1-f)^2\) \(f^2(1-f)\) \(f^3\)
111 \(f^3\) \(f^2(1-f)\) \(f(1-f)^2\) \((1-f)^3\)

Let \(m(y)\) be the number of 1s in \(y\). The majority decoder outputs \(h\) if \(m < 2\) and \(t\) if \(m \geq 2\). This is the MAP decoder: with equiprobable messages, MAP = ML, and \[\frac{p(y \mid h)}{p(y \mid t)} = \frac{f^{m}(1-f)^{K-m}}{f^{K-m}(1-f)^{m}} = \Bigl(\frac{f}{1-f}\Bigr)^{2m - K},\] which for \(f < 1/2\) is \(> 1\) iff \(m < K/2\).

The error probability is the probability that two or three bits flip: \[P_e = 3f^2(1-f) + f^3 = 3f^2 - 2f^3 .\] For \(f = 0.1\), \(P_e \approx 0.028\), much smaller than \(f\) — but the rate has dropped to \(R = 1/3\).

For a general repetition code \(R_K\) (\(K\) odd) with majority decoding, \[P_e = \sum_{n = \lceil K/2\rceil}^{K} \binom{K}{n} f^n (1-f)^{K-n} \approx \binom{K}{\lceil K/2\rceil} f^{\lceil K/2\rceil}(1-f)^{\lfloor K/2 \rfloor},\] dominated by the smallest number of flips that causes an error. Asymptotically \(P_e \sim 2^{-K D(1/2 \| f)}\). The error vanishes as \(K \to \infty\), but so does the rate \(R = 1/K\): for \(f = 0.1\), reaching \(P_e \approx 10^{-15}\) needs \(K = 61\), i.e. \(R \approx 0.016\). Repetition codes buy reliability at a ruinous price.

5.2.2 The Hamming (7,4) code

Encode blocks of 4 source bits \(z_1z_2z_3z_4\) into 7 bits by appending three parity-check bits (sums modulo 2, \(1 \oplus 1 = 0\)): \[z_5 = z_1 \oplus z_2 \oplus z_3, \qquad z_6 = z_2 \oplus z_3 \oplus z_4, \qquad z_7 = z_1 \oplus z_2 \oplus z_4 .\] Picture three overlapping circles, each containing four bits whose sum must be even. In matrix form \(\mathbf z = G\,\mathbf z^{(4)}\) (mod 2) with the \(7 \times 4\) generator matrix \[G = \begin{pmatrix} I_4 \\ P \end{pmatrix}, \qquad P = \begin{pmatrix} 1&1&1&0\\ 0&1&1&1 \\ 1&1&0&1 \end{pmatrix}.\] The 16 codewords differ pairwise in at least 3 positions (minimum distance 3), so any single flip leaves the received word closer to the transmitted codeword than to any other. The rate is \(R = 4/7\).

Decoding. Write \(\mathbf y = \mathbf z \oplus \boldsymbol\epsilon\) with \(\boldsymbol\epsilon\) the noise vector (\(\epsilon_i = 1\) if bit \(i\) flipped). For a BSC, \(P(\boldsymbol\epsilon) = f^{m(\boldsymbol\epsilon)}(1-f)^{7 - m(\boldsymbol\epsilon)}\), which (for \(f < 1/2\)) decreases with the number of flips \(m(\boldsymbol\epsilon)\). Hence the MAP decoder picks the codeword closest to \(\mathbf y\) in Hamming distance: \[\hat{\mathbf z} = \mathbf y \oplus \arg\min_{\boldsymbol\epsilon : \mathbf y \oplus \boldsymbol\epsilon \in \text{codebook}} m(\boldsymbol\epsilon).\] This is done efficiently with the parity-check matrix \[H = \begin{pmatrix} P & I_3 \end{pmatrix} = \begin{pmatrix} 1&1&1&0&1&0&0 \\ 0&1&1&1&0&1&0 \\ 1&1&0&1&0&0&1 \end{pmatrix}, \qquad H G = 0 \pmod 2 .\] The syndrome \(\mathbf s = H\mathbf y = H(\mathbf z \oplus \boldsymbol\epsilon) = H\boldsymbol\epsilon\) depends only on the noise. A flip of bit \(i\) produces the syndrome equal to the \(i\)-th column of \(H\); all seven columns are distinct and non-zero, so the seven single-flip patterns are in one-to-one correspondence with the seven non-zero syndromes:

syndrome 000 001 010 100 011 101 110 111
unflip none \(z_7\) \(z_6\) \(z_5\) \(z_4\) \(z_1\) \(z_3\) \(z_2\)

(A flip in a source bit \(z_1..z_4\) violates at least two checks; a flip in a parity bit violates exactly one.)

Worked example. Source \(1000\) → codeword \(1000\,101\). Suppose bit 3 flips: \(\mathbf y = 1010\,101\). Then \(s_1 = y_1 \oplus y_2 \oplus y_3 \oplus y_5 = 1\), \(s_2 = y_2 \oplus y_3 \oplus y_4 \oplus y_6 = 1\), \(s_3 = y_1 \oplus y_2 \oplus y_4 \oplus y_7 = 0\): syndrome \(110\) → unflip \(z_3\), recovering \(1000\).

Decoding fails only when two or more bits flip in a block, so the block error is \(P_B = 1 - (1-f)^7 - 7f(1-f)^6 \approx \binom72 f^2 = 21 f^2\) for small \(f\) (exactly \(0.15\) at \(f = 0.1\)). The error is \(O(f^2)\), as for \(R_3\), but at rate \(4/7\) rather than \(1/3\).

5.2.3 How good can a code be?

We want both large \(R\) and small \(P_e\). Repetition codes suggest that \(P_e \to 0\) forces \(R \to 0\). Shannon’s surprise is that this is false: \(P_e\) can be made arbitrarily small at any rate below a finite threshold, the capacity.

The capacity of a channel is the maximal mutual information between input and output, over all input distributions: \[C = \max_{p_Z} I(Z; Y).\]

For a noiseless channel \(I(Z;Y) = H(Z)\) and \(C = \max H(Z) = \log|\mathcal A_Z|\), consistent with the source coding theorem.

With \(p_0 = P(Z = 0)\), the output is Bernoulli with \(P(Y = 1) = p_0 f + (1 - p_0)(1 - f)\), and \(H(Y \mid Z) = h_2(f)\) whatever the input. So \[I(Z; Y) = h_2\bigl(p_0 f + (1-p_0)(1-f)\bigr) - h_2(f),\] maximised at \(p_0 = 1/2\) where the output is uniform: \[C_{\text{BSC}} = 1 - h_2(f).\] For \(f = 0.1\), \(C \approx 0.53\): reliable communication is possible at about half a bit per use — far better than the \(R \to 0\) of repetition codes.

\(H(Y) = h_2(\varepsilon) + (1-\varepsilon)h_2(p_0)\) and \(H(Y \mid Z) = h_2(\varepsilon)\), so \(I = (1-\varepsilon) h_2(p_0)\) and \(C_{\text{BEC}} = 1 - \varepsilon\): each non-erased symbol conveys one bit.

The alphabet is \(\{A, B, \ldots, Z, -\}\) (27 symbols, arranged in a circle so that \(-\) precedes \(A\)). Each input is received as itself, its predecessor or its successor, each with probability \(1/3\) — an inaccurate typewriter hitting neighbouring keys: \[P(Y = A \mid Z = B) = P(Y = B \mid Z = B) = P(Y = C \mid Z = B) = \tfrac13, \ \text{etc.}\] Since \(H(Y \mid Z) = \log 3\) for every input, \(I(Z;Y) = H(Y) - \log 3\), maximised when \(Y\) (hence \(Z\)) is uniform: \(H(Y) = \log 27 = 3\log 3\) and \[C = 3\log 3 - \log 3 = 2\log 3 = \log 9 \approx 3.17 \text{ bits}.\] The capacity is achieved with zero error by using only every third letter, \(S = \{B, E, H, K, N, Q, T, W, Z\}\): the output sets \(\{A,B,C\}, \{D,E,F\}, \ldots\) are disjoint, so these 9 codewords are non-confusable, and \(R = \log 9\) per use. In this case \(n_Z \cdot n_{Y|Z} = 9 \times 3 = 27 = n_Y\), so \(H(Z \mid Y) = 0\).

The noisy typewriter is special: non-confusable codewords exist for a single use. Shannon’s insight is that every channel looks like a noisy typewriter if we use it \(n\) times and \(n\) is large.

5.3 The noisy-channel coding theorem

A \((K, n)\) block code is a list of \(2^K\) codewords \(S = \{\mathbf z_1, \ldots, \mathbf z_{2^K}\} \subset \mathcal A_Z^n\), used to encode \(2^K\) messages; its rate is \(R = K/n\). A decoder maps \(\mathcal A_Y^n \to S\). The block error probability is \(P_B = P(D(\mathbf Y) \neq \mathbf Z)\), and the maximal block error probability is \(P_B^{\max} = \max_{\mathbf z \in S} P(D(\mathbf Y) \neq \mathbf z \mid \mathbf Z = \mathbf z)\).

The repetition code \(R_n\) is a \((1, n)\) block code; the Hamming code is a \((4, 7)\) code.

For a discrete memoryless channel with capacity \(C = \max_{p_Z} I(Z;Y)\):

  1. (Achievability) For every \(\delta > 0\) and \(\beta > 0\), for \(n\) large enough there exists a block code of length \(n\) and rate \(R \geq C - \beta\), with a decoder whose maximal block error probability is below \(\delta\).
  2. (Converse) No sequence of codes with rate \(R > C\) has error probability tending to zero.

5.3.1 The intuition: every channel is a noisy typewriter

  1. Use the channel \(n\) times. For large \(n\), the input \(\mathbf z\) is (with high probability) typical, one of about \(2^{nH(Z)}\) sequences.
  2. The output \(\mathbf y\) is typical, one of about \(2^{nH(Y)}\) sequences.
  3. The pair \((\mathbf z, \mathbf y)\) is jointly typical, one of about \(2^{nH(Z,Y)}\) pairs.
  4. Hence, for a given input \(\mathbf z\), the output is essentially one of \(2^{nH(Z,Y) - nH(Z)} = 2^{nH(Y \mid Z)}\) sequences — a “fan” of possible outputs.
  5. If we use \(2^{nR}\) codewords, their fans are (nearly) disjoint — non-confusable — only if they fit in the output space: \(2^{nR}\,2^{nH(Y\mid Z)} \leq 2^{nH(Y)}\), i.e. \[R \leq H(Y) - H(Y \mid Z) = I(Z;Y) \leq C .\]
  6. Conversely, choosing codewords at random among typical inputs and decoding by joint typicality achieves any \(R < C\) with vanishing error.

5.3.2 Joint typicality

Given \(p(z, y)\), the jointly typical set \(T_{n\beta}[Z, Y]\) is the set of pairs \((\mathbf z, \mathbf y)\) such that \[\Bigl|-\tfrac{1}{n}\log p(\mathbf z) - H(Z)\Bigr| < \beta,\quad \Bigl|-\tfrac{1}{n}\log p(\mathbf y) - H(Y)\Bigr| < \beta,\quad \Bigl|-\tfrac{1}{n}\log p(\mathbf z, \mathbf y) - H(Z, Y)\Bigr| < \beta .\]

Let \((\mathbf Z, \mathbf Y)\) be drawn i.i.d. from \(p(z, y)\). As \(n \to \infty\):

  1. \(P\bigl((\mathbf Z, \mathbf Y) \in T_{n\beta}\bigr) \to 1\);
  2. \(|T_{n\beta}[Z, Y]| \leq 2^{n(H(Z,Y) + \beta)}\);
  3. if \(\tilde{\mathbf Z}\) and \(\tilde{\mathbf Y}\) are drawn independently from the marginals \(p(\mathbf z)\) and \(p(\mathbf y)\), then \[P\bigl((\tilde{\mathbf Z}, \tilde{\mathbf Y}) \in T_{n\beta}\bigr) \leq 2^{-n(I(Z;Y) - 3\beta)} .\]

Proof.

  1. and (2) follow exactly as for the single-variable AEP. For (3), every jointly typical pair has \(p(\mathbf z) \leq 2^{-n(H(Z) - \beta)}\) and \(p(\mathbf y) \leq 2^{-n(H(Y) - \beta)}\), so \[P = \sum_{(\mathbf z, \mathbf y) \in T_{n\beta}} p(\mathbf z)\,p(\mathbf y) \leq 2^{n(H(Z,Y) + \beta)}\,2^{-n(H(Z) - \beta)}\,2^{-n(H(Y) - \beta)} = 2^{-n(I(Z;Y) - 3\beta)} .\]

Property 3 is the heart of the theorem: two independently drawn sequences almost never look jointly typical; the probability of a “spurious match” is exponentially small in \(nI(Z;Y)\).

5.3.3 Random coding and typical-set decoding

Proof (Proof of achievability). Fix \(p_Z\) achieving the capacity.

Random coding. Draw \(2^K = 2^{nR}\) codewords \(\mathbf z_1, \ldots, \mathbf z_{2^K}\) independently, each i.i.d. from \(p_Z\).

Typical-set decoding. On receiving \(\mathbf y\), output the codeword \(\mathbf z'\) that is jointly typical with \(\mathbf y\); if there is none, or more than one, declare failure.

The error of a given codebook \(S\), \(r(S)\), is hard to compute. Shannon’s trick is to average over all codebooks. By symmetry the averaged error equals the error when message 1 is sent: \[\langle r(S) \rangle_S = P(\mathbf z' \neq \mathbf z_1).\] When \(\mathbf z_1\) is sent and \(\mathbf y\) is received, an error occurs only if

  • \(E_1\): \(\mathbf z_1\) is not jointly typical with \(\mathbf y\). Since \((\mathbf z_1, \mathbf y)\) is drawn from the joint distribution, by the joint AEP \(P(E_1) < \delta/2\) for large \(n\);
  • \(E_2\): some other codeword \(\mathbf z_i\), \(i \geq 2\), is jointly typical with \(\mathbf y\). Each \(\mathbf z_i\) is independent of \(\mathbf y\), so by the union bound and property 3, \[P(E_2) \leq \sum_{i=2}^{2^{nR}} P\bigl((\mathbf z_i, \mathbf y) \in T_{n\beta}\bigr) \leq 2^{nR}\,2^{-n(I(Z;Y) - 3\beta)} = 2^{-n(C - R - 3\beta)} .\] This is smaller than \(\delta/2\) for large \(n\) provided \(R < C - 3\beta\).

Hence \(\langle r(S)\rangle_S \leq P(E_1) + P(E_2) < \delta\). Since the average over codebooks is below \(\delta\), at least one codebook \(S^*\) has \(r(S^*) < \delta\).

From average to maximal error (expurgation). \(r(S^*)\) is an average over messages. At most half the codewords can have error above \(2\delta\); discard them. The remaining \(2^{nR - 1}\) codewords have maximal error \(< 2\delta\) and rate \(R - 1/n\), which is still \(\geq C - \beta'\) for large \(n\). Since \(\beta, \delta\) are arbitrary, the theorem follows.

Remark. The genius of the proof is to show existence by averaging. A random codebook is bad in ways that are hard to analyse, but the ensemble has good average behaviour — so at least one codebook is at least as good as the average. In fact almost all random codebooks are good; the hard part is decoding them efficiently (typical-set decoding of a random code takes time exponential in \(n\)).

5.3.4 The converse: Fano’s inequality

Let \(X\) take values in \(\mathcal X\) and let \(\hat X = g(Y)\) be any estimate of \(X\) from \(Y\), with \(P_e = P(\hat X \neq X)\). Then \[H(X \mid Y) \leq H(X \mid \hat X) \leq h_2(P_e) + P_e\log_2(|\mathcal X| - 1).\]

Fano’s inequality says that small error forces small residual uncertainty; contrapositively, if \(H(X \mid Y)\) is large, every estimator errs often.

Proof (Proof sketch of the converse). Send a uniformly chosen message \(W \in \{1, \ldots, 2^{nR}\}\), so \(H(W) = nR\). Then \[nR = H(W) = H(W \mid \mathbf Y) + I(W; \mathbf Y) \leq \bigl(1 + P_e\,nR\bigr) + I(\mathbf Z; \mathbf Y) \leq 1 + P_e\,nR + nC,\] using Fano, the data-processing inequality (\(W \to \mathbf Z \to \mathbf Y\)) and memorylessness (\(I(\mathbf Z; \mathbf Y) \leq \sum_i I(Z_i; Y_i) \leq nC\)). Dividing by \(n\): \(R \leq C + 1/n + P_e R\), i.e. \(P_e \geq 1 - C/R - 1/(nR)\). If \(R > C\) the error is bounded away from zero.

For \(R < C\) the average error over random codebooks decays exponentially, \(\bar P_e \leq 2^{-nE_r(R)}\), where \(E_r(R) > 0\) is Gallager’s random-coding exponent. It quantifies how large \(n\) must be for a given target error.

5.4 Structured codes

The random-coding proof does not construct a practical code; it shows one exists. Practical coding needs structured codes with fast decoders.

  • Repetition codes: rate \(1/K\), error \(\sim 2^{-KD(1/2\|f)}\). A baseline.
  • Hamming codes: rate \(4/7\), single-error correcting; the first algebraic (linear) codes.
  • Modern codes — LDPC (Gallager 1962), turbo codes (Berrou et al. 1993), polar codes (Arıkan 2009) — approach capacity within fractions of a dB and are decoded in (near-)linear time by message passing, i.e. approximate Bayesian inference on a graph. Their invention represents sixty years of work catching up with Shannon.

5.5 Exercises

Compute the capacity of the Z-channel: \(\mathcal A_Z = \mathcal A_Y = \{0, 1\}\), \(p(0 \mid 0) = 1\), \(p(0 \mid 1) = q\), \(p(1 \mid 1) = 1 - q\).

Solution. Let \(P(Z = 1) = \pi\). Then \(P(Y = 1) = \pi(1 - q)\), \(H(Y \mid Z) = \pi h_2(q)\), and \(I = h_2(\pi(1-q)) - \pi h_2(q)\). Setting \(dI/d\pi = 0\) gives the optimum, and the capacity has the closed form \(C = \log_2\bigl(1 + (1-q)\,q^{q/(1-q)}\bigr)\). For \(q = 0.5\): \(C = \log_2(1.25) \approx 0.322\) bits per use, at \(\pi \approx 0.4\). Compare the BSC with \(f = 0.5\), whose capacity is zero: the Z-channel’s asymmetry (“0” is never corrupted) keeps it useful.

Prove Fano’s inequality using the error indicator \(E = \mathbf 1[\hat X \neq X]\).

Solution. Expand \(H(E, X \mid \hat X)\) in two ways. First, \(H(E, X \mid \hat X) = H(X \mid \hat X) + H(E \mid X, \hat X) = H(X \mid \hat X)\), since \(E\) is a function of \((X, \hat X)\). Second, \(H(E, X \mid \hat X) = H(E \mid \hat X) + H(X \mid E, \hat X) \leq h_2(P_e) + P_e\log_2(|\mathcal X| - 1)\): conditioning reduces entropy (\(H(E \mid \hat X) \leq H(E) = h_2(P_e)\)); if \(E = 0\) then \(X = \hat X\) and there is no uncertainty; if \(E = 1\), \(X\) is one of the remaining \(|\mathcal X| - 1\) values. Finally \(H(X \mid Y) \leq H(X \mid \hat X)\) by data processing.

For the repetition code \(R_5\) on a BSC with \(f = 0.1\), compute \(P_e\) and compare with \(R_3\).

Solution. Error iff \(\geq 3\) flips: \(P_e = \binom53 f^3(1-f)^2 + \binom54 f^4(1-f) + f^5 = 10(0.001)(0.81) + 5(0.0001)(0.9) + 10^{-5} \approx 0.0081 + 0.00045 + 0.00001 \approx 0.0086\). \(R_3\) had \(0.028\) at rate \(1/3\); \(R_5\) has \(0.0086\) at rate \(1/5\). Each factor \(\sim 3\) improvement costs a big drop in rate.

In the Hamming (7,4) code, the received word is \(\mathbf y = 0110\,110\). Decode it.

Solution. \(s_1 = y_1 \oplus y_2 \oplus y_3 \oplus y_5 = 0 \oplus 1 \oplus 1 \oplus 1 = 1\); \(s_2 = y_2 \oplus y_3 \oplus y_4 \oplus y_6 = 1 \oplus 1 \oplus 0 \oplus 1 = 1\); \(s_3 = y_1 \oplus y_2 \oplus y_4 \oplus y_7 = 0 \oplus 1 \oplus 0 \oplus 0 = 1\). Syndrome \(111\) → flip \(z_2\): \(\hat{\mathbf z} = 0010\,110\). Check: \(z_5 = 0 \oplus 0 \oplus 1 = 1\), \(z_6 = 0 \oplus 1 \oplus 0 = 1\), \(z_7 = 0 \oplus 0 \oplus 0 = 0\) \(\checkmark\). Decoded message: \(0010\).

5.6 Callouts

The noisy-channel coding theorem gives mutual information its operational meaning: \(\max I(Z;Y)\) is the maximum rate of reliable communication. Decoding is inference, and the optimal decoder under 0–1 loss is MAP.

For a symmetric channel (every row of \(p(y\mid z)\) a permutation of every other, and likewise columns) the capacity is achieved by the uniform input and equals \(\log|\mathcal A_Y| - H(\text{row})\). BSC, BEC-like and noisy typewriter examples all follow from this.

Shannon’s theorem is an existence result. Constructing capacity-achieving codes with efficient decoders was an open problem for decades.

The capacity \(C\) is an asymptotic (long-block) quantity. At finite block length the achievable rate is lower, roughly \(C - \sqrt{V/n}\,Q^{-1}(\epsilon)\) (Polyanskiy, Poor & Verdú 2010).

title: "Noisy channels and coding"
---

So far the channel was perfect: what the sender wrote, the receiver read. Real signals are corrupted by noise, and the receiver may get a string $Y$ different from the transmitted $Z$. Shannon's second big theorem answers a question that seems, at first, to have a disappointing answer: *can we communicate reliably over a noisy channel without letting the rate go to zero?* Surprisingly, yes — up to a maximum rate, the channel **capacity** $C = \max_{p(x)} I(X; Y)$. Achievability is proved by the beautiful *random-coding* argument, again built on typicality.

Along the way we meet, for the first time, the theme of Part II: **decoding is an inference problem.**

## Decoding as an inference problem

The general scheme is:

$$X \xrightarrow{\ \text{encoder } E\ } Z = E(X) \xrightarrow{\ \text{channel } p(y\mid z)\ } Y \xrightarrow{\ \text{decoder } D\ } X' = D(Y).$$

The sender encodes the source $X$ with a deterministic encoder $E : \mathcal A_X \to \mathcal B^K$; the encoded message $Z$ passes through a noisy channel, which outputs $Y$ with probability $p(y \mid z)$; the receiver applies a deterministic decoder $D$ and obtains $X'$. Because of noise the **error probability** $P_e = P(X' \neq X)$ is in general non-zero. Since $E$ is deterministic and injective, $I(X;Y) = I(Z;Y)$.

::: {.definition name="Discrete memoryless channel"}
A **discrete memoryless channel (DMC)** is a triple $(\mathcal A_Z, \mathcal A_Y, p(y \mid z))$: input alphabet, output alphabet, and a transition probability. Memoryless means that for a length-$n$ transmission
$$p(y^{(n)} \mid z^{(n)}) = \prod_{i=1}^{n} p(y_i \mid z_i).$$
:::

::: {.example name="Binary symmetric channel"}
A fair coin $X \in \{h, t\}$ is encoded as $Z \in \{0, 1\}$ ($h \mapsto 0$, $t \mapsto 1$) and sent through a channel that flips the bit with probability $f$:
$$P(Y = Z) = 1 - f, \qquad P(Y \neq Z) = f .$$
Decoding $Y$ directly gives $P_e = f$. With $H(Z) = 1$ and $H(Z \mid Y) = h_2(f)$,
$$I(X; Y) = I(Z;Y) = 1 - h_2(f).$$
At $f = 0$ the received bit carries all the information; at $f = 1/2$ none.
:::

::: {.example name="Binary erasure channel"}
The BEC with erasure probability $\varepsilon$ has $\mathcal A_Y = \{0, 1, ?\}$, $p(? \mid z) = \varepsilon$, $p(z \mid z) = 1 - \varepsilon$. Each input is either received correctly or visibly lost — *never* silently corrupted. For uniform input, $I(Z;Y) = 1 - \varepsilon$.
:::

### Estimators and Bayes risk

Reconstructing $X$ from $Y$ is an instance of a very general problem: a latent variable $X$ and an observed variable $Y$ are related by a joint distribution $p_{XY}(x, y)$, and we want an **estimator** $X' = D(Y)$, a deterministic function of the data. Its quality is measured by a **loss** $\ell(x', x)$; for discrete messages the natural one is the 0–1 loss
$$\ell(x', x) = 1 - \delta_{x', x}.$$

::: {.definition name="Posterior risk and Bayes risk"}
The **posterior risk** of $D$ given the observation $y$ is the expected loss under the posterior,
$$r_D(y) = \sum_x p(x \mid y)\,\ell(D(y), x) = 1 - p\bigl(D(y) \mid y\bigr),$$
i.e. the probability of error when $y$ is received. The **Bayes risk** is its average over $y$,
$$r_D = \sum_y p(y)\,r_D(y) = \sum_{x,y} p(x, y)\,\ell(D(y), x) = P_e .$$
:::

::: {.proposition name="MAP decoding is optimal"}
The decoder that minimises both the posterior risk and the Bayes risk under 0–1 loss is the **maximum a posteriori (MAP)** decoder
$$D_{\text{MAP}}(y) = \arg\max_{x} p(x \mid y) = \arg\max_x p(y \mid x)\,p(x).$$
If all messages are equiprobable it coincides with the **maximum-likelihood** decoder $\arg\max_x p(y \mid x)$.
:::

::: {.proof}
$r_D(y) = 1 - p(D(y) \mid y)$ is minimised, for each $y$ separately, by choosing $D(y)$ to maximise $p(\cdot \mid y)$. Minimising pointwise also minimises the average $r_D$.
:::

Other losses give other optimal estimators (squared loss → posterior mean, absolute loss → posterior median); we return to this in Part II.

## Error-correcting codes

To fight noise the sender adds **redundancy**: codewords become longer, and we trade rate for accuracy. Ideally we would use **non-confusable codewords**, i.e. codewords $z_i$ that the channel maps onto *disjoint* sets of outputs, so that every received $y$ is compatible with exactly one $z_i$.

::: {.definition name="Rate"}
If the code assigns codewords of length $L$ to a set $S$ of messages, the **rate** is
$$R = \frac{\log_2 |S|}{L}$$
— effective bits of information per transmitted binary digit. If $|S| = 2^K$, then $R = K/L$. An injective code needs $2^L \geq |S|$, so $R \leq 1$; adding redundancy (using only a subset of the $2^L$ strings as codewords) lowers $R$.
:::

### Repetition codes

::: {.example name="The repetition code $R_3$"}
Send each bit three times: $h \mapsto 000$, $t \mapsto 111$. Over a BSC the received block has the following probabilities:

| sent $\backslash$ received | 000 | 001, 010, 100 | 011, 101, 110 | 111 |
|:---:|:---:|:---:|:---:|:---:|
| 000 | $(1-f)^3$ | $f(1-f)^2$ | $f^2(1-f)$ | $f^3$ |
| 111 | $f^3$ | $f^2(1-f)$ | $f(1-f)^2$ | $(1-f)^3$ |

Let $m(y)$ be the number of 1s in $y$. The **majority decoder** outputs $h$ if $m < 2$ and $t$ if $m \geq 2$. This *is* the MAP decoder: with equiprobable messages, MAP = ML, and
$$\frac{p(y \mid h)}{p(y \mid t)} = \frac{f^{m}(1-f)^{K-m}}{f^{K-m}(1-f)^{m}} = \Bigl(\frac{f}{1-f}\Bigr)^{2m - K},$$
which for $f < 1/2$ is $> 1$ iff $m < K/2$.

The error probability is the probability that two or three bits flip:
$$P_e = 3f^2(1-f) + f^3 = 3f^2 - 2f^3 .$$
For $f = 0.1$, $P_e \approx 0.028$, much smaller than $f$ — but the rate has dropped to $R = 1/3$.
:::

For a general repetition code $R_K$ ($K$ odd) with majority decoding,
$$P_e = \sum_{n = \lceil K/2\rceil}^{K} \binom{K}{n} f^n (1-f)^{K-n} \approx \binom{K}{\lceil K/2\rceil} f^{\lceil K/2\rceil}(1-f)^{\lfloor K/2 \rfloor},$$
dominated by the smallest number of flips that causes an error. Asymptotically $P_e \sim 2^{-K D(1/2 \| f)}$. The error vanishes as $K \to \infty$, but so does the rate $R = 1/K$: for $f = 0.1$, reaching $P_e \approx 10^{-15}$ needs $K = 61$, i.e. $R \approx 0.016$. Repetition codes buy reliability at a ruinous price.

### The Hamming (7,4) code

::: {.example name="Hamming (7,4)"}
Encode blocks of 4 source bits $z_1z_2z_3z_4$ into 7 bits by appending three **parity-check bits** (sums modulo 2, $1 \oplus 1 = 0$):
$$z_5 = z_1 \oplus z_2 \oplus z_3, \qquad z_6 = z_2 \oplus z_3 \oplus z_4, \qquad z_7 = z_1 \oplus z_2 \oplus z_4 .$$
Picture three overlapping circles, each containing four bits whose sum must be even. In matrix form $\mathbf z = G\,\mathbf z^{(4)}$ (mod 2) with the $7 \times 4$ generator matrix
$$G = \begin{pmatrix} I_4 \\ P \end{pmatrix}, \qquad P = \begin{pmatrix} 1&1&1&0\\ 0&1&1&1 \\ 1&1&0&1 \end{pmatrix}.$$
The 16 codewords differ pairwise in at least 3 positions (minimum distance 3), so any single flip leaves the received word closer to the transmitted codeword than to any other. The rate is $R = 4/7$.

**Decoding.** Write $\mathbf y = \mathbf z \oplus \boldsymbol\epsilon$ with $\boldsymbol\epsilon$ the noise vector ($\epsilon_i = 1$ if bit $i$ flipped). For a BSC, $P(\boldsymbol\epsilon) = f^{m(\boldsymbol\epsilon)}(1-f)^{7 - m(\boldsymbol\epsilon)}$, which (for $f < 1/2$) decreases with the number of flips $m(\boldsymbol\epsilon)$. Hence the MAP decoder picks **the codeword closest to $\mathbf y$ in Hamming distance**:
$$\hat{\mathbf z} = \mathbf y \oplus \arg\min_{\boldsymbol\epsilon : \mathbf y \oplus \boldsymbol\epsilon \in \text{codebook}} m(\boldsymbol\epsilon).$$
This is done efficiently with the **parity-check matrix**
$$H = \begin{pmatrix} P & I_3 \end{pmatrix} = \begin{pmatrix} 1&1&1&0&1&0&0 \\ 0&1&1&1&0&1&0 \\ 1&1&0&1&0&0&1 \end{pmatrix}, \qquad H G = 0 \pmod 2 .$$
The **syndrome** $\mathbf s = H\mathbf y = H(\mathbf z \oplus \boldsymbol\epsilon) = H\boldsymbol\epsilon$ depends only on the noise. A flip of bit $i$ produces the syndrome equal to the $i$-th column of $H$; all seven columns are distinct and non-zero, so the seven single-flip patterns are in one-to-one correspondence with the seven non-zero syndromes:

| syndrome | 000 | 001 | 010 | 100 | 011 | 101 | 110 | 111 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| unflip | none | $z_7$ | $z_6$ | $z_5$ | $z_4$ | $z_1$ | $z_3$ | $z_2$ |

(A flip in a source bit $z_1..z_4$ violates at least two checks; a flip in a parity bit violates exactly one.)

*Worked example.* Source $1000$ → codeword $1000\,101$. Suppose bit 3 flips: $\mathbf y = 1010\,101$. Then $s_1 = y_1 \oplus y_2 \oplus y_3 \oplus y_5 = 1$, $s_2 = y_2 \oplus y_3 \oplus y_4 \oplus y_6 = 1$, $s_3 = y_1 \oplus y_2 \oplus y_4 \oplus y_7 = 0$: syndrome $110$ → unflip $z_3$, recovering $1000$.

Decoding fails only when two or more bits flip in a block, so the block error is $P_B = 1 - (1-f)^7 - 7f(1-f)^6 \approx \binom72 f^2 = 21 f^2$ for small $f$ (exactly $0.15$ at $f = 0.1$). The error is **$O(f^2)$, as for $R_3$, but at rate $4/7$** rather than $1/3$.
:::

### How good can a code be?

We want both large $R$ and small $P_e$. Repetition codes suggest that $P_e \to 0$ forces $R \to 0$. Shannon's surprise is that this is false: **$P_e$ can be made arbitrarily small at any rate below a finite threshold, the capacity.**

::: {.definition name="Channel capacity"}
The **capacity** of a channel is the maximal mutual information between input and output, over all input distributions:
$$C = \max_{p_Z} I(Z; Y).$$
:::

For a noiseless channel $I(Z;Y) = H(Z)$ and $C = \max H(Z) = \log|\mathcal A_Z|$, consistent with the source coding theorem.

::: {.example name="Capacity of the BSC"}
With $p_0 = P(Z = 0)$, the output is Bernoulli with $P(Y = 1) = p_0 f + (1 - p_0)(1 - f)$, and $H(Y \mid Z) = h_2(f)$ whatever the input. So
$$I(Z; Y) = h_2\bigl(p_0 f + (1-p_0)(1-f)\bigr) - h_2(f),$$
maximised at $p_0 = 1/2$ where the output is uniform:
$$C_{\text{BSC}} = 1 - h_2(f).$$
For $f = 0.1$, $C \approx 0.53$: reliable communication is possible at about half a bit per use — far better than the $R \to 0$ of repetition codes.
:::

::: {.example name="Capacity of the BEC"}
$H(Y) = h_2(\varepsilon) + (1-\varepsilon)h_2(p_0)$ and $H(Y \mid Z) = h_2(\varepsilon)$, so $I = (1-\varepsilon) h_2(p_0)$ and $C_{\text{BEC}} = 1 - \varepsilon$: each non-erased symbol conveys one bit.
:::

::: {.example name="The noisy typewriter"}
The alphabet is $\{A, B, \ldots, Z, -\}$ (27 symbols, arranged in a circle so that $-$ precedes $A$). Each input is received as itself, its predecessor or its successor, each with probability $1/3$ — an inaccurate typewriter hitting neighbouring keys:
$$P(Y = A \mid Z = B) = P(Y = B \mid Z = B) = P(Y = C \mid Z = B) = \tfrac13, \ \text{etc.}$$
Since $H(Y \mid Z) = \log 3$ for every input, $I(Z;Y) = H(Y) - \log 3$, maximised when $Y$ (hence $Z$) is uniform: $H(Y) = \log 27 = 3\log 3$ and
$$C = 3\log 3 - \log 3 = 2\log 3 = \log 9 \approx 3.17 \text{ bits}.$$
The capacity is achieved *with zero error* by using only every third letter, $S = \{B, E, H, K, N, Q, T, W, Z\}$: the output sets $\{A,B,C\}, \{D,E,F\}, \ldots$ are disjoint, so these 9 codewords are non-confusable, and $R = \log 9$ per use. In this case $n_Z \cdot n_{Y|Z} = 9 \times 3 = 27 = n_Y$, so $H(Z \mid Y) = 0$.
:::

The noisy typewriter is special: non-confusable codewords exist for a single use. Shannon's insight is that *every* channel looks like a noisy typewriter if we use it $n$ times and $n$ is large.

## The noisy-channel coding theorem

::: {.definition name="Block code"}
A $(K, n)$ **block code** is a list of $2^K$ codewords $S = \{\mathbf z_1, \ldots, \mathbf z_{2^K}\} \subset \mathcal A_Z^n$, used to encode $2^K$ messages; its rate is $R = K/n$. A decoder maps $\mathcal A_Y^n \to S$. The **block error probability** is $P_B = P(D(\mathbf Y) \neq \mathbf Z)$, and the **maximal block error probability** is $P_B^{\max} = \max_{\mathbf z \in S} P(D(\mathbf Y) \neq \mathbf z \mid \mathbf Z = \mathbf z)$.
:::

The repetition code $R_n$ is a $(1, n)$ block code; the Hamming code is a $(4, 7)$ code.

::: {.theorem name="Shannon's noisy-channel coding theorem"}
For a discrete memoryless channel with capacity $C = \max_{p_Z} I(Z;Y)$:

1. **(Achievability)** For every $\delta > 0$ and $\beta > 0$, for $n$ large enough there exists a block code of length $n$ and rate $R \geq C - \beta$, with a decoder whose maximal block error probability is below $\delta$.
2. **(Converse)** No sequence of codes with rate $R > C$ has error probability tending to zero.
:::

### The intuition: every channel is a noisy typewriter

1. Use the channel $n$ times. For large $n$, the input $\mathbf z$ is (with high probability) typical, one of about $2^{nH(Z)}$ sequences.
2. The output $\mathbf y$ is typical, one of about $2^{nH(Y)}$ sequences.
3. The pair $(\mathbf z, \mathbf y)$ is **jointly typical**, one of about $2^{nH(Z,Y)}$ pairs.
4. Hence, for a given input $\mathbf z$, the output is essentially one of $2^{nH(Z,Y) - nH(Z)} = 2^{nH(Y \mid Z)}$ sequences — a "fan" of possible outputs.
5. If we use $2^{nR}$ codewords, their fans are (nearly) disjoint — non-confusable — only if they fit in the output space: $2^{nR}\,2^{nH(Y\mid Z)} \leq 2^{nH(Y)}$, i.e.
$$R \leq H(Y) - H(Y \mid Z) = I(Z;Y) \leq C .$$
6. Conversely, choosing codewords at random among typical inputs and decoding by joint typicality achieves any $R < C$ with vanishing error.

### Joint typicality

::: {.definition name="Jointly typical sequences"}
Given $p(z, y)$, the jointly typical set $T_{n\beta}[Z, Y]$ is the set of pairs $(\mathbf z, \mathbf y)$ such that
$$\Bigl|-\tfrac{1}{n}\log p(\mathbf z) - H(Z)\Bigr| < \beta,\quad \Bigl|-\tfrac{1}{n}\log p(\mathbf y) - H(Y)\Bigr| < \beta,\quad \Bigl|-\tfrac{1}{n}\log p(\mathbf z, \mathbf y) - H(Z, Y)\Bigr| < \beta .$$
:::

::: {.lemma name="Joint AEP"}
Let $(\mathbf Z, \mathbf Y)$ be drawn i.i.d. from $p(z, y)$. As $n \to \infty$:

1. $P\bigl((\mathbf Z, \mathbf Y) \in T_{n\beta}\bigr) \to 1$;
2. $|T_{n\beta}[Z, Y]| \leq 2^{n(H(Z,Y) + \beta)}$;
3. if $\tilde{\mathbf Z}$ and $\tilde{\mathbf Y}$ are drawn **independently** from the marginals $p(\mathbf z)$ and $p(\mathbf y)$, then
$$P\bigl((\tilde{\mathbf Z}, \tilde{\mathbf Y}) \in T_{n\beta}\bigr) \leq 2^{-n(I(Z;Y) - 3\beta)} .$$
:::

::: {.proof}
(1) and (2) follow exactly as for the single-variable AEP. For (3), every jointly typical pair has $p(\mathbf z) \leq 2^{-n(H(Z) - \beta)}$ and $p(\mathbf y) \leq 2^{-n(H(Y) - \beta)}$, so
$$P = \sum_{(\mathbf z, \mathbf y) \in T_{n\beta}} p(\mathbf z)\,p(\mathbf y) \leq 2^{n(H(Z,Y) + \beta)}\,2^{-n(H(Z) - \beta)}\,2^{-n(H(Y) - \beta)} = 2^{-n(I(Z;Y) - 3\beta)} .$$
:::

Property 3 is the heart of the theorem: **two independently drawn sequences almost never look jointly typical**; the probability of a "spurious match" is exponentially small in $nI(Z;Y)$.

### Random coding and typical-set decoding

::: {.proof name="Proof of achievability"}
Fix $p_Z$ achieving the capacity.

*Random coding.* Draw $2^K = 2^{nR}$ codewords $\mathbf z_1, \ldots, \mathbf z_{2^K}$ independently, each i.i.d. from $p_Z$.

*Typical-set decoding.* On receiving $\mathbf y$, output the codeword $\mathbf z'$ that is jointly typical with $\mathbf y$; if there is none, or more than one, declare failure.

The error of a given codebook $S$, $r(S)$, is hard to compute. **Shannon's trick is to average over all codebooks.** By symmetry the averaged error equals the error when message 1 is sent:
$$\langle r(S) \rangle_S = P(\mathbf z' \neq \mathbf z_1).$$
When $\mathbf z_1$ is sent and $\mathbf y$ is received, an error occurs only if

- $E_1$: $\mathbf z_1$ is not jointly typical with $\mathbf y$. Since $(\mathbf z_1, \mathbf y)$ is drawn from the joint distribution, by the joint AEP $P(E_1) < \delta/2$ for large $n$;
- $E_2$: some other codeword $\mathbf z_i$, $i \geq 2$, is jointly typical with $\mathbf y$. Each $\mathbf z_i$ is independent of $\mathbf y$, so by the union bound and property 3,
$$P(E_2) \leq \sum_{i=2}^{2^{nR}} P\bigl((\mathbf z_i, \mathbf y) \in T_{n\beta}\bigr) \leq 2^{nR}\,2^{-n(I(Z;Y) - 3\beta)} = 2^{-n(C - R - 3\beta)} .$$
This is smaller than $\delta/2$ for large $n$ provided $R < C - 3\beta$.

Hence $\langle r(S)\rangle_S \leq P(E_1) + P(E_2) < \delta$. **Since the average over codebooks is below $\delta$, at least one codebook $S^*$ has $r(S^*) < \delta$.**

*From average to maximal error (expurgation).* $r(S^*)$ is an average over messages. At most half the codewords can have error above $2\delta$; discard them. The remaining $2^{nR - 1}$ codewords have maximal error $< 2\delta$ and rate $R - 1/n$, which is still $\geq C - \beta'$ for large $n$. Since $\beta, \delta$ are arbitrary, the theorem follows.
:::

::: {.remark}
The genius of the proof is to show existence by averaging. A random codebook is bad in ways that are hard to analyse, but the *ensemble* has good average behaviour — so at least one codebook is at least as good as the average. In fact almost all random codebooks are good; the hard part is decoding them efficiently (typical-set decoding of a random code takes time exponential in $n$).
:::

### The converse: Fano's inequality

::: {.theorem name="Fano's inequality"}
Let $X$ take values in $\mathcal X$ and let $\hat X = g(Y)$ be any estimate of $X$ from $Y$, with $P_e = P(\hat X \neq X)$. Then
$$H(X \mid Y) \leq H(X \mid \hat X) \leq h_2(P_e) + P_e\log_2(|\mathcal X| - 1).$$
:::

Fano's inequality says that small error forces small residual uncertainty; contrapositively, if $H(X \mid Y)$ is large, every estimator errs often.

::: {.proof name="Proof sketch of the converse"}
Send a uniformly chosen message $W \in \{1, \ldots, 2^{nR}\}$, so $H(W) = nR$. Then
$$nR = H(W) = H(W \mid \mathbf Y) + I(W; \mathbf Y) \leq \bigl(1 + P_e\,nR\bigr) + I(\mathbf Z; \mathbf Y) \leq 1 + P_e\,nR + nC,$$
using Fano, the data-processing inequality ($W \to \mathbf Z \to \mathbf Y$) and memorylessness ($I(\mathbf Z; \mathbf Y) \leq \sum_i I(Z_i; Y_i) \leq nC$). Dividing by $n$: $R \leq C + 1/n + P_e R$, i.e. $P_e \geq 1 - C/R - 1/(nR)$. If $R > C$ the error is bounded away from zero.
:::

::: {.proposition name="Random-coding exponent"}
For $R < C$ the average error over random codebooks decays exponentially, $\bar P_e \leq 2^{-nE_r(R)}$, where $E_r(R) > 0$ is Gallager's random-coding exponent. It quantifies how large $n$ must be for a given target error.
:::

## Structured codes

The random-coding proof does not construct a practical code; it shows one exists. Practical coding needs structured codes with fast decoders.

- **Repetition codes**: rate $1/K$, error $\sim 2^{-KD(1/2\|f)}$. A baseline.
- **Hamming codes**: rate $4/7$, single-error correcting; the first *algebraic* (linear) codes.
- **Modern codes** — LDPC (Gallager 1962), turbo codes (Berrou et al. 1993), polar codes (Arıkan 2009) — approach capacity within fractions of a dB and are decoded in (near-)linear time by *message passing*, i.e. approximate Bayesian inference on a graph. Their invention represents sixty years of work catching up with Shannon.

## Exercises

::: {.exercise}
Compute the capacity of the Z-channel: $\mathcal A_Z = \mathcal A_Y = \{0, 1\}$, $p(0 \mid 0) = 1$, $p(0 \mid 1) = q$, $p(1 \mid 1) = 1 - q$.
:::

::: {.solution}
Let $P(Z = 1) = \pi$. Then $P(Y = 1) = \pi(1 - q)$, $H(Y \mid Z) = \pi h_2(q)$, and $I = h_2(\pi(1-q)) - \pi h_2(q)$. Setting $dI/d\pi = 0$ gives the optimum, and the capacity has the closed form $C = \log_2\bigl(1 + (1-q)\,q^{q/(1-q)}\bigr)$. For $q = 0.5$: $C = \log_2(1.25) \approx 0.322$ bits per use, at $\pi \approx 0.4$. Compare the BSC with $f = 0.5$, whose capacity is zero: the Z-channel's asymmetry ("0" is never corrupted) keeps it useful.
:::

::: {.exercise}
Prove Fano's inequality using the error indicator $E = \mathbf 1[\hat X \neq X]$.
:::

::: {.solution}
Expand $H(E, X \mid \hat X)$ in two ways. First, $H(E, X \mid \hat X) = H(X \mid \hat X) + H(E \mid X, \hat X) = H(X \mid \hat X)$, since $E$ is a function of $(X, \hat X)$. Second, $H(E, X \mid \hat X) = H(E \mid \hat X) + H(X \mid E, \hat X) \leq h_2(P_e) + P_e\log_2(|\mathcal X| - 1)$: conditioning reduces entropy ($H(E \mid \hat X) \leq H(E) = h_2(P_e)$); if $E = 0$ then $X = \hat X$ and there is no uncertainty; if $E = 1$, $X$ is one of the remaining $|\mathcal X| - 1$ values. Finally $H(X \mid Y) \leq H(X \mid \hat X)$ by data processing.
:::

::: {.exercise}
For the repetition code $R_5$ on a BSC with $f = 0.1$, compute $P_e$ and compare with $R_3$.
:::

::: {.solution}
Error iff $\geq 3$ flips: $P_e = \binom53 f^3(1-f)^2 + \binom54 f^4(1-f) + f^5 = 10(0.001)(0.81) + 5(0.0001)(0.9) + 10^{-5} \approx 0.0081 + 0.00045 + 0.00001 \approx 0.0086$. $R_3$ had $0.028$ at rate $1/3$; $R_5$ has $0.0086$ at rate $1/5$. Each factor $\sim 3$ improvement costs a big drop in rate.
:::

::: {.exercise}
In the Hamming (7,4) code, the received word is $\mathbf y = 0110\,110$. Decode it.
:::

::: {.solution}
$s_1 = y_1 \oplus y_2 \oplus y_3 \oplus y_5 = 0 \oplus 1 \oplus 1 \oplus 1 = 1$; $s_2 = y_2 \oplus y_3 \oplus y_4 \oplus y_6 = 1 \oplus 1 \oplus 0 \oplus 1 = 1$; $s_3 = y_1 \oplus y_2 \oplus y_4 \oplus y_7 = 0 \oplus 1 \oplus 0 \oplus 0 = 1$. Syndrome $111$ → flip $z_2$: $\hat{\mathbf z} = 0010\,110$. Check: $z_5 = 0 \oplus 0 \oplus 1 = 1$, $z_6 = 0 \oplus 1 \oplus 0 = 1$, $z_7 = 0 \oplus 0 \oplus 0 = 0$ $\checkmark$. Decoded message: $0010$.
:::

## Callouts

::: {.callout-note}
The noisy-channel coding theorem gives mutual information its operational meaning: $\max I(Z;Y)$ is the maximum rate of reliable communication. Decoding is inference, and the optimal decoder under 0–1 loss is MAP.
:::

::: {.callout-tip}
For a symmetric channel (every row of $p(y\mid z)$ a permutation of every other, and likewise columns) the capacity is achieved by the uniform input and equals $\log|\mathcal A_Y| - H(\text{row})$. BSC, BEC-like and noisy typewriter examples all follow from this.
:::

::: {.callout-warning}
Shannon's theorem is an existence result. Constructing capacity-achieving codes with efficient decoders was an open problem for decades.
:::

::: {.callout-important}
The capacity $C$ is an asymptotic (long-block) quantity. At finite block length the achievable rate is lower, roughly $C - \sqrt{V/n}\,Q^{-1}(\epsilon)$ (Polyanskiy, Poor & Verdú 2010).
:::
