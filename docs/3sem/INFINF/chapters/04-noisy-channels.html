5  Noisy channels and coding

Shannon’s second big theorem answers a complementary question: given a noisy channel, what is the maximum rate at which information can be transmitted with vanishing error probability? The answer is the channel capacity \(C = \max_{p(x)} I(X; Y)\), and its achievability is proved by the beautiful random-coding argument.

5.1 Decoding as inference

Consider a channel \(p(y \mid x)\): an input symbol \(x\) is transmitted and a possibly-corrupted output \(y\) is observed. The decoder’s task is to infer what was sent given what was received.

A discrete memoryless channel (DMC) is a triple \((\mathcal X, \mathcal Y, p(y \mid x))\): input alphabet \(\mathcal X\), output alphabet \(\mathcal Y\), and a conditional distribution \(p(y \mid x)\). Memoryless means for a length-\(n\) transmission, \[p(y^n \mid x^n) = \prod_{i=1}^{n} p(y_i \mid x_i).\]

The BSC with crossover probability \(q \in [0, 1/2]\) has \(\mathcal X = \mathcal Y = \{0, 1\}\) and \(p(1 \mid 0) = p(0 \mid 1) = q\). It flips each bit independently with probability \(q\).

The BEC with erasure probability \(\varepsilon\) has \(\mathcal Y = \{0, 1, ?\}\) and \(p(? \mid x) = \varepsilon\), \(p(x \mid x) = 1 - \varepsilon\). Each input is either received correctly or lost — but never silently corrupted.

5.2 Error-correcting codes

The idea of coding is to send a codeword \(\mathbf x = (x_1, \ldots, x_n)\) chosen from a codebook \(\mathcal C \subset \mathcal X^n\) of size \(|\mathcal C| = 2^{nR}\), so the code rate is \(R = (\log_2 |\mathcal C|)/n\) bits per channel use. On the receiver side, a decoder \(g : \mathcal Y^n \to \mathcal C\) maps the received sequence back to a codeword.

A rate \(R\) is achievable on channel \(p(y \mid x)\) if there exists a sequence of codes \(\{\mathcal C_n\}\) of size \(\lfloor 2^{nR}\rfloor\) and decoders \(\{g_n\}\) such that the maximal error probability \[\lambda^{(n)} = \max_{\mathbf x \in \mathcal C_n} P\bigl(g_n(Y^n) \neq \mathbf x \mid X^n = \mathbf x\bigr)\] tends to zero as \(n \to \infty\). The capacity \(C\) is the supremum of achievable rates.

5.3 The noisy-channel coding theorem

For a discrete memoryless channel, \[C = \max_{p(x)} I(X; Y).\] Any rate \(R < C\) is achievable, and any rate \(R > C\) is not.

Proof idea (achievability). Fix an input distribution \(p(x)\) achieving \(I(X; Y)\). Generate a random codebook of \(2^{nR}\) i.i.d. \(\sim p^{\otimes n}\) codewords. Decode by joint typicality: given \(Y^n\), output the unique codeword \(\hat X^n\) such that \((X^n, Y^n) \in A_\varepsilon^{(n)}\). The average error probability, averaged over both the message and the random codebook, tends to zero for \(R < C - 2\varepsilon\). Then expurgate half the codebook to get a code with maximal error probability tending to zero.

Proof idea (converse). Use Fano’s inequality: \(H(\mathbf X \mid \hat{\mathbf X}) \leq 1 + P_e \cdot nR\), which combined with data processing gives \(nR \leq nC + 1 + nRP_e\), so \(R \leq C\) if \(P_e \to 0\).

For the BSC with crossover \(q\), the capacity is \(C = 1 - h_2(q)\), achieved by uniform \(p(x)\). For the BEC with erasure \(\varepsilon\), \(C = 1 - \varepsilon\): each non-erased symbol conveys one bit.

5.4 Fano’s inequality

Let \(X\) take values in \(\mathcal X\) and let \(\hat X\) be an estimate of \(X\) from any random variable \(Y\). Let \(P_e = P(\hat X \neq X)\). Then \[H(X \mid Y) \leq H(X \mid \hat X) \leq h_2(P_e) + P_e\log_2(|\mathcal X| - 1).\]

Fano’s inequality lower-bounds the error probability of any estimator: if \(P_e\) is small then \(H(X \mid Y)\) must be small too. It is the fundamental tool for converse coding theorems throughout the notes.

Combining Fano with the data-processing inequality yields the converse of the noisy-channel coding theorem: any code with rate above capacity has average error probability bounded away from zero.

5.5 Random coding

The genius of Shannon’s proof is to show existence by averaging. The typical codebook is bad in ways that are hard to see, but the ensemble of codebooks has good average behaviour — so at least one codebook must be at least as good as the average.

For \(R < C\), the average error probability over random codebooks decays exponentially in \(n\): \[\bar P_e \leq 2^{-n(E_r(R))},\] where \(E_r(R) > 0\) for \(R < C\) is Gallager’s random-coding exponent. This gives the sharp asymptotic rate of convergence, not just the fact that it holds.

Remark. The random-coding exponent is what makes Shannon’s theorem quantitative: it tells you how large \(n\) has to be for a given target error. Modern coding theory is largely the search for structured codes that meet or approach the random-coding exponent with efficient encoders and decoders (turbo codes, LDPC, polar codes).

5.6 Typical-set decoding

Given \(p(x, y)\), the jointly typical set \(A_\varepsilon^{(n)}(X, Y)\) is \[\Bigl\{ (x^n, y^n) : |\!-\tfrac{1}{n}\log p(x^n) - H(X)| < \varepsilon,\ |\!-\tfrac{1}{n}\log p(y^n) - H(Y)| < \varepsilon,\ |\!-\tfrac{1}{n}\log p(x^n, y^n) - H(X, Y)| < \varepsilon \Bigr\}.\]

As \(n \to \infty\): (i) \(P((X^n, Y^n) \in A_\varepsilon^{(n)}) \to 1\); (ii) \(|A_\varepsilon^{(n)}(X, Y)| \leq 2^{n(H(X,Y) + \varepsilon)}\); (iii) if \((\tilde X^n, \tilde Y^n)\) are drawn independently from the marginals, then \(P((\tilde X^n, \tilde Y^n) \in A_\varepsilon^{(n)}) \leq 2^{-n(I(X;Y) - 3\varepsilon)}\).

Property (iii) is the key to the noisy-channel coding theorem: it says that if you draw two random \(n\)-sequences from the marginals, they almost never look typical together — the probability of a “spurious match” is exponentially small in \(nI(X; Y)\).

5.7 Structured codes

The random-coding proof does not construct a specific code; it shows one exists. Practical coding requires structured codes with fast decoders.

Send each bit \(n\) times, majority-decode. For a BSC\((q)\) this has rate \(R = 1/n\) and error probability \(\sim \exp(-n D(1/2 \| q))\). Poor rate but easy analysis; a textbook baseline.

Four data bits, three parity bits, minimum distance \(3\): corrects any single error in a block of \(7\). Rate \(R = 4/7\); a first example of an algebraic code that meets the Singleton bound.

Modern codes — LDPC (Gallager 1962), turbo codes (Berrou et al. 1993), polar codes (Arıkan 2009) — approach capacity within fractions of a dB and are decoded in polynomial time. Their invention represents 60 years of work catching up with Shannon.

5.8 Exercises

Compute the capacity of the Z-channel: \(\mathcal X = \mathcal Y = \{0, 1\}\), \(p(0 \mid 0) = 1\), \(p(0 \mid 1) = q\), \(p(1 \mid 1) = 1 - q\).

Solution. Let the input distribution be \(p(0) = \alpha\), \(p(1) = 1 - \alpha\). Then \(H(Y \mid X) = (1 - \alpha) h_2(q)\) and \(H(Y) = h_2(\alpha + (1-\alpha)q)\) (Bernoulli output). Maximise \(I = H(Y) - H(Y \mid X)\) over \(\alpha\). The optimum satisfies a transcendental equation solvable numerically; e.g. for \(q = 0.5\) the capacity is \(\approx 0.322\) bit per channel use, less than the BSC\((0.5)\) capacity (which is zero) — the Z-channel is asymmetric and therefore useful even at large error rates.

Prove Fano’s inequality using the identity \(H(X, \hat X) = H(\hat X) + H(X \mid \hat X)\) and a careful decomposition of \(H(X \mid \hat X)\) into “the error event” and “given the error event”.

Solution. Introduce indicator \(E = \mathbf 1[\hat X \neq X]\). Then \(H(E, X \mid \hat X) = H(E \mid \hat X) + H(X \mid E, \hat X) \leq h_2(P_e) + P_e \log_2(|\mathcal X| - 1)\) (given error, \(X\) is one of the \(|\mathcal X| - 1\) remaining values). Since \(H(X \mid \hat X) \leq H(E, X \mid \hat X)\), the inequality follows.

5.9 Callouts

The noisy-channel coding theorem is the result of information theory: it establishes an operational meaning of mutual information as the maximum rate of reliable communication.

For an asymmetric channel it is often useful to first find \(p(x)\) that maximises \(I(X; Y)\) numerically, then compute the resulting capacity. Symmetric channels admit closed-form solutions.

Shannon’s theorem is an existence result. Constructing capacity-achieving codes was an open problem for decades; even now the practical gap is a few tenths of a dB for high-noise regimes.

The capacity \(C\) is an asymptotic (long-block) quantity. Finite-block coding has a lower achievable rate, characterised by the finite-block-length coding bounds of Polyanskiy, Poor & Verdú (2010).
