10  A problem of high-dimensional inference

This chapter works through a real research problem that ties together everything in Chapters 7–8: building a likelihood with latent variables, choosing conjugate priors, discovering that the exact posterior is a combinatorial monster, and sampling it with Metropolis and Gibbs. The problem comes from population genetics: Gaggiotti et al. (2002) studied how new colonies of grey seals are founded, and asked where the founders came from, using only the genomes of pups born in the new colony.

10.1 The problem

Grey seals live in isolated colonies; occasionally a new colony is founded by migrants from older ones. Assume the founders come from \(P\) old colonies, in unknown proportions \[\mathbf x = (x_1, \ldots, x_P), \qquad x_i \geq 0, \quad \sum_{i=1}^P x_i = 1 .\] \(\mathbf x\) is the unknown we want to infer: a point in the \((P-1)\)-dimensional simplex.

The data: \(N = 150\) pups born in the new colony (whose parents were migrants) were genotyped at \(L = 9\) loci, chosen among the most variable ones to maximise discrimination. At each locus an individual carries two variants (alleles) of the gene, one inherited from the mother (\(n = 1\)) and one from the father (\(n = 2\)), each among \(M_l\) possible alleles. Taking \(M = \max_l M_l\) (and assigning zero frequency to non-existent alleles), the data are \[y_{k,l,n} \in \{1, \ldots, M\}, \qquad k = 1..N \text{ (individual)},\ l = 1..L \text{ (locus)},\ n = 1, 2 \text{ (parent)}.\] What links \(\mathbf x\) to \(\mathbf y\) is that the allele frequencies in the old colonies are known from previous studies: \[p_m^{(i,l)} = \text{frequency of allele } m \text{ at locus } l \text{ in colony } i, \qquad \sum_m p_m^{(i,l)} = 1 .\] Different colonies have different allele frequencies, so a pup’s genotype carries (weak) information about where its parents came from; with many pups and loci, this adds up to information about \(\mathbf x\).

10.2 Basic model

We first study a simplified model in which only the maternal alleles are observed: data \(y_{k,l} \equiv y_{k,l,1}\).

10.2.1 Likelihood

Introduce a latent variable for each pup, \[Z_k \in \{1, \ldots, P\}: \text{ the colony the mother of pup } k \text{ came from.}\] Two modelling assumptions connect the variables:

  • the probability of inheriting allele \(m\) at locus \(l\) from a mother of colony \(i\) is the frequency of that allele in colony \(i\): \[P(Y_{k,l} = m \mid Z_k = i) = p_m^{(i,l)};\]
  • the probability that a mother came from colony \(i\) is the proportion of founders from colony \(i\): \[P(Z_k = i \mid \mathbf x) = x_i .\]

Marginalising the latent variable, and using that \(Y_{k,l}\) depends on \(\mathbf x\) only through \(Z_k\) (conditional independence), \[P(Y_{k,l} = m \mid \mathbf x) = \sum_{i=1}^P P(Y_{k,l} = m \mid Z_k = i)P(Z_k = i \mid \mathbf x) = \sum_{i=1}^P x_i\,p_m^{(i,l)} .\] Assuming further that the alleles at different loci are independent given the origin (a simplification — probably not exactly true for real genomes), \[P(\mathbf Y_k = \mathbf y_k \mid Z_k = i) = \prod_{l=1}^L p^{(i,l)}_{y_{k,l}} \equiv \gamma_{ik}, \qquad P(\mathbf Y_k = \mathbf y_k \mid \mathbf x) = \sum_{i=1}^P x_i\,\gamma_{ik}.\] \(\gamma_{ik}\) is the likelihood that pup \(k\)’s maternal genotype came from colony \(i\). Assuming independent individuals, the full likelihood is \[P(\mathbf Y = \mathbf y \mid \mathbf x) = \prod_{k=1}^N\sum_{i=1}^P x_i\,\gamma_{ik} = \prod_{k=1}^N\sum_{i=1}^P x_i\prod_{l=1}^L p^{(i,l)}_{y_{k,l}} .\] This is a mixture model of exactly the type of Chapter 8: each pup is drawn from one of \(P\) “components” (colonies) with weights \(\mathbf x\), but the component distributions \(\gamma_{ik}\) are known.

10.2.2 Prior: the Dirichlet distribution

The likelihood is a polynomial in \(\mathbf x\), so the natural (conjugate) prior on the simplex is the Dirichlet distribution.

\(\mathbf x \sim \text{Dir}(\boldsymbol\alpha)\), \(\alpha_i > 0\), has density on the simplex \(\mathcal D = \{\mathbf x : x_i \geq 0, \sum_i x_i = 1\}\) \[\text{Dir}(\boldsymbol\alpha; \mathbf x) = \frac{1}{B(\boldsymbol\alpha)}\prod_{i=1}^P x_i^{\alpha_i - 1}, \qquad B(\boldsymbol\alpha) = \frac{\Gamma(\alpha_1)\cdots\Gamma(\alpha_P)}{\Gamma(\alpha_1 + \cdots + \alpha_P)} .\] With \(\alpha_0 = \sum_i\alpha_i\): \(\mathbb E[x_i] = \alpha_i/\alpha_0\) and \(\operatorname{Var}[x_i] = \alpha_i(\alpha_0 - \alpha_i)/\bigl(\alpha_0^2(\alpha_0 + 1)\bigr)\). For \(P = 2\) it reduces to the Beta distribution. \(\boldsymbol\alpha = (1, \ldots, 1)\) is uniform on the simplex; large \(\alpha_0\) concentrates the mass around the mean.

The key integral, used repeatedly below, is just the normalisation: \[\int_{\mathcal D} d\mathbf x\,\prod_i x_i^{\beta_i - 1} = B(\boldsymbol\beta).\]

The posterior is \[P(\mathbf x \mid \mathbf y) = \frac{1}{P(\mathbf y)}\prod_{k=1}^N\Bigl(\sum_{i=1}^P x_i\gamma_{ik}\Bigr)\cdot\frac{1}{B(\boldsymbol\alpha)}\prod_{p=1}^P x_p^{\alpha_p - 1},\] with evidence \(P(\mathbf y) = \int_{\mathcal D} d\mathbf x\,(\text{numerator})\), an integral over the simplex.

10.2.3 Metropolis approach

Metropolis only needs the unnormalised posterior. A simple proposal moves \(\mathbf x\) by a small random step and then projects back onto the simplex: \[\mathbf x \;\to\; \mathbf x + \mathbf u \;\to\; b_{0,1}(\mathbf x + \mathbf u) \;\to\; \frac{b_{0,1}(\mathbf x + \mathbf u)}{\sum_i b_{0,1}(x_i + u_i)} = \mathbf x', \qquad u_i \sim \mathcal U(-\epsilon, \epsilon),\] where \(b_{0,1}(x) = \min(\max(x, 0), 1)\) clips each component into \([0, 1]\). The acceptance probability is \[A(\mathbf x' \mid \mathbf x) = \min\Biggl\{1, \frac{\prod_k\bigl(\sum_i x'_i\gamma_{ik}\bigr)\prod_p (x'_p)^{\alpha_p - 1}}{\prod_k\bigl(\sum_i x_i\gamma_{ik}\bigr)\prod_p x_p^{\alpha_p - 1}}\Biggr\},\] in which the evidence and \(B(\boldsymbol\alpha)\) cancel. Each evaluation costs \(O(NP)\) operations (after precomputing \(\gamma_{ik}\), which costs \(O(NPL)\) once). In practice one works with log-probabilities to avoid underflow: \(\prod_k\) of 150 small numbers is far below double-precision range.

Remark (Is this proposal symmetric?). The clip-and-renormalise map is not exactly symmetric, so strictly a Hastings correction would be needed. Cleaner alternatives: (i) parametrise by \(P - 1\) free coordinates and reject proposals that leave the simplex (a symmetric proposal on a bounded domain is fine — out-of-domain proposals have \(\pi = 0\) and are simply rejected); (ii) propose \(\mathbf x' \sim \text{Dir}(c\,\mathbf x)\) with a large concentration \(c\) and include the Hastings ratio \(\text{Dir}(c\mathbf x'; \mathbf x)/\text{Dir}(c\mathbf x; \mathbf x')\).

10.2.4 Analytic expression of the posterior

The posterior can, in principle, be written in closed form. Expand the product of sums: \[\prod_{k=1}^N\Bigl(\sum_{i=1}^P x_i\gamma_{ik}\Bigr) = \sum_{i_1=1}^P\cdots\sum_{i_N=1}^P\ \prod_{k=1}^N x_{i_k}\gamma_{i_k k} = \sum_{\mathbf i}\ \prod_{k=1}^N x_{i_k}\gamma_{i_k k},\] where the multi-index \(\mathbf i = (i_1, \ldots, i_N)\) runs over all \(P^N\) assignments of pups to colonies — i.e. over all values of the latent variables \(\mathbf Z\). Let \(n_p(\mathbf i) = \sum_k\delta_{i_k p}\) count how many pups are assigned to colony \(p\). Then \(\prod_k x_{i_k} = \prod_p x_p^{n_p(\mathbf i)}\) and the numerator becomes \[\frac{1}{B(\boldsymbol\alpha)}\sum_{\mathbf i}\Bigl(\prod_k\gamma_{i_k k}\Bigr)\prod_p x_p^{n_p(\mathbf i) + \alpha_p - 1} = \sum_{\mathbf i}\xi(\mathbf i)\,\text{Dir}\bigl(\mathbf n(\mathbf i) + \boldsymbol\alpha; \mathbf x\bigr), \qquad \xi(\mathbf i) = \frac{B(\mathbf n(\mathbf i) + \boldsymbol\alpha)}{B(\boldsymbol\alpha)}\prod_{k=1}^N\gamma_{i_k k}.\] Since each Dirichlet integrates to one, the evidence is \(P(\mathbf y) = \sum_{\mathbf i}\xi(\mathbf i)\), and

\[P(\mathbf x \mid \mathbf y) = \sum_{\mathbf i}\zeta(\mathbf i)\,\text{Dir}\bigl(\mathbf n(\mathbf i) + \boldsymbol\alpha; \mathbf x\bigr), \qquad \zeta(\mathbf i) = \frac{\xi(\mathbf i)}{\sum_{\mathbf j}\xi(\mathbf j)} .\] Posterior moments follow from those of the Dirichlet, e.g. \[\mathbb E[x_p \mid \mathbf y] = \sum_{\mathbf i}\zeta(\mathbf i)\,\frac{n_p(\mathbf i) + \alpha_p}{\sum_q\bigl(n_q(\mathbf i) + \alpha_q\bigr)} = \sum_{\mathbf i}\zeta(\mathbf i)\,\frac{n_p(\mathbf i) + \alpha_p}{N + \alpha_0}.\]

The interpretation is transparent: for each hypothetical assignment \(\mathbf i\) of pups to colonies, the posterior on \(\mathbf x\) would be the conjugate \(\text{Dir}(\boldsymbol\alpha + \text{counts})\); the true posterior averages these over assignments, weighted by how well each assignment explains the genotypes.

Remark (Why the analytic formula is useless). The sum has \(P^N\) terms. With \(N = 150\) and \(P = 7\) (as in the study), that is \(7^{150} \approx 10^{127}\) terms — hopeless. This is a general feature of mixture models: marginalising the latent variables analytically is exponential in \(N\). Note, by contrast, that the factorised form \(\prod_k\sum_i x_i\gamma_{ik}\) costs only \(N \cdot P\) operations, which is why Metropolis on \(\mathbf x\) is perfectly feasible.

10.2.5 A simple example

To see the structure, consider \(P = 2\) colonies, \(M = 2\) alleles and two loci, “tail length” and “fin length”, with allele 1 = long and 2 = short. The known frequencies are \[p^{(1,1)} = p^{(1,2)} = \bigl(\tfrac23, \tfrac13\bigr), \qquad p^{(2,1)} = p^{(2,2)} = \bigl(\tfrac14, \tfrac34\bigr):\] in colony 1 two thirds of the individuals have long tails (and fins), in colony 2 only a quarter. We observe two alleles \((y_1, y_2)\), one per locus, and \(\mathbf x = (x_1, 1 - x_1)\). Following Allegra’s notes, take the likelihood to be \[P(y_1, y_2 \mid \mathbf x) = \prod_{l=1}^{2}\Bigl(\sum_{i=1}^2 x_i p^{(i,l)}_{y_l}\Bigr) = \sum_{i,j} x_ix_j\,p^{(i,1)}_{y_1}p^{(j,2)}_{y_2},\] i.e. each of the two alleles comes from an independently drawn founder. (This is equivalent to \(N = 2\) pups with \(L = 1\) locus each. For a single pup with two loci, the basic model would instead give \(\sum_i x_i\,p^{(i,1)}_{y_1}p^{(i,2)}_{y_2}\), linear in \(\mathbf x\), and the posterior would be a mixture of only two Beta components; see the exercises.) For the four possible observations this gives

\((y_1, y_2)\) \(P(y_1, y_2 \mid \mathbf x)\)
(long, long) \(\tfrac49 x_1^2 + \tfrac13 x_1x_2 + \tfrac1{16}x_2^2\)
(long, short), (short, long) \(\tfrac29 x_1^2 + \tfrac7{12} x_1x_2 + \tfrac3{16}x_2^2\)
(short, short) \(\tfrac19 x_1^2 + \tfrac12 x_1x_2 + \tfrac9{16}x_2^2\)

With a uniform prior (\(\alpha_1 = \alpha_2 = 1\)), each monomial \(x_1^a x_2^b\) is an unnormalised \(\text{Beta}(a+1, b+1)\) with integral \(B(a+1, b+1)\): \(\int x_1^2 = \tfrac13\), \(\int x_1x_2 = \tfrac16\), \(\int x_2^2 = \tfrac13\). For (long, long) the evidence is \(\tfrac{4}{27} + \tfrac{1}{18} + \tfrac{1}{48} = \tfrac{97}{432}\) and \[P(x_1 \mid \text{long, long}) = \tfrac{64}{97}\,\text{Beta}(x_1; 3, 1) + \tfrac{24}{97}\,\text{Beta}(x_1; 2, 2) + \tfrac{9}{97}\,\text{Beta}(x_1; 1, 3).\] Similarly

\((y_1, y_2)\) weight of Beta(3,1) Beta(2,2) Beta(1,3) \(\mathbb E[x_1 \mid y]\)
(long, long) 64/97 24/97 9/97 0.642
(long, short) or (short, long) 32/101 42/101 27/101 0.512
(short, short) 16/133 36/133 81/133 0.378

(using \(\mathbb E[x_1] = 3/4, 1/2, 1/4\) for the three Beta components). The three components correspond to the latent configurations “both founders from colony 1” (\(\mathbf n = (2,0)\)), “one from each” (\(\mathbf n = (1,1)\), two assignments) and “both from colony 2” (\(\mathbf n = (0, 2)\)), each giving a \(\text{Dir}(\mathbf n + \boldsymbol\alpha) = \text{Beta}\) component. Observing long features shifts belief towards colony 1, short features towards colony 2, and mixed features leave the prior mean \(1/2\) almost unchanged. With two alleles the posterior remains very broad: each observation carries little information, and precision comes only from many pups.

10.2.6 Gibbs sampling approach

The smart alternative to marginalising \(\mathbf Z\) is not to marginalise it, and to sample \(\mathbf Z\) jointly with \(\mathbf x\), exactly as for the Gaussian mixture of Chapter 8. Keeping the latent variables, \[P(\mathbf y \mid \mathbf Z) = \prod_{k=1}^N\gamma_{Z_k k}, \qquad P(\mathbf Z \mid \mathbf x) = \prod_{k=1}^N x_{Z_k} = \prod_{i=1}^P x_i^{m_i(\mathbf Z)}, \quad m_i(\mathbf Z) = \sum_k\delta(Z_k = i),\] so the joint posterior is \[P(\mathbf x, \mathbf Z \mid \mathbf y) = \frac{1}{P(\mathbf y)B(\boldsymbol\alpha)}\prod_{k=1}^N\gamma_{Z_kk}\ \prod_{i=1}^P x_i^{m_i(\mathbf Z) + \alpha_i - 1}.\] The full conditionals are standard:

Proportions. Only the last factor depends on \(\mathbf x\); normalising over the simplex, \[\mathbf x \mid \mathbf y, \mathbf Z \sim \text{Dir}\bigl(\boldsymbol\alpha + \mathbf m(\mathbf Z)\bigr):\] prior pseudo-counts plus the number of mothers currently assigned to each colony.

Origins. Only the factors \(\gamma_{Z_kk}\,x_{Z_k}\) depend on \(Z_k\), so \[P(Z_k = i \mid \mathbf y, \mathbf x, \mathbf Z_{-k}) = \frac{\gamma_{ik}\,x_i}{\sum_j\gamma_{jk}\,x_j}:\] Bayes’ theorem for “which colony did this mother come from?”, with prior \(\mathbf x\) and likelihood \(\gamma_{\cdot k}\). Given \(\mathbf x\), the \(Z_k\) are conditionally independent and can all be updated at once.

Repeat:

  1. sample \(\mathbf x \sim \text{Dir}(\boldsymbol\alpha + \mathbf m(\mathbf Z))\);
  2. for all \(k\), sample \(Z_k \sim \text{Cat}\bigl(\gamma_{\cdot k}\odot\mathbf x / \sum_j\gamma_{jk}x_j\bigr)\).

Each sweep costs \(O(NP)\) and requires no tuning. As a bonus, the samples of \(Z_k\) give the posterior probability that each pup’s mother came from each colony — an individual-level “assignment test”.

Remark (Data augmentation). The Gibbs sampler explores the joint space of \((\mathbf x, \mathbf Z)\), of dimension \(P - 1 + N\), which is larger than the space of \(\mathbf x\) alone. Yet it is easier to sample: the \(P^N\)-term sum is never computed; instead the chain visits the relevant assignments \(\mathbf i\) with frequency \(\propto\xi(\mathbf i)\). The marginal of \(\mathbf x\) in the samples is the exact mixture-of-Dirichlets posterior.

10.3 Refined model

The model actually used by Gaggiotti et al. is richer in three ways: both parents contribute alleles, parents tend to mate within their own origin, and the proportions \(\mathbf x\) are linked to the geography of the old colonies.

10.3.1 Two parents and assortative mating

Let \(Z_{k,n}\) be the origin of parent \(n\) of pup \(k\). As before, \[P(Y_{k,l,n} = m \mid Z_{k,n} = i) = p_m^{(i,l)}, \qquad P(\mathbf Y_{k,n} = \mathbf y_{k,n} \mid Z_{k,n} = i) = \prod_{l}p^{(i,l)}_{y_{k,l,n}} .\] If the two parents’ origins were independent, \(P(Z_{k,1} = i, Z_{k,2} = j \mid \mathbf x) = x_ix_j\), and (assuming the maternal and paternal alleles are independent given the origins) \[P(\mathbf Y = \mathbf y \mid \mathbf x) = \prod_{k=1}^N\sum_{i,j=1}^P x_ix_j\prod_{l=1}^L p^{(i,l)}_{y_{k,l,1}}p^{(j,l)}_{y_{k,l,2}} .\] But founders mate preferentially with individuals of the same origin (assortative mating). Model this with a parameter \(w \in [0,1]\): with probability \(w\) an individual mates with someone of its own origin, with probability \(1 - w\) with a random founder: \[P(Z_{k,1} = i, Z_{k,2} = j \mid \mathbf x, w) = w\,\delta_{ij}\,x_i + (1 - w)\,x_ix_j .\] Defining \(\gamma_{ijk} = \prod_l p^{(i,l)}_{y_{k,l,1}}p^{(j,l)}_{y_{k,l,2}}\), the likelihood becomes \[P(\mathbf Y = \mathbf y \mid \mathbf x, w) = \prod_{k=1}^N\Bigl[w\sum_{i=1}^P x_i\,\gamma_{iik} + (1 - w)\sum_{i,j=1}^P x_ix_j\,\gamma_{ijk}\Bigr].\] For \(w = 0\) we recover random mating; for \(w = 1\) both parents always share an origin.

10.3.2 Geography in the prior

Gaggiotti et al. further assume that the expected contribution of each old colony decays exponentially with its (known) distance \(\delta_i\) from the new colony and grows with its (known) productivity \(\pi_i\): \[\mathbb E[x_i] \propto \bigl((1 - S) + S\pi_i\bigr)e^{-R\delta_i},\] with an unknown distance decay \(R\) and productivity weight \(S\). This is built into the Dirichlet prior: \[\mathbf x \mid R, S, \alpha_0 \sim \text{Dir}(\boldsymbol\alpha), \qquad \alpha_i = \alpha_0\,\frac{\bigl((1 - S) + S\pi_i\bigr)e^{-R\delta_i}}{c}, \quad c = \sum_{i=1}^P\bigl((1 - S) + S\pi_i\bigr)e^{-R\delta_i},\] so that \(\mathbb E[x_i] = \alpha_i/\alpha_0\) has the desired form and \(\alpha_0\) controls how tightly \(\mathbf x\) follows it. The hyperparameters get uniform priors: \[\alpha_0 \sim \mathcal U(P, 100), \quad w \sim \mathcal U(0, 1), \quad S \sim \mathcal U(0, 1), \quad R \sim \mathcal U(0, 5).\] This is a hierarchical model: data ← \((\mathbf x, w)\) ← \((R, S, \alpha_0)\). The posterior is \[P(\mathbf x, w, \alpha_0, R, S \mid \mathbf y) \propto P(\mathbf y \mid \mathbf x, w)\,\text{Dir}(\boldsymbol\alpha(R, S, \alpha_0); \mathbf x)\,P(w)P(R)P(S)P(\alpha_0).\] Note that \(B(\boldsymbol\alpha)\) now depends on the hyperparameters and does not cancel in Metropolis ratios for \(R, S, \alpha_0\).

The posterior on \(R\) and \(S\) is the scientifically interesting output: do seals found colonies preferentially near their origin, and do productive colonies send more migrants?

10.3.3 Metropolis approach

Update the parameters one at a time (or in blocks) with bounded random-walk moves, \(u \sim \mathcal U(-\epsilon, \epsilon)\): \[\mathbf x \to \frac{b(\mathbf x + \mathbf u)}{\sum_i b(x_i + u_i)}, \quad w \to b_{0,1}(w + u), \quad S \to b_{0,1}(S + u), \quad R \to b_{0,5}(R + u), \quad \alpha_0 \to b_{P,100}(\alpha_0 + u),\] each accepted with the Metropolis ratio of the unnormalised posterior. (The remark on symmetry of clipped proposals applies here too.)

10.3.4 Gibbs sampling with latent variables

As in the basic model, we can keep the parental origins \(Z_{k,1}, Z_{k,2}\) as latent variables. To deal with the mixture in the mating model, introduce one more latent variable per pup, \[Q_k \in \{0, 1\}: \quad Q_k = 1 \text{ if the parents mated assortatively}, \quad P(Q_k = 1 \mid w) = w,\] with \[P(Z_{k,1}, Z_{k,2} \mid Q_k = 1, \mathbf x) = \delta_{Z_{k,1}Z_{k,2}}\,x_{Z_{k,1}}, \qquad P(Z_{k,1}, Z_{k,2} \mid Q_k = 0, \mathbf x) = x_{Z_{k,1}}x_{Z_{k,2}} .\] Summing over \(Q_k\) reproduces \(w\delta_{ij}x_i + (1-w)x_ix_j\). With a Beta prior \(w \sim \text{Beta}(\beta_1, \beta_2)\) (uniform for \(\beta_1 = \beta_2 = 1\)), the augmented posterior is \[P(\mathbf x, w, \mathbf Z, \mathbf Q \mid \mathbf y) \propto \prod_{k=1}^N\gamma_{Z_{k,1}Z_{k,2}k}\ \prod_{i=1}^P x_i^{m_i(\mathbf Z, \mathbf Q) + \alpha_i - 1}\ w^{n_q + \beta_1 - 1}(1 - w)^{N - n_q + \beta_2 - 1}\ \prod_{k : Q_k = 1}\delta_{Z_{k,1}Z_{k,2}},\] where \(n_q = \sum_k\delta(Q_k = 1)\) counts assortative matings and \[m_i(\mathbf Z, \mathbf Q) = \sum_{k=1}^N\Bigl[\delta(Q_k = 1)\,\delta(Z_{k,1} = i) + \delta(Q_k = 0)\bigl(\delta(Z_{k,1} = i) + \delta(Z_{k,2} = i)\bigr)\Bigr]\] counts the independent draws from \(\mathbf x\) that landed on colony \(i\) (an assortative pair counts once, since only one origin was drawn). The full conditionals:

  • Proportions: \(\mathbf x \mid \ldots \sim \text{Dir}\bigl(\boldsymbol\alpha + \mathbf m(\mathbf Z, \mathbf Q)\bigr)\).
  • Mating parameter: \(w \mid \ldots \sim \text{Beta}(\beta_1 + n_q,\ \beta_2 + N - n_q)\).
  • Parental origins, jointly for each pup: \[P(Z_{k,1} = i, Z_{k,2} = j \mid Q_k = 1, \ldots) = \frac{\gamma_{iik}\,x_i\,\delta_{ij}}{\sum_{i'}\gamma_{i'i'k}\,x_{i'}}, \qquad P(Z_{k,1} = i, Z_{k,2} = j \mid Q_k = 0, \ldots) = \frac{\gamma_{ijk}\,x_ix_j}{\sum_{i',j'}\gamma_{i'j'k}\,x_{i'}x_{j'}} .\]
  • Mating type, given the origins: \[P(Q_k = 1 \mid \ldots) = \frac{w\,\delta_{Z_{k,1}Z_{k,2}}\,x_{Z_{k,1}}}{w\,\delta_{Z_{k,1}Z_{k,2}}\,x_{Z_{k,1}} + (1 - w)\,x_{Z_{k,1}}x_{Z_{k,2}}}, \qquad P(Q_k = 0 \mid \ldots) = 1 - P(Q_k = 1 \mid \ldots).\] (If the parents have different origins, \(Q_k = 0\) with certainty.)

Remark (A mixing caveat). Updating \(Q_k\) given \(\mathbf Z_k\) and then \(\mathbf Z_k\) given \(Q_k\) can mix slowly: when \(Q_k = 1\) the origins are forced equal, and then \(Q_k\) can only switch if \(\mathbf Z_k\) already has equal origins. Sampling \((Q_k, Z_{k,1}, Z_{k,2})\) jointly — from the \(P + P^2\) possible configurations, with weights \(w\gamma_{iik}x_i\) and \((1-w)\gamma_{ijk}x_ix_j\) — avoids the problem at the same cost.

For the hyperparameters \(R, S, \alpha_0\) the conditionals are not standard (they enter through \(\boldsymbol\alpha\) and \(B(\boldsymbol\alpha)\)), so we use Metropolis steps for them. The result is a Metropolis-within-Gibbs sampler:

Repeat:

  1. sample \(\mathbf x \sim \text{Dir}\bigl(\boldsymbol\alpha(R, S, \alpha_0) + \mathbf m(\mathbf Z, \mathbf Q)\bigr)\);
  2. sample \(w \sim \text{Beta}(\beta_1 + n_q, \beta_2 + N - n_q)\);
  3. for all \(k\), sample \((Z_{k,1}, Z_{k,2})\) from their conditional;
  4. for all \(k\), sample \(Q_k\) from its conditional;
  5. Metropolis updates \(S \to b_{0,1}(S + u)\), \(R \to b_{0,5}(R + u)\), \(\alpha_0 \to b_{P,100}(\alpha_0 + u)\), each targeting \(\text{Dir}(\boldsymbol\alpha(R, S, \alpha_0); \mathbf x)\,P(R)P(S)P(\alpha_0)\).

10.4 Lessons

  • Latent variables make likelihoods tractable. Writing down the generative story (“each pup has a mother from some colony”) gives the likelihood; keeping the story’s hidden variables gives a sampler.
  • Exact marginalisation is exponential. The analytic posterior is a mixture over \(P^N\) assignments; MCMC replaces the sum by a random walk through the relevant terms.
  • Conjugacy turns modelling choices into algorithms. Dirichlet priors for proportions and Beta priors for probabilities make every latent-variable conditional a standard distribution.
  • Hierarchies encode scientific hypotheses. Distance decay and productivity enter as hyperparameters whose posterior answers the scientific question; their non-conjugate updates are handled by Metropolis within Gibbs.

In the simple example, verify the evidence \(97/432\) for the observation (long, long) and the mixture weights \(64/97, 24/97, 9/97\). Then compute the posterior variance of \(x_1\).

Solution. \(\tfrac49\cdot\tfrac13 = \tfrac{4}{27} = \tfrac{64}{432}\), \(\tfrac13\cdot\tfrac16 = \tfrac1{18} = \tfrac{24}{432}\), \(\tfrac1{16}\cdot\tfrac13 = \tfrac1{48} = \tfrac{9}{432}\); total \(97/432\), and the weights are the three terms divided by the total. Solution. \(P = \tfrac49 x_1 + \tfrac1{16}x_2\). The two components correspond to the two values of the single latent variable \(Z_1\).

Derive the full conditional \(P(Z_k = i \mid \mathbf y, \mathbf x, \mathbf Z_{-k}) \propto \gamma_{ik}x_i\) of the basic model by dividing the joint posterior by its sum over \(Z_k\).

Solution. In \(P(\mathbf x, \mathbf Z \mid \mathbf y) \propto \prod_{k'}\gamma_{Z_{k'}k'}x_{Z_{k'}}\cdot\prod_p x_p^{\alpha_p - 1}\), all factors with \(k' \neq k\) and the prior are common to numerator and denominator and cancel, leaving \(\gamma_{Z_kk}x_{Z_k}/\sum_i\gamma_{ik}x_i\).

Show that summing the augmented model over \(Q_k\) reproduces \(P(Z_{k,1} = i, Z_{k,2} = j \mid \mathbf x, w) = w\delta_{ij}x_i + (1-w)x_ix_j\), and that the likelihood reduces to the basic-model form (with both alleles from the same colony) when \(w = 1\).

Solution. \(\sum_{q}P(Q_k = q \mid w)P(i, j \mid q, \mathbf x) = w\,\delta_{ij}x_i + (1 - w)x_ix_j\). For \(w = 1\), \(P(\mathbf y \mid \mathbf x) = \prod_k\sum_i x_i\gamma_{iik}\) with \(\gamma_{iik} = \prod_l p^{(i,l)}_{y_{k,l,1}}p^{(i,l)}_{y_{k,l,2}}\): each pup is a single draw from a colony, carrying \(2L\) alleles from it — the basic model with twice as many loci.

Estimate the cost per sweep of the refined Gibbs sampler, and compare with the size of the analytic sum.

Solution. Precompute \(\gamma_{ijk}\): \(O(NP^2L)\) once. Per sweep: the \((Z_{k,1}, Z_{k,2})\) updates cost \(O(NP^2)\), the rest \(O(N + P)\). With \(N = 150\), \(P = 7\) this is \(\sim 10^4\) operations per sweep, against \(\sim (P^2)^N \approx 10^{254}\) terms in the exact marginalisation.

10.6 Callouts

This chapter is a template for applied Bayesian work: (1) write the generative story, (2) translate it into a likelihood with latent variables, (3) choose (conjugate) priors, encoding scientific hypotheses in hyperparameters, (4) sample with Gibbs where conditionals are standard and Metropolis elsewhere.

Always test a sampler on simulated data with known \(\mathbf x\), \(w\), \(R\), \(S\) before running it on real data: if the posterior does not concentrate around the truth as \(N\) grows, there is a bug or an identifiability problem.

Products of \(N \cdot L\) probabilities underflow double precision. Work with \(\log\gamma_{ik}\) and use the log-sum-exp trick when normalising categorical conditionals: \(\log\sum_i e^{a_i} = a_{\max} + \log\sum_i e^{a_i - a_{\max}}\).

This chapter works through a real research problem that ties together everything in Chapters 7–8: building a likelihood with latent variables, choosing conjugate priors, discovering that the exact posterior is a combinatorial monster, and sampling it with Metropolis and Gibbs. The problem comes from population genetics: Gaggiotti et al. (2002) studied how new colonies of **grey seals** are founded, and asked *where the founders came from*, using only the genomes of pups born in the new colony.

## The problem

Grey seals live in isolated colonies; occasionally a new colony is founded by migrants from older ones. Assume the founders come from $P$ old colonies, in unknown proportions
$$\mathbf x = (x_1, \ldots, x_P), \qquad x_i \geq 0, \quad \sum_{i=1}^P x_i = 1 .$$
**$\mathbf x$ is the unknown we want to infer**: a point in the $(P-1)$-dimensional simplex.

The data: $N = 150$ pups born in the new colony (whose parents were migrants) were genotyped at $L = 9$ loci, chosen among the most variable ones to maximise discrimination. At each locus an individual carries two variants (**alleles**) of the gene, one inherited from the mother ($n = 1$) and one from the father ($n = 2$), each among $M_l$ possible alleles. Taking $M = \max_l M_l$ (and assigning zero frequency to non-existent alleles), the data are
$$y_{k,l,n} \in \{1, \ldots, M\}, \qquad k = 1..N \text{ (individual)},\ l = 1..L \text{ (locus)},\ n = 1, 2 \text{ (parent)}.$$
What links $\mathbf x$ to $\mathbf y$ is that the **allele frequencies in the old colonies are known** from previous studies:
$$p_m^{(i,l)} = \text{frequency of allele } m \text{ at locus } l \text{ in colony } i, \qquad \sum_m p_m^{(i,l)} = 1 .$$
Different colonies have different allele frequencies, so a pup's genotype carries (weak) information about where its parents came from; with many pups and loci, this adds up to information about $\mathbf x$.

## Basic model

We first study a simplified model in which only the **maternal** alleles are observed: data $y_{k,l} \equiv y_{k,l,1}$.

### Likelihood

Introduce a **latent variable** for each pup,
$$Z_k \in \{1, \ldots, P\}: \text{ the colony the mother of pup } k \text{ came from.}$$
Two modelling assumptions connect the variables:

- the probability of inheriting allele $m$ at locus $l$ from a mother of colony $i$ is the frequency of that allele in colony $i$:
$$P(Y_{k,l} = m \mid Z_k = i) = p_m^{(i,l)};$$
- the probability that a mother came from colony $i$ is the proportion of founders from colony $i$:
$$P(Z_k = i \mid \mathbf x) = x_i .$$

Marginalising the latent variable, and using that $Y_{k,l}$ depends on $\mathbf x$ only through $Z_k$ (conditional independence),
$$P(Y_{k,l} = m \mid \mathbf x) = \sum_{i=1}^P P(Y_{k,l} = m \mid Z_k = i)P(Z_k = i \mid \mathbf x) = \sum_{i=1}^P x_i\,p_m^{(i,l)} .$$
Assuming further that the alleles at different loci are independent given the origin (a simplification — probably not exactly true for real genomes),
$$P(\mathbf Y_k = \mathbf y_k \mid Z_k = i) = \prod_{l=1}^L p^{(i,l)}_{y_{k,l}} \equiv \gamma_{ik}, \qquad P(\mathbf Y_k = \mathbf y_k \mid \mathbf x) = \sum_{i=1}^P x_i\,\gamma_{ik}.$$
$\gamma_{ik}$ is the likelihood that pup $k$'s maternal genotype came from colony $i$. Assuming independent individuals, the full likelihood is
$$P(\mathbf Y = \mathbf y \mid \mathbf x) = \prod_{k=1}^N\sum_{i=1}^P x_i\,\gamma_{ik} = \prod_{k=1}^N\sum_{i=1}^P x_i\prod_{l=1}^L p^{(i,l)}_{y_{k,l}} .$$
This is a **mixture model** of exactly the type of Chapter 8: each pup is drawn from one of $P$ "components" (colonies) with weights $\mathbf x$, but the component distributions $\gamma_{ik}$ are *known*.

### Prior: the Dirichlet distribution

The likelihood is a polynomial in $\mathbf x$, so the natural (conjugate) prior on the simplex is the Dirichlet distribution.

::: {.definition name="Dirichlet distribution"}
$\mathbf x \sim \text{Dir}(\boldsymbol\alpha)$, $\alpha_i > 0$, has density on the simplex $\mathcal D = \{\mathbf x : x_i \geq 0, \sum_i x_i = 1\}$
$$\text{Dir}(\boldsymbol\alpha; \mathbf x) = \frac{1}{B(\boldsymbol\alpha)}\prod_{i=1}^P x_i^{\alpha_i - 1}, \qquad B(\boldsymbol\alpha) = \frac{\Gamma(\alpha_1)\cdots\Gamma(\alpha_P)}{\Gamma(\alpha_1 + \cdots + \alpha_P)} .$$
With $\alpha_0 = \sum_i\alpha_i$: $\mathbb E[x_i] = \alpha_i/\alpha_0$ and $\operatorname{Var}[x_i] = \alpha_i(\alpha_0 - \alpha_i)/\bigl(\alpha_0^2(\alpha_0 + 1)\bigr)$. For $P = 2$ it reduces to the Beta distribution. $\boldsymbol\alpha = (1, \ldots, 1)$ is uniform on the simplex; large $\alpha_0$ concentrates the mass around the mean.
:::

The key integral, used repeatedly below, is just the normalisation:
$$\int_{\mathcal D} d\mathbf x\,\prod_i x_i^{\beta_i - 1} = B(\boldsymbol\beta).$$

The posterior is
$$P(\mathbf x \mid \mathbf y) = \frac{1}{P(\mathbf y)}\prod_{k=1}^N\Bigl(\sum_{i=1}^P x_i\gamma_{ik}\Bigr)\cdot\frac{1}{B(\boldsymbol\alpha)}\prod_{p=1}^P x_p^{\alpha_p - 1},$$
with evidence $P(\mathbf y) = \int_{\mathcal D} d\mathbf x\,(\text{numerator})$, an integral over the simplex.

### Metropolis approach

Metropolis only needs the unnormalised posterior. A simple proposal moves $\mathbf x$ by a small random step and then projects back onto the simplex:
$$\mathbf x \;\to\; \mathbf x + \mathbf u \;\to\; b_{0,1}(\mathbf x + \mathbf u) \;\to\; \frac{b_{0,1}(\mathbf x + \mathbf u)}{\sum_i b_{0,1}(x_i + u_i)} = \mathbf x', \qquad u_i \sim \mathcal U(-\epsilon, \epsilon),$$
where $b_{0,1}(x) = \min(\max(x, 0), 1)$ clips each component into $[0, 1]$. The acceptance probability is
$$A(\mathbf x' \mid \mathbf x) = \min\Biggl\{1, \frac{\prod_k\bigl(\sum_i x'_i\gamma_{ik}\bigr)\prod_p (x'_p)^{\alpha_p - 1}}{\prod_k\bigl(\sum_i x_i\gamma_{ik}\bigr)\prod_p x_p^{\alpha_p - 1}}\Biggr\},$$
in which the evidence and $B(\boldsymbol\alpha)$ cancel. Each evaluation costs $O(NP)$ operations (after precomputing $\gamma_{ik}$, which costs $O(NPL)$ once). In practice one works with log-probabilities to avoid underflow: $\prod_k$ of 150 small numbers is far below double-precision range.

::: {.remark name="Is this proposal symmetric?"}
The clip-and-renormalise map is not exactly symmetric, so strictly a Hastings correction would be needed. Cleaner alternatives: (i) parametrise by $P - 1$ free coordinates and reject proposals that leave the simplex (a symmetric proposal on a bounded domain is fine — out-of-domain proposals have $\pi = 0$ and are simply rejected); (ii) propose $\mathbf x' \sim \text{Dir}(c\,\mathbf x)$ with a large concentration $c$ and include the Hastings ratio $\text{Dir}(c\mathbf x'; \mathbf x)/\text{Dir}(c\mathbf x; \mathbf x')$.
:::

### Analytic expression of the posterior

The posterior can, in principle, be written in closed form. Expand the product of sums:
$$\prod_{k=1}^N\Bigl(\sum_{i=1}^P x_i\gamma_{ik}\Bigr) = \sum_{i_1=1}^P\cdots\sum_{i_N=1}^P\ \prod_{k=1}^N x_{i_k}\gamma_{i_k k} = \sum_{\mathbf i}\ \prod_{k=1}^N x_{i_k}\gamma_{i_k k},$$
where the multi-index $\mathbf i = (i_1, \ldots, i_N)$ runs over all $P^N$ assignments of pups to colonies — i.e. over all values of the latent variables $\mathbf Z$. Let $n_p(\mathbf i) = \sum_k\delta_{i_k p}$ count how many pups are assigned to colony $p$. Then $\prod_k x_{i_k} = \prod_p x_p^{n_p(\mathbf i)}$ and the numerator becomes
$$\frac{1}{B(\boldsymbol\alpha)}\sum_{\mathbf i}\Bigl(\prod_k\gamma_{i_k k}\Bigr)\prod_p x_p^{n_p(\mathbf i) + \alpha_p - 1} = \sum_{\mathbf i}\xi(\mathbf i)\,\text{Dir}\bigl(\mathbf n(\mathbf i) + \boldsymbol\alpha; \mathbf x\bigr), \qquad \xi(\mathbf i) = \frac{B(\mathbf n(\mathbf i) + \boldsymbol\alpha)}{B(\boldsymbol\alpha)}\prod_{k=1}^N\gamma_{i_k k}.$$
Since each Dirichlet integrates to one, the evidence is $P(\mathbf y) = \sum_{\mathbf i}\xi(\mathbf i)$, and

::: {.proposition name="The posterior is a mixture of Dirichlets"}
$$P(\mathbf x \mid \mathbf y) = \sum_{\mathbf i}\zeta(\mathbf i)\,\text{Dir}\bigl(\mathbf n(\mathbf i) + \boldsymbol\alpha; \mathbf x\bigr), \qquad \zeta(\mathbf i) = \frac{\xi(\mathbf i)}{\sum_{\mathbf j}\xi(\mathbf j)} .$$
Posterior moments follow from those of the Dirichlet, e.g.
$$\mathbb E[x_p \mid \mathbf y] = \sum_{\mathbf i}\zeta(\mathbf i)\,\frac{n_p(\mathbf i) + \alpha_p}{\sum_q\bigl(n_q(\mathbf i) + \alpha_q\bigr)} = \sum_{\mathbf i}\zeta(\mathbf i)\,\frac{n_p(\mathbf i) + \alpha_p}{N + \alpha_0}.$$
:::

The interpretation is transparent: for each hypothetical assignment $\mathbf i$ of pups to colonies, the posterior on $\mathbf x$ would be the conjugate $\text{Dir}(\boldsymbol\alpha + \text{counts})$; the true posterior averages these over assignments, weighted by how well each assignment explains the genotypes.

::: {.remark name="Why the analytic formula is useless"}
The sum has $P^N$ terms. With $N = 150$ and $P = 7$ (as in the study), that is $7^{150} \approx 10^{127}$ terms — hopeless. This is a general feature of mixture models: marginalising the latent variables *analytically* is exponential in $N$. Note, by contrast, that the factorised form $\prod_k\sum_i x_i\gamma_{ik}$ costs only $N \cdot P$ operations, which is why Metropolis on $\mathbf x$ is perfectly feasible.
:::

### A simple example

To see the structure, consider $P = 2$ colonies, $M = 2$ alleles and two loci, "tail length" and "fin length", with allele 1 = long and 2 = short. The known frequencies are
$$p^{(1,1)} = p^{(1,2)} = \bigl(\tfrac23, \tfrac13\bigr), \qquad p^{(2,1)} = p^{(2,2)} = \bigl(\tfrac14, \tfrac34\bigr):$$
in colony 1 two thirds of the individuals have long tails (and fins), in colony 2 only a quarter. We observe two alleles $(y_1, y_2)$, one per locus, and $\mathbf x = (x_1, 1 - x_1)$. Following Allegra's notes, take the likelihood to be
$$P(y_1, y_2 \mid \mathbf x) = \prod_{l=1}^{2}\Bigl(\sum_{i=1}^2 x_i p^{(i,l)}_{y_l}\Bigr) = \sum_{i,j} x_ix_j\,p^{(i,1)}_{y_1}p^{(j,2)}_{y_2},$$
i.e. each of the two alleles comes from an *independently drawn* founder. (This is equivalent to $N = 2$ pups with $L = 1$ locus each. For a single pup with two loci, the basic model would instead give $\sum_i x_i\,p^{(i,1)}_{y_1}p^{(i,2)}_{y_2}$, linear in $\mathbf x$, and the posterior would be a mixture of only two Beta components; see the exercises.) For the four possible observations this gives

| $(y_1, y_2)$ | $P(y_1, y_2 \mid \mathbf x)$ |
|:---:|:---|
| (long, long) | $\tfrac49 x_1^2 + \tfrac13 x_1x_2 + \tfrac1{16}x_2^2$ |
| (long, short), (short, long) | $\tfrac29 x_1^2 + \tfrac7{12} x_1x_2 + \tfrac3{16}x_2^2$ |
| (short, short) | $\tfrac19 x_1^2 + \tfrac12 x_1x_2 + \tfrac9{16}x_2^2$ |

With a uniform prior ($\alpha_1 = \alpha_2 = 1$), each monomial $x_1^a x_2^b$ is an unnormalised $\text{Beta}(a+1, b+1)$ with integral $B(a+1, b+1)$: $\int x_1^2 = \tfrac13$, $\int x_1x_2 = \tfrac16$, $\int x_2^2 = \tfrac13$. For (long, long) the evidence is $\tfrac{4}{27} + \tfrac{1}{18} + \tfrac{1}{48} = \tfrac{97}{432}$ and
$$P(x_1 \mid \text{long, long}) = \tfrac{64}{97}\,\text{Beta}(x_1; 3, 1) + \tfrac{24}{97}\,\text{Beta}(x_1; 2, 2) + \tfrac{9}{97}\,\text{Beta}(x_1; 1, 3).$$
Similarly

| $(y_1, y_2)$ | weight of Beta(3,1) | Beta(2,2) | Beta(1,3) | $\mathbb E[x_1 \mid y]$ |
|:---:|:---:|:---:|:---:|:---:|
| (long, long) | 64/97 | 24/97 | 9/97 | 0.642 |
| (long, short) or (short, long) | 32/101 | 42/101 | 27/101 | 0.512 |
| (short, short) | 16/133 | 36/133 | 81/133 | 0.378 |

(using $\mathbb E[x_1] = 3/4, 1/2, 1/4$ for the three Beta components). The three components correspond to the latent configurations "both founders from colony 1" ($\mathbf n = (2,0)$), "one from each" ($\mathbf n = (1,1)$, two assignments) and "both from colony 2" ($\mathbf n = (0, 2)$), each giving a $\text{Dir}(\mathbf n + \boldsymbol\alpha) = \text{Beta}$ component. Observing long features shifts belief towards colony 1, short features towards colony 2, and mixed features leave the prior mean $1/2$ almost unchanged. With two alleles the posterior remains very broad: each observation carries little information, and precision comes only from many pups.

### Gibbs sampling approach

The smart alternative to marginalising $\mathbf Z$ is **not** to marginalise it, and to sample $\mathbf Z$ jointly with $\mathbf x$, exactly as for the Gaussian mixture of Chapter 8. Keeping the latent variables,
$$P(\mathbf y \mid \mathbf Z) = \prod_{k=1}^N\gamma_{Z_k k}, \qquad P(\mathbf Z \mid \mathbf x) = \prod_{k=1}^N x_{Z_k} = \prod_{i=1}^P x_i^{m_i(\mathbf Z)}, \quad m_i(\mathbf Z) = \sum_k\delta(Z_k = i),$$
so the joint posterior is
$$P(\mathbf x, \mathbf Z \mid \mathbf y) = \frac{1}{P(\mathbf y)B(\boldsymbol\alpha)}\prod_{k=1}^N\gamma_{Z_kk}\ \prod_{i=1}^P x_i^{m_i(\mathbf Z) + \alpha_i - 1}.$$
The full conditionals are standard:

**Proportions.** Only the last factor depends on $\mathbf x$; normalising over the simplex,
$$\mathbf x \mid \mathbf y, \mathbf Z \sim \text{Dir}\bigl(\boldsymbol\alpha + \mathbf m(\mathbf Z)\bigr):$$
prior pseudo-counts plus the number of mothers currently assigned to each colony.

**Origins.** Only the factors $\gamma_{Z_kk}\,x_{Z_k}$ depend on $Z_k$, so
$$P(Z_k = i \mid \mathbf y, \mathbf x, \mathbf Z_{-k}) = \frac{\gamma_{ik}\,x_i}{\sum_j\gamma_{jk}\,x_j}:$$
Bayes' theorem for "which colony did this mother come from?", with prior $\mathbf x$ and likelihood $\gamma_{\cdot k}$. Given $\mathbf x$, the $Z_k$ are conditionally independent and can all be updated at once.

::: {.definition name="Block Gibbs sampler (basic model)"}
Repeat:

1. sample $\mathbf x \sim \text{Dir}(\boldsymbol\alpha + \mathbf m(\mathbf Z))$;
2. for all $k$, sample $Z_k \sim \text{Cat}\bigl(\gamma_{\cdot k}\odot\mathbf x / \sum_j\gamma_{jk}x_j\bigr)$.
:::

Each sweep costs $O(NP)$ and requires no tuning. As a bonus, the samples of $Z_k$ give the posterior probability that each pup's mother came from each colony — an individual-level "assignment test".

::: {.remark name="Data augmentation"}
The Gibbs sampler explores the joint space of $(\mathbf x, \mathbf Z)$, of dimension $P - 1 + N$, which is *larger* than the space of $\mathbf x$ alone. Yet it is easier to sample: the $P^N$-term sum is never computed; instead the chain *visits* the relevant assignments $\mathbf i$ with frequency $\propto\xi(\mathbf i)$. The marginal of $\mathbf x$ in the samples is the exact mixture-of-Dirichlets posterior.
:::

## Refined model

The model actually used by Gaggiotti et al. is richer in three ways: both parents contribute alleles, parents tend to mate within their own origin, and the proportions $\mathbf x$ are linked to the geography of the old colonies.

### Two parents and assortative mating

Let $Z_{k,n}$ be the origin of parent $n$ of pup $k$. As before,
$$P(Y_{k,l,n} = m \mid Z_{k,n} = i) = p_m^{(i,l)}, \qquad P(\mathbf Y_{k,n} = \mathbf y_{k,n} \mid Z_{k,n} = i) = \prod_{l}p^{(i,l)}_{y_{k,l,n}} .$$
If the two parents' origins were independent, $P(Z_{k,1} = i, Z_{k,2} = j \mid \mathbf x) = x_ix_j$, and (assuming the maternal and paternal alleles are independent given the origins)
$$P(\mathbf Y = \mathbf y \mid \mathbf x) = \prod_{k=1}^N\sum_{i,j=1}^P x_ix_j\prod_{l=1}^L p^{(i,l)}_{y_{k,l,1}}p^{(j,l)}_{y_{k,l,2}} .$$
But founders mate preferentially with individuals of the same origin (**assortative mating**). Model this with a parameter $w \in [0,1]$: with probability $w$ an individual mates with someone of its own origin, with probability $1 - w$ with a random founder:
$$P(Z_{k,1} = i, Z_{k,2} = j \mid \mathbf x, w) = w\,\delta_{ij}\,x_i + (1 - w)\,x_ix_j .$$
Defining $\gamma_{ijk} = \prod_l p^{(i,l)}_{y_{k,l,1}}p^{(j,l)}_{y_{k,l,2}}$, the likelihood becomes
$$P(\mathbf Y = \mathbf y \mid \mathbf x, w) = \prod_{k=1}^N\Bigl[w\sum_{i=1}^P x_i\,\gamma_{iik} + (1 - w)\sum_{i,j=1}^P x_ix_j\,\gamma_{ijk}\Bigr].$$
For $w = 0$ we recover random mating; for $w = 1$ both parents always share an origin.

### Geography in the prior

Gaggiotti et al. further assume that the expected contribution of each old colony decays exponentially with its (known) distance $\delta_i$ from the new colony and grows with its (known) productivity $\pi_i$:
$$\mathbb E[x_i] \propto \bigl((1 - S) + S\pi_i\bigr)e^{-R\delta_i},$$
with an unknown **distance decay** $R$ and **productivity weight** $S$. This is built into the Dirichlet prior:
$$\mathbf x \mid R, S, \alpha_0 \sim \text{Dir}(\boldsymbol\alpha), \qquad \alpha_i = \alpha_0\,\frac{\bigl((1 - S) + S\pi_i\bigr)e^{-R\delta_i}}{c}, \quad c = \sum_{i=1}^P\bigl((1 - S) + S\pi_i\bigr)e^{-R\delta_i},$$
so that $\mathbb E[x_i] = \alpha_i/\alpha_0$ has the desired form and $\alpha_0$ controls how tightly $\mathbf x$ follows it. The **hyperparameters** get uniform priors:
$$\alpha_0 \sim \mathcal U(P, 100), \quad w \sim \mathcal U(0, 1), \quad S \sim \mathcal U(0, 1), \quad R \sim \mathcal U(0, 5).$$
This is a **hierarchical model**: data ← $(\mathbf x, w)$ ← $(R, S, \alpha_0)$. The posterior is
$$P(\mathbf x, w, \alpha_0, R, S \mid \mathbf y) \propto P(\mathbf y \mid \mathbf x, w)\,\text{Dir}(\boldsymbol\alpha(R, S, \alpha_0); \mathbf x)\,P(w)P(R)P(S)P(\alpha_0).$$
Note that $B(\boldsymbol\alpha)$ now depends on the hyperparameters and does *not* cancel in Metropolis ratios for $R, S, \alpha_0$.

The posterior on $R$ and $S$ is the scientifically interesting output: *do seals found colonies preferentially near their origin, and do productive colonies send more migrants?*

### Metropolis approach

Update the parameters one at a time (or in blocks) with bounded random-walk moves, $u \sim \mathcal U(-\epsilon, \epsilon)$:
$$\mathbf x \to \frac{b(\mathbf x + \mathbf u)}{\sum_i b(x_i + u_i)}, \quad w \to b_{0,1}(w + u), \quad S \to b_{0,1}(S + u), \quad R \to b_{0,5}(R + u), \quad \alpha_0 \to b_{P,100}(\alpha_0 + u),$$
each accepted with the Metropolis ratio of the unnormalised posterior. (The remark on symmetry of clipped proposals applies here too.)

### Gibbs sampling with latent variables

As in the basic model, we can keep the parental origins $Z_{k,1}, Z_{k,2}$ as latent variables. To deal with the mixture in the mating model, introduce one more latent variable per pup,
$$Q_k \in \{0, 1\}: \quad Q_k = 1 \text{ if the parents mated assortatively}, \quad P(Q_k = 1 \mid w) = w,$$
with
$$P(Z_{k,1}, Z_{k,2} \mid Q_k = 1, \mathbf x) = \delta_{Z_{k,1}Z_{k,2}}\,x_{Z_{k,1}}, \qquad P(Z_{k,1}, Z_{k,2} \mid Q_k = 0, \mathbf x) = x_{Z_{k,1}}x_{Z_{k,2}} .$$
Summing over $Q_k$ reproduces $w\delta_{ij}x_i + (1-w)x_ix_j$. With a Beta prior $w \sim \text{Beta}(\beta_1, \beta_2)$ (uniform for $\beta_1 = \beta_2 = 1$), the augmented posterior is
$$P(\mathbf x, w, \mathbf Z, \mathbf Q \mid \mathbf y) \propto \prod_{k=1}^N\gamma_{Z_{k,1}Z_{k,2}k}\ \prod_{i=1}^P x_i^{m_i(\mathbf Z, \mathbf Q) + \alpha_i - 1}\ w^{n_q + \beta_1 - 1}(1 - w)^{N - n_q + \beta_2 - 1}\ \prod_{k : Q_k = 1}\delta_{Z_{k,1}Z_{k,2}},$$
where $n_q = \sum_k\delta(Q_k = 1)$ counts assortative matings and
$$m_i(\mathbf Z, \mathbf Q) = \sum_{k=1}^N\Bigl[\delta(Q_k = 1)\,\delta(Z_{k,1} = i) + \delta(Q_k = 0)\bigl(\delta(Z_{k,1} = i) + \delta(Z_{k,2} = i)\bigr)\Bigr]$$
counts the *independent draws* from $\mathbf x$ that landed on colony $i$ (an assortative pair counts once, since only one origin was drawn). The full conditionals:

- **Proportions:** $\mathbf x \mid \ldots \sim \text{Dir}\bigl(\boldsymbol\alpha + \mathbf m(\mathbf Z, \mathbf Q)\bigr)$.
- **Mating parameter:** $w \mid \ldots \sim \text{Beta}(\beta_1 + n_q,\ \beta_2 + N - n_q)$.
- **Parental origins**, jointly for each pup:
$$P(Z_{k,1} = i, Z_{k,2} = j \mid Q_k = 1, \ldots) = \frac{\gamma_{iik}\,x_i\,\delta_{ij}}{\sum_{i'}\gamma_{i'i'k}\,x_{i'}}, \qquad P(Z_{k,1} = i, Z_{k,2} = j \mid Q_k = 0, \ldots) = \frac{\gamma_{ijk}\,x_ix_j}{\sum_{i',j'}\gamma_{i'j'k}\,x_{i'}x_{j'}} .$$
- **Mating type**, given the origins:
$$P(Q_k = 1 \mid \ldots) = \frac{w\,\delta_{Z_{k,1}Z_{k,2}}\,x_{Z_{k,1}}}{w\,\delta_{Z_{k,1}Z_{k,2}}\,x_{Z_{k,1}} + (1 - w)\,x_{Z_{k,1}}x_{Z_{k,2}}}, \qquad P(Q_k = 0 \mid \ldots) = 1 - P(Q_k = 1 \mid \ldots).$$
(If the parents have different origins, $Q_k = 0$ with certainty.)

::: {.remark name="A mixing caveat"}
Updating $Q_k$ given $\mathbf Z_k$ and then $\mathbf Z_k$ given $Q_k$ can mix slowly: when $Q_k = 1$ the origins are forced equal, and then $Q_k$ can only switch if $\mathbf Z_k$ already has equal origins. Sampling $(Q_k, Z_{k,1}, Z_{k,2})$ **jointly** — from the $P + P^2$ possible configurations, with weights $w\gamma_{iik}x_i$ and $(1-w)\gamma_{ijk}x_ix_j$ — avoids the problem at the same cost.
:::

For the hyperparameters $R, S, \alpha_0$ the conditionals are not standard (they enter through $\boldsymbol\alpha$ and $B(\boldsymbol\alpha)$), so we use Metropolis steps for them. The result is a **Metropolis-within-Gibbs** sampler:

::: {.definition name="Sampler for the refined model"}
Repeat:

1. sample $\mathbf x \sim \text{Dir}\bigl(\boldsymbol\alpha(R, S, \alpha_0) + \mathbf m(\mathbf Z, \mathbf Q)\bigr)$;
2. sample $w \sim \text{Beta}(\beta_1 + n_q, \beta_2 + N - n_q)$;
3. for all $k$, sample $(Z_{k,1}, Z_{k,2})$ from their conditional;
4. for all $k$, sample $Q_k$ from its conditional;
5. Metropolis updates $S \to b_{0,1}(S + u)$, $R \to b_{0,5}(R + u)$, $\alpha_0 \to b_{P,100}(\alpha_0 + u)$, each targeting $\text{Dir}(\boldsymbol\alpha(R, S, \alpha_0); \mathbf x)\,P(R)P(S)P(\alpha_0)$.
:::

## Lessons

- **Latent variables make likelihoods tractable.** Writing down the generative story ("each pup has a mother from some colony") gives the likelihood; keeping the story's hidden variables gives a sampler.
- **Exact marginalisation is exponential.** The analytic posterior is a mixture over $P^N$ assignments; MCMC replaces the sum by a random walk through the relevant terms.
- **Conjugacy turns modelling choices into algorithms.** Dirichlet priors for proportions and Beta priors for probabilities make every latent-variable conditional a standard distribution.
- **Hierarchies encode scientific hypotheses.** Distance decay and productivity enter as hyperparameters whose posterior answers the scientific question; their non-conjugate updates are handled by Metropolis within Gibbs.

## Exercises

::: {.exercise}
In the simple example, verify the evidence $97/432$ for the observation (long, long) and the mixture weights $64/97, 24/97, 9/97$. Then compute the posterior variance of $x_1$.
:::

::: {.solution}
$\tfrac49\cdot\tfrac13 = \tfrac{4}{27} = \tfrac{64}{432}$, $\tfrac13\cdot\tfrac16 = \tfrac1{18} = \tfrac{24}{432}$, $\tfrac1{16}\cdot\tfrac13 = \tfrac1{48} = \tfrac{9}{432}$; total $97/432$, and the weights are the three terms divided by the total. For the variance use $\mathbb E[x_1^2] = \sum_c w_c\,\mathbb E_c[x_1^2]$ with $\mathbb E[x^2] = a(a+1)/((a+b)(a+b+1))$: $\text{Beta}(3,1) \to 3\cdot4/(4\cdot5) = 0.6$, $\text{Beta}(2,2) \to 2\cdot3/(4\cdot5) = 0.3$, $\text{Beta}(1,3) \to 2/20 = 0.1$. $\mathbb E[x_1^2] = (64\cdot0.6 + 24\cdot0.3 + 9\cdot0.1)/97 = 46.5/97 \approx 0.479$; $\operatorname{Var} = 0.479 - 0.642^2 \approx 0.067$ (s.d. $\approx 0.26$) — barely narrower than the uniform prior's $0.289$.
:::

::: {.exercise}
Redo the simple example for a *single* pup whose two loci share the same mother, $P(y_1, y_2 \mid \mathbf x) = \sum_i x_i\,p^{(i,1)}_{y_1}p^{(i,2)}_{y_2}$, for the observation (long, long).
:::

::: {.solution}
$P = \tfrac49 x_1 + \tfrac1{16}x_2$. With a uniform prior, $\int x_1 = \int x_2 = \tfrac12$, so the evidence is $\tfrac29 + \tfrac1{32} = \tfrac{73}{288}$ and the posterior is $\tfrac{64}{73}\text{Beta}(2,1) + \tfrac{9}{73}\text{Beta}(1,2)$, with mean $\tfrac{64}{73}\cdot\tfrac23 + \tfrac9{73}\cdot\tfrac13 \approx 0.626$. The two components correspond to the two values of the single latent variable $Z_1$.
:::

::: {.exercise}
Derive the full conditional $P(Z_k = i \mid \mathbf y, \mathbf x, \mathbf Z_{-k}) \propto \gamma_{ik}x_i$ of the basic model by dividing the joint posterior by its sum over $Z_k$.
:::

::: {.solution}
In $P(\mathbf x, \mathbf Z \mid \mathbf y) \propto \prod_{k'}\gamma_{Z_{k'}k'}x_{Z_{k'}}\cdot\prod_p x_p^{\alpha_p - 1}$, all factors with $k' \neq k$ and the prior are common to numerator and denominator and cancel, leaving $\gamma_{Z_kk}x_{Z_k}/\sum_i\gamma_{ik}x_i$.
:::

::: {.exercise}
Show that summing the augmented model over $Q_k$ reproduces $P(Z_{k,1} = i, Z_{k,2} = j \mid \mathbf x, w) = w\delta_{ij}x_i + (1-w)x_ix_j$, and that the likelihood reduces to the basic-model form (with both alleles from the same colony) when $w = 1$.
:::

::: {.solution}
$\sum_{q}P(Q_k = q \mid w)P(i, j \mid q, \mathbf x) = w\,\delta_{ij}x_i + (1 - w)x_ix_j$. For $w = 1$, $P(\mathbf y \mid \mathbf x) = \prod_k\sum_i x_i\gamma_{iik}$ with $\gamma_{iik} = \prod_l p^{(i,l)}_{y_{k,l,1}}p^{(i,l)}_{y_{k,l,2}}$: each pup is a single draw from a colony, carrying $2L$ alleles from it — the basic model with twice as many loci.
:::

::: {.exercise}
Estimate the cost per sweep of the refined Gibbs sampler, and compare with the size of the analytic sum.
:::

::: {.solution}
Precompute $\gamma_{ijk}$: $O(NP^2L)$ once. Per sweep: the $(Z_{k,1}, Z_{k,2})$ updates cost $O(NP^2)$, the rest $O(N + P)$. With $N = 150$, $P = 7$ this is $\sim 10^4$ operations per sweep, against $\sim (P^2)^N \approx 10^{254}$ terms in the exact marginalisation.
:::

## Callouts

::: {.callout-note}
This chapter is a template for applied Bayesian work: (1) write the generative story, (2) translate it into a likelihood with latent variables, (3) choose (conjugate) priors, encoding scientific hypotheses in hyperparameters, (4) sample with Gibbs where conditionals are standard and Metropolis elsewhere.
:::

::: {.callout-tip}
Always test a sampler on **simulated data** with known $\mathbf x$, $w$, $R$, $S$ before running it on real data: if the posterior does not concentrate around the truth as $N$ grows, there is a bug or an identifiability problem.
:::

::: {.callout-warning}
Products of $N \cdot L$ probabilities underflow double precision. Work with $\log\gamma_{ik}$ and use the log-sum-exp trick when normalising categorical conditionals: $\log\sum_i e^{a_i} = a_{\max} + \log\sum_i e^{a_i - a_{\max}}$.
:::
