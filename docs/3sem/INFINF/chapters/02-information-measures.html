3  Information-theoretic measures

Entropy is only the first in a family of information measures. This chapter introduces the three most useful ones — conditional entropy, mutual information, and KL divergence — and develops the identities and inequalities that connect them. Every result here will be used in the coding theorems of Chapters 3–4.

3.1 Properties of Shannon entropy

We first collect a few properties beyond the elementary ones of Chapter 1.

The Shannon entropy \(H : \Delta_M \to [0, \log M]\) on the probability simplex is a strictly concave function of \(p\): for any two distributions \(p, q\) and \(\lambda \in [0, 1]\), \[H(\lambda p + (1 - \lambda)q) \geq \lambda H(p) + (1 - \lambda)H(q),\] with equality iff \(p = q\).

For non-negative reals \(a_i, b_i > 0\), \[\sum_i a_i \log \frac{a_i}{b_i} \geq \Bigl(\sum_i a_i\Bigr)\log \frac{\sum_i a_i}{\sum_i b_i},\] with equality iff \(a_i / b_i\) is constant across \(i\).

The log-sum inequality is the workhorse behind almost every information-theoretic inequality that follows.

3.2 Kullback–Leibler divergence

The KL divergence measures how far one distribution \(p\) is from another \(q\).

For distributions \(p, q\) on a discrete alphabet \(\mathcal X\), \[D(p \| q) = \sum_{x \in \mathcal X} p(x) \log_2 \frac{p(x)}{q(x)}.\] By convention \(0\log(0/q) = 0\) and \(p\log(p/0) = +\infty\) for \(p > 0\).

For any two distributions \(p, q\) on the same alphabet, \(D(p \| q) \geq 0\), with equality iff \(p = q\).

Proof idea. Apply Jensen’s inequality to the convex function \(-\log\) with expectation over \(p\): \(-\log \mathbb E_p[q/p] \leq \mathbb E_p[-\log(q/p)]\); the left-hand side vanishes because \(\mathbb E_p[q(X)/p(X)] = \sum_x q(x) = 1\), so the right-hand side is non-negative.

Remark. The KL divergence is not a metric: it is not symmetric (\(D(p \| q) \neq D(q \| p)\) in general) and does not satisfy the triangle inequality. It nonetheless functions as a “distance” in the sense that \(D(p \| q) = 0 \iff p = q\), and it is convex in each argument.

For \(p \sim \text{Bern}(p_1)\) and \(q \sim \text{Bern}(p_2)\), \[D(p \| q) = p_1 \log_2 \frac{p_1}{p_2} + (1 - p_1)\log_2\frac{1 - p_1}{1 - p_2}.\] When \(p_2 = 1/2\) this reduces to \(1 - h_2(p_1)\), the “distance from uniform” of a biased coin.

3.3 Joint entropy, mutual information, conditional entropy

Given two random variables \(X, Y\) we can build several information quantities from their joint distribution.

\[H(X, Y) = -\sum_{x, y} p(x, y) \log_2 p(x, y), \qquad H(Y \mid X) = \sum_x p(x)\,H(Y \mid X = x) .\] The conditional entropy \(H(Y \mid X)\) is the average uncertainty remaining in \(Y\) once \(X\) is known.

\[H(X, Y) = H(X) + H(Y \mid X) = H(Y) + H(X \mid Y).\] More generally, \(H(X_1, \ldots, X_n) = \sum_{i=1}^{n} H(X_i \mid X_1, \ldots, X_{i-1})\).

The chain rule generalises the corresponding rule for surprisal in Chapter 1.

The mutual information between \(X\) and \(Y\) is \[I(X; Y) = D(p(x, y) \| p(x)\,p(y)) = \sum_{x, y} p(x, y)\log_2\frac{p(x, y)}{p(x)p(y)}.\]

Rewriting the KL yields three equivalent expressions: \[I(X; Y) = H(X) + H(Y) - H(X, Y) = H(X) - H(X \mid Y) = H(Y) - H(Y \mid X) .\]

\(I(X; Y) \geq 0\), with equality iff \(X, Y\) are independent.

A binary symmetric channel with crossover probability \(q\) carries information \(I(X; Y) = 1 - h_2(q)\) per symbol when the input is uniform. At \(q = 0\) (noise-free) it carries the full 1 bit; at \(q = 1/2\) (pure noise) it carries zero.

3.4 Venn-diagram of information

The three quantities \(H(X), H(Y), H(X, Y)\) and their combinations \(H(X \mid Y), H(Y \mid X), I(X; Y)\) obey the same set-theoretic identities as a Venn diagram of two overlapping sets. This is the pedagogical device that generations of textbooks use to remember the relations.

Remark. The Venn-diagram picture breaks for three or more random variables because the “interaction information” \(I(X; Y; Z)\) can be negative. Don’t over-extend the analogy.

3.5 Data-processing inequality

An operational classic: post-processing cannot increase information.

If \(X \to Y \to Z\) is a Markov chain (i.e. \(Z \perp\!\!\!\perp X \mid Y\)), then \[I(X; Y) \geq I(X; Z).\] Equality holds iff \(Y \to Z\) preserves all information about \(X\).

Proof. Use the chain rule \(I(X; Y, Z) = I(X; Y) + I(X; Z \mid Y) = I(X; Z) + I(X; Y \mid Z)\). The Markov property makes \(I(X; Z \mid Y) = 0\), so \(I(X; Y) = I(X; Z) + I(X; Y \mid Z) \geq I(X; Z)\).

3.6 Convexity and further identities

\(D(p \| q)\) is convex in the pair \((p, q)\): for \(\lambda \in [0, 1]\), \[D(\lambda p_1 + (1 - \lambda)p_2 \| \lambda q_1 + (1 - \lambda)q_2) \leq \lambda D(p_1 \| q_1) + (1 - \lambda)D(p_2 \| q_2).\]

For fixed conditional \(p(y \mid x)\), \(I(X; Y)\) is a concave function of \(p(x)\). For fixed marginal \(p(x)\), \(I(X; Y)\) is a convex function of \(p(y \mid x)\). This is the workhorse behind the capacity theorems.

3.7 Exercises

Show that \(H(X, Y) \leq H(X) + H(Y)\) with equality iff \(X, Y\) are independent, using the log-sum inequality directly (not via mutual information).

Solution. Write \(H(X) + H(Y) - H(X, Y) = -\sum_{x,y}p(x,y)\log[p(x)p(y)/p(x,y)]\). By the log-sum inequality applied with \(a_{xy} = p(x,y)\) and \(b_{xy} = p(x)p(y)\), \[\sum_{x,y} p(x,y)\log \tfrac{p(x,y)}{p(x)p(y)} \geq 1 \cdot \log \tfrac{1}{1} = 0.\] So the difference is \(\geq 0\) with equality iff \(p(x,y)/[p(x)p(y)]\) is constant — i.e. equal to 1 — iff independence.

Compute \(I(X; Y)\) for a binary symmetric channel with error probability \(q\) and uniform input.

Solution. \(H(Y) = 1\) (uniform input plus symmetric noise gives uniform output). \(H(Y \mid X) = h_2(q)\) (conditional on the input, \(Y\) is Bernoulli\((q)\)). So \(I(X; Y) = 1 - h_2(q)\), matching the example above.

Prove the data-processing inequality for the specific case \(X \to Y \to Z\) where \(Y = f(X)\) deterministically.

Solution. \(H(X \mid Y) = 0\) because \(Y\) determines \(X\) trivially… wait, if \(Y = f(X)\) then \(X\) is not determined by \(Y\) unless \(f\) is invertible. Instead: \(I(X;Z) = H(X) - H(X|Z) \leq H(X) - H(X|Y,Z)\) (conditioning reduces entropy). Since the Markov property makes \(H(X|Y,Z) = H(X|Y)\), we get \(I(X;Z) \leq H(X) - H(X|Y) = I(X;Y)\). The DPI holds. Deterministic post-processing is a special case.

3.8 Callouts

The three interpretations of mutual information — as a KL divergence, as a reduction of entropy, and as an inclusion–exclusion of joint and marginal entropies — are all useful. Which one you invoke depends on what you want to prove.

When bounding an information quantity, try (i) apply Jensen’s inequality to \(-\log\); (ii) apply the log-sum inequality; (iii) invoke the data-processing inequality. These three moves cover 90% of the proofs in Cover & Thomas.

The KL divergence \(D(p \| q)\) is asymmetric. In machine learning the direction matters: \(D(p \| q)\) (with \(p\) empirical) is maximum-likelihood; \(D(q \| p)\) is not.

## Properties of Shannon entropy

We first collect a few properties beyond the elementary ones of Chapter 1.

::: {.proposition name="Concavity of entropy"}
The Shannon entropy $H : \Delta_M \to [0, \log M]$ on the probability simplex is a *strictly concave* function of $p$: for any two distributions $p, q$ and $\lambda \in [0, 1]$,
$$H(\lambda p + (1 - \lambda)q) \geq \lambda H(p) + (1 - \lambda)H(q),$$
with equality iff $p = q$.
:::

::: {.lemma name="Log-sum inequality"}
For non-negative reals $a_i, b_i > 0$,
$$\sum_i a_i \log \frac{a_i}{b_i} \geq \Bigl(\sum_i a_i\Bigr)\log \frac{\sum_i a_i}{\sum_i b_i},$$
with equality iff $a_i / b_i$ is constant across $i$.
:::

The log-sum inequality is the workhorse behind almost every information-theoretic inequality that follows.

## Kullback–Leibler divergence

The KL divergence measures how *far* one distribution $p$ is from another $q$.

::: {.definition name="Kullback–Leibler divergence"}
For distributions $p, q$ on a discrete alphabet $\mathcal X$,
$$D(p \| q) = \sum_{x \in \mathcal X} p(x) \log_2 \frac{p(x)}{q(x)}.$$
By convention $0\log(0/q) = 0$ and $p\log(p/0) = +\infty$ for $p > 0$.
:::

::: {.theorem name="Gibbs' inequality"}
For any two distributions $p, q$ on the same alphabet, $D(p \| q) \geq 0$, with equality iff $p = q$.
:::

*Proof idea.* Apply Jensen's inequality to the convex function $-\log$ with expectation over $p$: $-\log \mathbb E_p[q/p] \leq \mathbb E_p[-\log(q/p)]$; the left-hand side vanishes because $\mathbb E_p[q(X)/p(X)] = \sum_x q(x) = 1$, so the right-hand side is non-negative.

::: {.remark}
The KL divergence is *not* a metric: it is not symmetric ($D(p \| q) \neq D(q \| p)$ in general) and does not satisfy the triangle inequality. It nonetheless functions as a "distance" in the sense that $D(p \| q) = 0 \iff p = q$, and it is convex in each argument.
:::

::: {.example name="KL of Bernoullis"}
For $p \sim \text{Bern}(p_1)$ and $q \sim \text{Bern}(p_2)$,
$$D(p \| q) = p_1 \log_2 \frac{p_1}{p_2} + (1 - p_1)\log_2\frac{1 - p_1}{1 - p_2}.$$
When $p_2 = 1/2$ this reduces to $1 - h_2(p_1)$, the "distance from uniform" of a biased coin.
:::

## Joint entropy, mutual information, conditional entropy

Given two random variables $X, Y$ we can build several information quantities from their joint distribution.

::: {.definition name="Joint and conditional entropy"}
$$H(X, Y) = -\sum_{x, y} p(x, y) \log_2 p(x, y), \qquad H(Y \mid X) = \sum_x p(x)\,H(Y \mid X = x) .$$
The conditional entropy $H(Y \mid X)$ is the average uncertainty remaining in $Y$ once $X$ is known.
:::

::: {.proposition name="Chain rule for entropy"}
$$H(X, Y) = H(X) + H(Y \mid X) = H(Y) + H(X \mid Y).$$
More generally, $H(X_1, \ldots, X_n) = \sum_{i=1}^{n} H(X_i \mid X_1, \ldots, X_{i-1})$.
:::

The chain rule generalises the corresponding rule for surprisal in Chapter 1.

::: {.definition name="Mutual information"}
The **mutual information** between $X$ and $Y$ is
$$I(X; Y) = D(p(x, y) \| p(x)\,p(y)) = \sum_{x, y} p(x, y)\log_2\frac{p(x, y)}{p(x)p(y)}.$$
:::

Rewriting the KL yields three equivalent expressions:
$$I(X; Y) = H(X) + H(Y) - H(X, Y) = H(X) - H(X \mid Y) = H(Y) - H(Y \mid X) .$$

::: {.corollary name="Non-negativity of mutual information"}
$I(X; Y) \geq 0$, with equality iff $X, Y$ are independent.
:::

::: {.example name="Bit conveyed by a noisy channel"}
A binary symmetric channel with crossover probability $q$ carries information $I(X; Y) = 1 - h_2(q)$ per symbol when the input is uniform. At $q = 0$ (noise-free) it carries the full 1 bit; at $q = 1/2$ (pure noise) it carries zero.
:::

::: {.remark}
The Venn-diagram picture *breaks* for three or more random variables because the "interaction information" $I(X; Y; Z)$ can be negative. Don't over-extend the analogy.
:::

## Data-processing inequality

An operational classic: post-processing cannot increase information.

::: {.theorem name="Data-processing inequality"}
If $X \to Y \to Z$ is a Markov chain (i.e.\ $Z \perp\!\!\!\perp X \mid Y$), then
$$I(X; Y) \geq I(X; Z).$$
Equality holds iff $Y \to Z$ preserves all information about $X$.
:::

*Proof.* Use the chain rule $I(X; Y, Z) = I(X; Y) + I(X; Z \mid Y) = I(X; Z) + I(X; Y \mid Z)$. The Markov property makes $I(X; Z \mid Y) = 0$, so $I(X; Y) = I(X; Z) + I(X; Y \mid Z) \geq I(X; Z)$.

## Convexity and further identities

::: {.proposition name="Convexity of KL"}
$D(p \| q)$ is convex in the pair $(p, q)$: for $\lambda \in [0, 1]$,
$$D(\lambda p_1 + (1 - \lambda)p_2 \| \lambda q_1 + (1 - \lambda)q_2) \leq \lambda D(p_1 \| q_1) + (1 - \lambda)D(p_2 \| q_2).$$
:::

::: {.proposition name="Concavity of mutual information"}
For fixed conditional $p(y \mid x)$, $I(X; Y)$ is a concave function of $p(x)$. For fixed marginal $p(x)$, $I(X; Y)$ is a convex function of $p(y \mid x)$. This is the workhorse behind the capacity theorems.
:::

## Exercises

::: {.exercise}

So the difference is $\geq 0$ with equality iff $p(x,y)/[p(x)p(y)]$ is constant — i.e.\ equal to 1 — iff independence.
