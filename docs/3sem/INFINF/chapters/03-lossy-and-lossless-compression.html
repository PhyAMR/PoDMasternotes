4  Source coding: compression

Shannon’s motivation for defining entropy was to answer an engineering question: given a source that emits symbols according to a distribution \(p\), what is the minimum number of bits per symbol needed to transmit them? This chapter proves the two source-coding theorems (lossy and lossless) that make the answer \(H(X)\) operational.

4.1 Two ways to compress

There is a fundamental split in the theory:

  • Lossless compression reconstructs every original symbol exactly. Examples: gzip, PNG, FLAC.
  • Lossy compression allows some distortion in reconstruction. Examples: JPEG, MP3, H.264.

The tools for the two problems are different, but both build on the same object: the typical set.

4.2 The typical set and AEP

Fix \(\varepsilon > 0\) and \(n \in \mathbb N\). The \(\varepsilon\)-typical set of length-\(n\) sequences from source \(X \sim p\) is \[A_\varepsilon^{(n)} = \Bigl\{ x^n \in \mathcal X^n : \Bigl|\,{-\tfrac{1}{n}\log_2 p(x^n) - H(X)}\Bigr| \leq \varepsilon \Bigr\}.\] That is, sequences whose empirical entropy is close to \(H(X)\).

For \(X_1, X_2, \ldots\) i.i.d. \(\sim p\):

  1. \(-\tfrac{1}{n}\log_2 p(X_1, \ldots, X_n) \to H(X)\) in probability as \(n \to \infty\).
  2. \(P(A_\varepsilon^{(n)}) \to 1\) as \(n \to \infty\).
  3. \(|A_\varepsilon^{(n)}| \leq 2^{n(H(X) + \varepsilon)}\) and \(|A_\varepsilon^{(n)}| \geq (1 - \varepsilon) 2^{n(H(X) - \varepsilon)}\) for \(n\) sufficiently large.

The AEP is the workhorse of Shannon-style theorems: almost all probability mass concentrates on a set of roughly \(2^{nH}\) sequences, and these sequences are (asymptotically) equiprobable — hence the equipartition.

Remark (Physical meaning). The AEP is the information-theoretic analogue of the ergodic theorem: the “typical” behaviour of a long random sequence is the same as the ensemble-averaged behaviour, up to exponentially small corrections.

4.3 Lossy source coding

Fix \(\varepsilon > 0\). For \(n\) sufficiently large, there exists a code \(\phi_n : \mathcal X^n \to \{0, 1\}^{n(H(X) + \varepsilon)}\) and decoder \(\psi_n\) such that \[P\bigl(\psi_n(\phi_n(X^n)) \neq X^n\bigr) < \varepsilon .\] Conversely, any code with rate \(R < H(X)\) has error probability tending to 1.

Proof sketch. Enumerate the typical set with \(\lceil n(H + \varepsilon)\rceil\) bits and send atypical sequences to a garbage symbol. By AEP the error probability tends to zero. For the converse use Fano’s inequality (below) to show that any rate below \(H\) leaves a positive average distortion.

Compression at rate \(R < H(X)\) is possible only at the cost of a positive distortion; the rate–distortion function \(R(D) = \min_{p(\hat x | x) : \mathbb E d(X, \hat X) \leq D} I(X; \hat X)\) characterises the optimal trade-off for distortion measure \(d\).

4.4 Lossless source coding: symbol codes

For truly lossless compression the constraint is that the code be uniquely decodable.

A code \(\phi : \mathcal X \to \{0, 1\}^*\) is a prefix code if no codeword is a prefix of another. Prefix codes are instantaneously decodable: the decoder recognises each codeword as soon as its last bit arrives.

A set of codeword lengths \(\ell_1, \ldots, \ell_M\) can be realised by a binary prefix code iff \[\sum_{i=1}^{M} 2^{-\ell_i} \leq 1 .\]

Proof. Represent codewords as leaves of a binary tree; a length-\(\ell_i\) leaf occupies a fraction \(2^{-\ell_i}\) of the tree. Prefix-free means the leaves are disjoint, so their measures sum to at most 1. Conversely, given lengths satisfying the inequality, greedily place codewords in a binary tree from shortest to longest.

Kraft’s inequality holds for the strictly larger class of uniquely decodable codes — no gain in achievable code lengths by relaxing the prefix condition.

4.5 Source coding theorem for symbol codes

For any uniquely decodable code \(\phi : \mathcal X \to \{0, 1\}^*\) with expected length \(L = \sum_x p(x)\ell_x\), \[L \geq H(X)/\log_2 2 = H(X) \quad \text{bits/symbol}.\] Conversely there exists a prefix code (a Shannon–Fano code) with \(L < H(X) + 1\).

Proof. Lower bound via Kraft + Gibbs’ inequality; upper bound by choosing \(\ell_x = \lceil \log_2 (1/p(x))\rceil\).

For \(X\) with distribution \((0.5, 0.25, 0.125, 0.125)\): pick \(\ell = (1, 2, 3, 3)\), so codewords \(0, 10, 110, 111\). Expected length \(L = 0.5 + 0.5 + 0.375 + 0.375 = 1.75\) bits. This exactly matches \(H(X) = 1.75\) bits — a rare case where a simple construction is optimal.

4.6 Huffman codes

Shannon–Fano codes are simple but not always optimal. Huffman’s greedy algorithm produces an optimal prefix code for a given source distribution.

Given probabilities \(p_1, \ldots, p_M\):

  1. Repeatedly combine the two lowest-probability symbols into a super-symbol whose probability is their sum.
  2. Assign bits 0 and 1 to the merged edges.
  3. Read the codeword for each leaf by traversing from root to leaf.

The expected length of a Huffman code satisfies \[H(X) \leq L^{Huff} < H(X) + 1,\] and no prefix code (with the same source distribution) has smaller expected length.

The gap of at most 1 bit is due to the ceiling operation. For long blocks the gap becomes negligible: coding \(n\)-tuples of source symbols achieves expected length within \(1/n\) of the entropy per symbol.

For \(X\) with probabilities \((0.4, 0.35, 0.2, 0.05)\): entropy \(H = 1.74\) bits. Huffman merges \(0.05 + 0.2 = 0.25\), then \(0.25 + 0.35 = 0.60\), then \(0.60 + 0.4 = 1.0\). Codewords: \(0, 10, 110, 111\) with lengths \((1, 2, 3, 3)\); expected length \(L = 1.85\) bits, only \(0.11\) above \(H\).

4.7 Universal codes

In practice one rarely knows the source distribution in advance. Universal codes (Lempel–Ziv, arithmetic coding, context-tree weighting) achieve entropy rate for the true distribution without knowing it: they estimate the distribution from the observed prefix and adapt on the fly.

The Lempel–Ziv 1977 sliding-window algorithm, applied to a stationary ergodic source of entropy rate \(H_\infty\), achieves an asymptotic compression rate of \(H_\infty\) per symbol as the window grows. No advance knowledge of the source is needed.

Remark. Modern file formats (gzip, bzip2, xz) are variations on Lempel–Ziv and arithmetic coding. The theoretical guarantee that they hit the entropy limit is a Shannon-theorem consequence of the AEP for ergodic sequences.

4.8 Exercises

Construct a Huffman code for a source with probabilities \((1/2, 1/4, 1/8, 1/16, 1/16)\) and verify it achieves \(H(X)\).

Solution. \(H(X) = 1 + 0.5 + 0.375 + 0.25 + 0.25 = 1.875\) bits. Huffman merges: \((1/16 + 1/16) = 1/8\), then \((1/8 + 1/8) = 1/4\), etc. Final codewords: \(0, 10, 110, 1110, 1111\) with lengths \((1, 2, 3, 4, 4)\); expected length \(L = 1/2 + 1/2 + 3/8 + 1/4 + 1/4 = 1.875\) bits. Exactly \(H\) — because all probabilities are dyadic.

Show that Kraft’s inequality implies \(\sum_i 2^{-\ell_i} = 1\) for a complete prefix code (one where every internal node has two children).

Solution. Each leaf \(i\) of the binary tree at depth \(\ell_i\) occupies a fraction \(2^{-\ell_i}\) of the tree, and a complete binary tree has its leaves partitioning the entire tree, so \(\sum_i 2^{-\ell_i} = 1\). An incomplete code (missing some leaves) gives strict inequality.

Compute \(R(D)\) for a Gaussian source with variance \(\sigma^2\) and squared-error distortion \(d(x, \hat x) = (x - \hat x)^2\).

Solution. The rate–distortion function is \(R(D) = \tfrac12 \log_2(\sigma^2/D)\) for \(0 \leq D \leq \sigma^2\), and \(R(D) = 0\) for \(D \geq \sigma^2\). It is achieved by a jointly Gaussian test channel with reverse-water-filling on the eigenvalues.

4.9 Callouts

The source-coding theorem is asymptotic: it says the entropy is achievable in the limit of long blocks. Finite-block codes always leave a gap, typically \(O(\log n / n)\).

For a single-symbol Huffman code the code length is \(\lceil \log_2 (1/p_i) \rceil\); if this is not achievable, the gap is at most 1 bit and vanishes for long-block codes.

Real-world compressors use arithmetic coding rather than Huffman when the source distribution has one very-high-probability symbol, because arithmetic coding can produce non-integer code lengths and achieve entropy exactly.

Universal codes give the asymptotic compression rate. On short inputs (a single tweet) they often expand the data due to header overhead. Don’t benchmark compressors on toy examples.
