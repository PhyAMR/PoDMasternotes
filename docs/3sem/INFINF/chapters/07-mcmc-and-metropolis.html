8  Markov Chain Monte Carlo and Metropolis

Part II of the course turns from communication to inference. The central computational problem is this: we want expectations under a distribution \(\pi\) that we can evaluate only up to a normalisation constant — a Bayesian posterior, or a Boltzmann distribution — in high dimension. Direct integration is hopeless, and independent sampling is usually impossible, but dependent sampling via a cleverly designed Markov chain works. This chapter introduces the Monte Carlo idea, elementary samplers, the Metropolis algorithm, and the theory of its convergence and autocorrelation.

8.1 Inference requires integrals

In Bayesian inference, data \(\mathbf y\) are explained by parameters \(\boldsymbol\theta\) and latent variables \(\mathbf z\), and everything we learn is encoded in the posterior \[f(\boldsymbol\theta, \mathbf z \mid \mathbf y) = \frac{f(\mathbf y \mid \boldsymbol\theta, \mathbf z)\,f(\boldsymbol\theta, \mathbf z)}{f(\mathbf y)}, \qquad f(\mathbf y) = \int d\boldsymbol\theta\,d\mathbf z\,f(\mathbf y \mid \boldsymbol\theta, \mathbf z)f(\boldsymbol\theta, \mathbf z).\] Any posterior summary is an integral of the form \[\mathbb E[g \mid \mathbf y] = \int d\boldsymbol\theta\,d\mathbf z\; g(\boldsymbol\theta, \mathbf z)\,f(\boldsymbol\theta, \mathbf z \mid \mathbf y).\] For example, the posterior mean of the parameters uses \(g = \boldsymbol\theta\); posterior variances, credible intervals (\(g\) = indicator), and predictive distributions are all of this form. The normalisation \(f(\mathbf y)\) (the marginal likelihood or evidence) is itself such an integral, usually intractable.

8.1.1 The curse of dimensionality

The obvious numerical approach is to discretise. In \(d\) dimensions, cover the integration region with \(N\) cells of side \(\epsilon\) and use a Riemann sum, \[\int d\mathbf x\,f(\mathbf x) = \sum_i f(\mathbf x_i)\,\epsilon^d + O(\epsilon).\] Since \(N \propto V/\epsilon^d\), the resolution is \(\epsilon \propto N^{-1/d}\), so the error scales as \(O(N^{-1/d})\): for fixed accuracy, the number of cells grows exponentially with \(d\). With 10 points per axis, a 20-dimensional grid already has \(10^{20}\) cells. This is the curse of dimensionality: volume grows exponentially with dimension, so any uniform covering of the space becomes sparse.

8.2 The Monte Carlo approach

Monte Carlo methods (Metropolis, Ulam, von Neumann, early 1950s) replace sums over cells by sums over random samples.

Let \(B\) be the disc of radius \(1/2\) centred at \((1/2, 1/2)\); \(\operatorname{Vol}(B) = \pi/4\). If \((X, Y) \sim \mathcal U([0,1]^2)\), \[\operatorname{Vol}(B) = P\bigl((X, Y) \in B\bigr) = \mathbb E\bigl[\chi_B(X, Y)\bigr],\] with \(\chi_B\) the indicator function. Draw \(N\) i.i.d. uniform points and let \(M_N = \frac1N\sum_i \chi_B(X_i, Y_i)\) — the fraction of darts inside the disc. Then \[\mathbb E[M_N] = \operatorname{Vol}(B), \qquad \operatorname{Var}[M_N] = \frac{\operatorname{Var}[\chi_B]}{N} = \frac{p(1-p)}{N},\quad p = \tfrac\pi4 .\] The estimate is unbiased, with error \(\approx 0.41/\sqrt N\). In two dimensions this is no better than the Riemann sum (\(N^{-1/2}\) as well), but for the volume of a ball in \(d\) dimensions the grid error degrades to \(N^{-1/d}\) while the Monte Carlo error stays \(N^{-1/2}\).

Given i.i.d. samples \(X_1, \ldots, X_N \sim f\) and a function \(g\) with finite variance, the Monte Carlo estimator of \(\mathbb E_f[g] = \int d\mathbf x\,f(\mathbf x)g(\mathbf x)\) is \[M_N = \frac1N\sum_{i=1}^{N} g(X_i), \qquad \mathbb E[M_N] = \mathbb E_f[g], \qquad \operatorname{Var}[M_N] = \frac{\operatorname{Var}_f[g]}{N}.\] By the law of large numbers \(M_N \to \mathbb E_f[g]\) almost surely; by the CLT the error is \(\approx \sigma_g/\sqrt N\).

The rate \(1/\sqrt N\) is dimension-free. The price is that we must be able to sample from \(f\) — and that is the hard part.

8.3 Simple ways to sample a distribution

All samplers are built from a single primitive: a generator of uniform random numbers \(U \sim \mathcal U(0, 1)\).

8.3.1 Inverse-CDF sampling

Let \(X\) have a continuous, invertible CDF \(F_X\). If \(U \sim \mathcal U(0,1)\), then \(X = F_X^{-1}(U)\) has CDF \(F_X\).

Proof. Let \(Z = F_X(X)\). Then \(F_Z(z) = P(F_X(X) \leq z) = P(X \leq F_X^{-1}(z)) = F_X(F_X^{-1}(z)) = z\) on \([0, 1]\), so \(Z \sim \mathcal U(0, 1)\). Reading the argument backwards, \(F_X^{-1}(U)\) is distributed as \(X\).

Exponential. \(f(x) = \lambda e^{-\lambda x}\), \(F(x) = 1 - e^{-\lambda x}\), so \(X = -\tfrac1\lambda\log(1 - U)\) (or \(-\tfrac1\lambda\log U\), since \(1 - U \sim U\)).

Cauchy. \(F(x) = \tfrac12 + \tfrac1\pi\arctan x\), so \(X = \tan\bigl(\pi(U - \tfrac12)\bigr)\).

The Gaussian has no closed-form inverse CDF; the Box–Muller transform \(X = \sqrt{-2\ln U_1}\cos(2\pi U_2)\) works instead, using a 2-D change of variables.

8.3.2 Rejection sampling

When \(F^{-1}\) is unavailable, we can sample uniformly under the graph of the density.

Let \(f_X\) be (essentially) supported on \(I = [a, b]\), and let \(M \geq \max_x f_X(x)\).

  1. Draw \(Z_1, Z_2 \sim \mathcal U(0,1)\) and set \(Y = a + (b - a)Z_1\) (uniform on \(I\)).
  2. Accept \(Y\) if \(Z_2 \leq f_X(Y)/M\); otherwise reject it and start again.

Values are accepted with probability proportional to \(f_X(y)\), so the accepted values are distributed as \(X\).

Proof. \[P(Y \leq x, \text{accept}) = \frac{1}{b - a}\int_a^x dy\int_0^1 dz_2\,\chi\Bigl(z_2 \leq \frac{f_X(y)}{M}\Bigr) = \frac{1}{(b-a)M}\int_a^x f_X(y)\,dy = \frac{F_X(x)}{(b-a)M},\] and \(P(\text{accept}) = \frac{1}{(b-a)M}\). Dividing, \(P(Y \leq x \mid \text{accept}) = F_X(x)\).

More generally, with any proposal density \(q\) such that \(f \leq Mq\), draw \(Y \sim q\) and accept with probability \(f(Y)/(Mq(Y))\); the acceptance probability is \(1/M\). The method also works if \(f\) is known only up to normalisation (then \(M\) just absorbs the constant).

Sample \(X \sim \mathcal N(0, \sigma^2)\) on \([-\kappa\sigma, \kappa\sigma]\) with \(M = \max f = (2\pi\sigma^2)^{-1/2}\): \[P(\text{accept}) = \frac{1}{2\kappa\sigma\,M} = \frac{\sqrt{2\pi}}{2\kappa}.\] For \(\kappa = 4\) this is \(0.31\). In \(d\) dimensions with \(\Sigma = \sigma^2 I\), the box has volume \((2\kappa\sigma)^d\) and \(M = (2\pi\sigma^2)^{-d/2}\), so \[P(\text{accept}) = \Bigl(\frac{\sqrt{2\pi}}{2\kappa}\Bigr)^d,\] which for \(\kappa = 4\) is \(9 \times 10^{-6}\) at \(d = 10\) and \(8 \times 10^{-11}\) at \(d = 20\). The acceptance rate decays exponentially with dimension. The same happens for the darts example: the fraction of the unit cube occupied by the inscribed ball is \(\pi/4 \approx 0.79\) in \(d = 2\), \(0.52\) in \(d = 3\), but \(0.0025\) in \(d = 10\).

Remark. In high dimension, almost all the volume of a box (or of any simple envelope) lies where the target has negligible mass — the “concentration of measure”. Independent proposals are doomed. The way out is to make local moves from a point already in the high-probability region: Markov chains.

8.4 Markov Chain Monte Carlo

The MCMC idea: construct a Markov chain whose stationary distribution is the target \(\pi\), run it until it reaches equilibrium, and use its trajectory as a (correlated) sample. By Chapter 6, an ergodic chain satisfies \(p_{X_n} \to \pi\) for \(n \to \infty\), so after a transient (burn-in) the states \(X_n, X_{n+1}, \ldots\) are distributed according to \(\pi\). Relabelling the first post-burn-in state as \(X_1\), the ergodic theorem gives \[G_n = \frac1n\sum_{i=1}^n g(X_i) \xrightarrow[n\to\infty]{} \mathbb E_\pi[g].\] To compute posterior expectations, we need a chain with stationary distribution \(\pi(\boldsymbol\theta, \mathbf z) = f(\boldsymbol\theta, \mathbf z \mid \mathbf y)\). The question is how to build one for an arbitrary \(\pi\).

8.5 The Metropolis algorithm

8.5.1 Discrete state space

Let \(X_n \in \{1, \ldots, K\}\) and let \(\pi\) be the target. Choose a symmetric proposal matrix \(T\), with \(T_{ij}\) the probability of proposing a jump \(j \to i\): \[T_{ij} = T_{ji}, \qquad T_{ii} = 0, \qquad \textstyle\sum_i T_{ij} = 1.\] A proposed jump \(j \to i\) is accepted with probability \[A_{ij} = \min\Bigl\{1, \frac{\pi_i}{\pi_j}\Bigr\}:\] uphill moves (towards more probable states) are always accepted, downhill moves with probability \(\pi_i/\pi_j < 1\). If rejected, the chain stays at \(j\). The total rejection probability from \(j\) is \(R_j = 1 - \sum_k A_{kj}T_{kj}\), and the transition matrix is \[P_{ij} = T_{ij}A_{ij} + R_j\,\delta_{ij}.\]

\(P_{ij}\,\pi_j = P_{ji}\,\pi_i\) for all \(i, j\). Hence \(\pi\) is a stationary distribution of the chain, and if the chain is ergodic it is the limiting distribution.

Proof. For \(i = j\) there is nothing to prove. For \(i \neq j\), \[P_{ij}\pi_j = T_{ij}\min\Bigl\{1, \frac{\pi_i}{\pi_j}\Bigr\}\pi_j = T_{ij}\min\{\pi_j, \pi_i\} = T_{ji}\min\Bigl\{\frac{\pi_j}{\pi_i}, 1\Bigr\}\pi_i = P_{ji}\pi_i,\] using the symmetry of \(T\) and of \(\min\). Stationarity follows from Chapter 6.

Target \(\pi = (0.5, 0.3, 0.2)\), proposal \(T_{ij} = 1/2\) for \(i \neq j\). Off-diagonal entries \(P_{ij} = \tfrac12\min(1, \pi_i/\pi_j)\):

\(P_{ij}\) from 1 from 2 from 3
to 1 \(R_1\) \(\tfrac12\) \(\tfrac12\)
to 2 \(\tfrac12\cdot\tfrac{3}{5} = 0.3\) \(R_2\) \(\tfrac12\)
to 3 \(\tfrac12\cdot\tfrac{2}{5} = 0.2\) \(\tfrac12\cdot\tfrac{2}{3} = \tfrac13\) \(R_3\)

with \(R_1 = 1 - 0.3 - 0.2 = 0.5\), \(R_2 = 1 - \tfrac12 - \tfrac13 = \tfrac16\), \(R_3 = 1 - \tfrac12 - \tfrac12 = 0\). Check stationarity row by row: \(0.5\cdot0.5 + 0.5\cdot0.3 + 0.5\cdot0.2 = 0.5\) \(\checkmark\); \(0.3\cdot0.5 + \tfrac16\cdot0.3 + 0.5\cdot 0.2 = 0.15 + 0.05 + 0.1 = 0.3\) \(\checkmark\); \(0.2\cdot0.5 + \tfrac13\cdot 0.3 + 0 = 0.2\) \(\checkmark\). Detailed balance, e.g. \(P_{21}\pi_1 = 0.3 \cdot 0.5 = 0.15 = P_{12}\pi_2 = 0.5\cdot 0.3\) \(\checkmark\).

8.5.2 Continuous state space

The same construction works in \(\mathbb R^d\). With a symmetric proposal density \(T(\mathbf x' \mid \mathbf x) = T(\mathbf x \mid \mathbf x')\) and acceptance \[A(\mathbf x' \mid \mathbf x) = \min\Bigl\{1, \frac{\pi(\mathbf x')}{\pi(\mathbf x)}\Bigr\},\] the rejection probability is \(R(\mathbf x) = \int d\mathbf x'\,T(\mathbf x'\mid\mathbf x)\bigl(1 - A(\mathbf x'\mid\mathbf x)\bigr)\) and the transition kernel is \[P(\mathbf x' \mid \mathbf x) = A(\mathbf x' \mid \mathbf x)\,T(\mathbf x' \mid \mathbf x) + \delta(\mathbf x' - \mathbf x)\,R(\mathbf x).\] Detailed balance \(P(\mathbf x'\mid\mathbf x)\pi(\mathbf x) = P(\mathbf x\mid\mathbf x')\pi(\mathbf x')\) follows exactly as in the discrete case.

From the current state \(\mathbf x\):

  1. propose \(\mathbf x' \sim T(\cdot \mid \mathbf x)\), e.g. \(\mathbf x' = \mathbf x + \sigma\boldsymbol\xi\), \(\boldsymbol\xi \sim \mathcal N(0, I)\);
  2. draw \(u \sim \mathcal U(0,1)\); if \(u < \pi(\mathbf x')/\pi(\mathbf x)\), move to \(\mathbf x'\); otherwise stay at \(\mathbf x\) (and record \(\mathbf x\) again as the next sample).

If \(\pi(\mathbf x) = f(\mathbf x \mid \mathbf y) = f(\mathbf x, \mathbf y)/f(\mathbf y)\), then \[A(\mathbf x' \mid \mathbf x) = \min\Bigl\{1, \frac{f(\mathbf x', \mathbf y)}{f(\mathbf x, \mathbf y)}\Bigr\} = \min\Bigl\{1, \frac{f(\mathbf y \mid \mathbf x')f(\mathbf x')}{f(\mathbf y \mid \mathbf x)f(\mathbf x)}\Bigr\}:\] only the unnormalised posterior (likelihood × prior) is needed. The intractable marginal likelihood \(f(\mathbf y)\) cancels.

This is why Metropolis revolutionised Bayesian statistics (and, earlier, statistical physics, where the unknown constant is the partition function \(Z\)).

8.5.3 Metropolis–Hastings

With a non-symmetric proposal \(q(\mathbf x' \mid \mathbf x)\), detailed balance is restored by the Hastings correction: \[A(\mathbf x' \mid \mathbf x) = \min\Bigl\{1, \frac{\pi(\mathbf x')\,q(\mathbf x \mid \mathbf x')}{\pi(\mathbf x)\,q(\mathbf x' \mid \mathbf x)}\Bigr\}.\] The ratio of proposal densities compensates for the bias of proposing some moves more often than their reverses. Gibbs sampling (Chapter 8) and HMC (Chapter 11) are both special cases.

We observe \(k = 7\) heads in \(n = 10\) tosses of a coin with unknown bias \(\theta\), and use a uniform prior. The unnormalised posterior is \(\pi(\theta) \propto \theta^7(1-\theta)^3\) on \([0,1]\) (the exact answer is \(\text{Beta}(8, 4)\), with mean \(8/12 = 0.667\)). Metropolis with \(\theta' = \theta + 0.1\,\xi\): accept with probability \(\min\{1, \pi(\theta')/\pi(\theta)\}\), with \(\pi(\theta') = 0\) (always reject) if \(\theta' \notin [0,1]\). Note that rejected proposals outside the support must still be counted as a repeated sample of \(\theta\). A run of \(10^5\) steps reproduces the Beta mean and variance (\(8\cdot4/(12^2\cdot 13) \approx 0.0171\)) to about two decimal places.

Target \(\pi(x) \propto e^{-x^2/2}\), proposal \(x' = x + \sigma_p\xi\), acceptance \(\min\{1, e^{(x^2 - x'^2)/2}\}\). Tiny \(\sigma_p\): almost every move is accepted but the chain crawls (random walk with tiny steps). Huge \(\sigma_p\): proposals land in the tails and are almost all rejected; the chain sits still. The optimum is \(\sigma_p \approx 2.4\), with acceptance rate \(\approx 44\%\).

8.6 Convergence and correlation

The Metropolis chain is guaranteed to converge to \(\pi\). Two practical issues remain:

  • Convergence time: how long is the transient before equilibrium?
  • Autocorrelation: the samples are identically distributed but not independent, so they carry less information than an i.i.d. sample of the same size.

Both are controlled by the spectrum of the transition matrix. We work with a finite state space; the continuous case is analogous, though the operator theory is more delicate.

8.6.1 Spectrum of a reversible chain

\(\boldsymbol\pi\) is an eigenvector of \(P\) with eigenvalue 1, but \(P\) is not symmetric, so its spectrum is not obviously real. Detailed balance fixes this. Let \(\Lambda = \operatorname{diag}(\sqrt{\pi_1}, \ldots, \sqrt{\pi_K})\) and \[V = \Lambda^{-1}P\Lambda, \qquad V_{ij} = P_{ij}\sqrt{\pi_j/\pi_i}.\] By detailed balance, \(V_{ij} = P_{ij}\pi_j/\sqrt{\pi_i\pi_j} = P_{ji}\pi_i/\sqrt{\pi_i\pi_j} = V_{ji}\): \(V\) is symmetric. Hence \(V = WDW^\top\) with \(D = \operatorname{diag}(\lambda_1, \ldots, \lambda_K)\) real and \(W\) orthogonal (columns \(\mathbf w_k\)). Since \(P = \Lambda V\Lambda^{-1}\) is similar to \(V\), it has the same real eigenvalues, with

  • right eigenvectors \(\boldsymbol\phi_k = \Lambda\mathbf w_k\): \(P\boldsymbol\phi_k = \Lambda V\mathbf w_k = \lambda_k\boldsymbol\phi_k\);
  • left eigenvectors \(\boldsymbol\psi_k = \Lambda^{-1}\mathbf w_k\): \(\boldsymbol\psi_k^\top P = \mathbf w_k^\top V\Lambda^{-1} = \lambda_k\boldsymbol\psi_k^\top\);
  • biorthonormality \(\boldsymbol\psi_k^\top\boldsymbol\phi_l = \mathbf w_k^\top\mathbf w_l = \delta_{kl}\).

The powers of \(P\) have the spectral decomposition \[P^n = \Lambda V^n\Lambda^{-1} = \sum_k \lambda_k^n\,\boldsymbol\phi_k\boldsymbol\psi_k^\top .\]

All eigenvalues satisfy \(|\lambda_k| \leq 1\). The eigenvalue \(1\) has left eigenvector \(\mathbf 1 = (1, \ldots, 1)\) and right eigenvector \(\boldsymbol\pi\); for an ergodic chain it is simple and all others satisfy \(|\lambda_k| < 1\).

Proof. From \(P^n\boldsymbol\phi_k = \lambda_k^n\boldsymbol\phi_k\), for each component \(j\): \(|\lambda_k|^n|(\boldsymbol\phi_k)_j| \leq \sum_l (P^n)_{jl}|(\boldsymbol\phi_k)_l| \leq \gamma\sum_l (P^n)_{jl}\), with \(\gamma = \max_l|(\boldsymbol\phi_k)_l|\). Choosing \(j\) where \(|(\boldsymbol\phi_k)_j| = \gamma\) gives \(|\lambda_k|^n \leq \sum_l (P^n)_{jl} \leq K\) (entries of \(P^n\) are probabilities). A bound uniform in \(n\) forces \(|\lambda_k| \leq 1\). The left eigenvector \(\mathbf 1\) expresses \(\sum_i P_{ij} = 1\); simplicity for ergodic chains is Perron–Frobenius.

Order the eigenvalues as \(1 = \lambda_1 > |\lambda_2| \geq |\lambda_3| \geq \cdots\).

8.6.2 Convergence time

Start the chain from \(\mathbf p^{(0)}\). Since \(\boldsymbol\phi_1 = \boldsymbol\pi\) and \(\boldsymbol\psi_1 = \mathbf 1\) (so \(\boldsymbol\psi_1^\top\mathbf p^{(0)} = 1\)), \[\mathbf p^{(n)} = P^n\mathbf p^{(0)} = \boldsymbol\pi + \sum_{k \geq 2}\lambda_k^n\,\boldsymbol\phi_k\,(\boldsymbol\psi_k^\top\mathbf p^{(0)}) = \boldsymbol\pi + O(e^{-n/\tau_{\text{conv}}}),\] with \[\tau_{\text{conv}} = -\frac{1}{\log|\lambda_2|} = -\frac{1}{\log(1 - \delta\lambda)} \simeq \frac{1}{\delta\lambda}, \qquad \delta\lambda = 1 - |\lambda_2| .\] The convergence time is the inverse spectral gap: the smaller the gap, the longer the burn-in.

In the three-state Metropolis example, \(\operatorname{tr}P = 2/3\) and \(\det P = 0\), so the eigenvalues are \(1\), \(0\) and \(-1/3\): \(|\lambda_2| = 1/3\) and the chain equilibrates within a few steps (each step shrinks the deviation from \(\boldsymbol\pi\) by a factor 3). For the two-state chain of Chapter 6, \(\lambda_2 = 1 - a - b\): with \(a = b = 0.01\), \(\tau_{\text{conv}} \approx 50\) steps.

8.6.3 The step size of random-walk Metropolis

For a continuous Metropolis chain the transition operator splits as \(V = K + M\), with \[(Kf)(\mathbf x) = \int d\mathbf x'\,T(\mathbf x'\mid\mathbf x)A(\mathbf x'\mid\mathbf x)f(\mathbf x'), \qquad (Mf)(\mathbf x) = R(\mathbf x)f(\mathbf x).\] The spectrum of \(M\) is the range of the rejection probability, \([0, \max R]\), a continuum; \(K\) contributes isolated eigenvalues. Which part sets the gap depends on the proposal width \(\sigma\):

  • Small steps. \(T(\mathbf x'\mid\mathbf x) \to \delta(\mathbf x' - \mathbf x)\) as \(\sigma \to 0\), so \(Kf = f + O(\sigma^2)\): the top eigenvalues of \(K\) are \(1 - O(\sigma^2)\) and the gap closes as \(\sigma^2\). The chain is a slow random walk: covering a distance \(L\) takes \(\sim (L/\sigma)^2\) steps.
  • Large steps. Most proposals land in low-probability regions; \(R(\mathbf x) \to 1\), the top of the spectrum of \(M\) approaches 1, and the chain gets stuck.

In \(D\) dimensions, Taylor-expanding \(A(\mathbf x'\mid\mathbf x)\) around \(\mathbf x' = \mathbf x\) inside \(R(\mathbf x) = 1 - \int d^D\mathbf x'\,A(\mathbf x'\mid\mathbf x)\,\mathcal N(\mathbf x'; \mathbf x, \sigma^2 I)\) gives \[R(\mathbf x) = O(D\sigma^2):\] each of the \(D\) directions contributes a term of order \(\sigma^2\). To keep the rejection rate bounded away from 1 we need \(\sigma^2 \lesssim 1/D\). The optimal step size shrinks as \(\sigma \propto D^{-1/2}\), and the number of steps needed to traverse the distribution grows as \(\sim D\).

For random-walk Metropolis on a \(D\)-dimensional target with i.i.d. components, as \(D \to \infty\) the optimal proposal is \(\sigma = 2.38/\sqrt D\) (in units of the target’s standard deviation), and the corresponding acceptance rate is \(\alpha^* \approx 0.234\).

The rule of thumb “aim for 20–40% acceptance” (about 44% in one dimension) comes from this result and works surprisingly well in practice.

8.6.4 Autocorrelation and effective sample size

After burn-in, \(X_n, X_{n+1}, \ldots\) are distributed according to \(\pi\) but are autocorrelated. For any (not necessarily independent) identically distributed sample, \[\operatorname{Var}\Bigl[\frac1n\sum_i g(X_i)\Bigr] = \frac1{n^2}\Bigl[\sum_i\operatorname{Var}[g(X_i)] + \sum_i\sum_{j\neq i}\operatorname{Cov}[g(X_i), g(X_j)]\Bigr].\]

  • Independent samples: covariances vanish and the variance is \(\operatorname{Var}[g]/n\), the familiar \(1/\sqrt n\) error.
  • Perfectly correlated samples: all covariances equal \(\operatorname{Var}[g]\) and the variance is \(\operatorname{Var}[g]\) — no improvement with \(n\) at all: it is as if we had a single sample.

A stationary chain lies in between. Its covariance depends only on the lag, \(\operatorname{Cov}[g(X_i), g(X_j)] = c_{|i-j|}\), and typically decays to zero beyond some lag \(\tau\), so the covariance matrix is banded around the diagonal.

\[A_g = \frac{1}{\operatorname{Var}[g]}\sum_{j=-\infty}^{\infty}\operatorname{Cov}[g(X_i), g(X_{i+j})] = 1 + 2\sum_{j=1}^\infty\frac{c_j}{c_0}.\]

Summing the banded covariance matrix row by row, rows away from the boundaries contribute \(c_0A_g\) each; boundary rows contribute \(O(\tau)\) in total. Hence \[\operatorname{Var}\Bigl[\frac1n\sum_i g(X_i)\Bigr] = \frac{\operatorname{Var}[g]\,A_g}{n} + O\Bigl(\frac{1}{n^2}\Bigr) = \frac{\operatorname{Var}[g]}{n_g^{\text{eff}}} + O\Bigl(\frac1{n^2}\Bigr), \qquad n^{\text{eff}}_g = \frac{n}{A_g}.\] A correlated chain of length \(n\) is worth \(n/A_g\) independent samples — the effective sample size.

Let \(X_{t+1} = \rho X_t + \sqrt{1 - \rho^2}\,\xi_t\) with \(\xi_t \sim \mathcal N(0,1)\) — a Markov chain with stationary \(\mathcal N(0, 1)\) and \(c_j = \rho^{|j|}\). Then \[A = 1 + 2\sum_{j\geq1}\rho^j = \frac{1 + \rho}{1 - \rho}.\] For \(\rho = 0.9\), \(A = 19\): \(10^4\) steps are worth only about 530 independent draws. For \(\rho = 0.99\), \(A = 199\).

8.6.5 Autocorrelation from the spectrum

Standardise \(h = (g - \mu_g)/\sigma_g\), so \(\mathbb E_\pi[h] = 0\), \(\operatorname{Var}[h] = 1\). At equilibrium, \(P(X_n = i, X_0 = j) = (P^n)_{ij}\pi_j\), so \[\operatorname{Cov}[h(X_n), h(X_0)] = \sum_{ij}h_ih_j\pi_j(P^n)_{ij} = \sum_{k}\lambda_k^n\sum_{ij}h_ih_j\pi_j(\boldsymbol\phi_k)_i(\boldsymbol\psi_k)_j .\] The \(k = 1\) term is \(\sum_{ij}h_ih_j\pi_i\pi_j = (\mathbb E_\pi h)^2 = 0\). Summing the geometric series \(\sum_{n \geq 1}\lambda_k^n = \lambda_k/(1 - \lambda_k)\), \[A_g = 1 + 2\sum_{n\geq1}\operatorname{Cov}[h(X_n), h(X_0)] = \sum_{k \geq 2}\frac{1 + \lambda_k}{1 - \lambda_k}\sum_{ij}h_ih_j\pi_j(\boldsymbol\phi_k)_i(\boldsymbol\psi_k)_j ,\] where we used \(1 = \operatorname{Var}[h] = \sum_{k\geq2}\sum_{ij}h_ih_j\pi_j(\boldsymbol\phi_k)_i(\boldsymbol\psi_k)_j\). In terms of the orthonormal eigenvectors of \(V\), the weights are \(a_k^2 = \bigl(\sum_i\sqrt{\pi_i}\,h_i(\mathbf w_k)_i\bigr)^2 \geq 0\) with \(\sum_{k\geq2}a_k^2 = 1\), so \[A_g = \sum_{k\geq 2}a_k^2\,\frac{1 + \lambda_k}{1 - \lambda_k}.\] The autocorrelation time is a weighted average of \((1 + \lambda_k)/(1 - \lambda_k)\): eigenvalues close to 1 (small gaps) inflate it, and the observable “feels” a slow mode only to the extent that it overlaps with it. The AR(1) result \(A = (1 + \rho)/(1 - \rho)\) is the single-mode case. (Negative eigenvalues give \(A_g < 1\): antithetic, “better than independent” samples are possible.)

8.7 Practical MCMC

  • Burn-in. Discard the transient (several \(\tau_{\text{conv}}\)); check that discarding more does not change the estimate.
  • Trace plots of \(g(X_t)\) vs \(t\) should look like stationary noise around a constant mean.
  • Effective sample size: estimate \(A_g\) from the empirical autocorrelation (truncating the sum when it becomes noisy) and report \(n/A_g\), not \(n\).
  • Gelman–Rubin \(\hat R\): run several chains from over-dispersed starting points and compare within-chain and between-chain variances; \(\hat R \approx 1\) (in practice \(< 1.01\)) indicates convergence.
  • Thinning (keeping one sample every \(k\)) reduces storage but never increases the information in the chain.

8.8 Exercises

Prove that with a symmetric proposal the Metropolis–Hastings acceptance reduces to \(\min\{1, \pi(y)/\pi(x)\}\), and verify detailed balance for \(x \neq y\).

Solution. With \(q(y\mid x) = q(x\mid y)\) the \(q\)’s cancel in the Hastings ratio. Then \(\pi(x)q(y\mid x)\min\{1, \pi(y)/\pi(x)\} = q(y\mid x)\min\{\pi(x), \pi(y)\}\), which is symmetric in \(x \leftrightarrow y\) because \(q\) is symmetric: this is \(\pi(y)P(x \mid y)\).

Using the inverse-CDF method, give an algorithm to sample from \(f(x) = 2x\) on \([0, 1]\). Then design a rejection sampler for the same density using the uniform envelope and compute its acceptance rate.

Solution. \(F(x) = x^2\), so \(X = \sqrt U\). For rejection: \(M = \max f = 2\), \(b - a = 1\), so \(P(\text{accept}) = 1/((b-a)M) = 1/2\): draw \(Y \sim \mathcal U(0,1)\), accept if \(U_2 \leq Y\).

A Metropolis chain has \(A_g = 25\) for the observable \(g\). How long must the chain be (after burn-in) to estimate \(\mathbb E[g]\) to within \(0.01\sigma_g\) (one standard error)?

Solution. Standard error \(= \sigma_g\sqrt{A_g/n} = 0.01\sigma_g \Rightarrow n = A_g/10^{-4} = 2.5 \times 10^5\) steps, versus \(10^4\) for i.i.d. sampling.

For the two-state chain with \(P(0\to1) = a\), \(P(1\to0) = b\) and the observable \(g(x) = x\), compute \(A_g\).

Solution. Only one non-trivial eigenvalue, \(\lambda_2 = 1 - a - b\), and the centred \(g\) lies entirely along its eigenvector, so \(A_g = (1 + \lambda_2)/(1 - \lambda_2) = (2 - a - b)/(a + b)\). For \(a = b = 0.5\) (\(\lambda_2 = 0\), i.i.d.) \(A_g = 1\); for \(a = b = 0.01\), \(A_g = 99\); for \(a = b = 0.9\) (\(\lambda_2 = -0.8\), alternating) \(A_g = 1/9\).

8.9 Callouts

Metropolis is not the fastest MCMC algorithm; it is the most general. It needs only pointwise evaluations of the unnormalised target. Specialised samplers (Gibbs, HMC) exploit more structure and do much better.

The MCMC estimator is biased by the initial transient. Always discard a burn-in. And the error bar is \(\sigma_g\sqrt{A_g/n}\), not \(\sigma_g/\sqrt n\): forgetting \(A_g\) gives wildly overconfident results.

A chain that “looks converged” may still be missing modes of a multimodal target: trace plots detect within-mode stationarity, not between-mode mixing. The spectral gap of a chain with well-separated modes is exponentially small in the barrier height.

Effective sample size per unit of computation is the right figure of merit for comparing samplers.

Part II of the course turns from communication to inference. The central computational problem is this: we want expectations under a distribution $\pi$ that we can evaluate only *up to a normalisation constant* — a Bayesian posterior, or a Boltzmann distribution — in high dimension. Direct integration is hopeless, and independent sampling is usually impossible, but *dependent* sampling via a cleverly designed Markov chain works. This chapter introduces the Monte Carlo idea, elementary samplers, the Metropolis algorithm, and the theory of its convergence and autocorrelation.

## Inference requires integrals

In Bayesian inference, data $\mathbf y$ are explained by parameters $\boldsymbol\theta$ and latent variables $\mathbf z$, and everything we learn is encoded in the posterior
$$f(\boldsymbol\theta, \mathbf z \mid \mathbf y) = \frac{f(\mathbf y \mid \boldsymbol\theta, \mathbf z)\,f(\boldsymbol\theta, \mathbf z)}{f(\mathbf y)}, \qquad f(\mathbf y) = \int d\boldsymbol\theta\,d\mathbf z\,f(\mathbf y \mid \boldsymbol\theta, \mathbf z)f(\boldsymbol\theta, \mathbf z).$$
Any posterior summary is an integral of the form
$$\mathbb E[g \mid \mathbf y] = \int d\boldsymbol\theta\,d\mathbf z\; g(\boldsymbol\theta, \mathbf z)\,f(\boldsymbol\theta, \mathbf z \mid \mathbf y).$$
For example, the posterior mean of the parameters uses $g = \boldsymbol\theta$; posterior variances, credible intervals ($g$ = indicator), and predictive distributions are all of this form. The normalisation $f(\mathbf y)$ (the **marginal likelihood** or **evidence**) is itself such an integral, usually intractable.

### The curse of dimensionality

The obvious numerical approach is to discretise. In $d$ dimensions, cover the integration region with $N$ cells of side $\epsilon$ and use a Riemann sum,
$$\int d\mathbf x\,f(\mathbf x) = \sum_i f(\mathbf x_i)\,\epsilon^d + O(\epsilon).$$
Since $N \propto V/\epsilon^d$, the resolution is $\epsilon \propto N^{-1/d}$, so the error scales as $O(N^{-1/d})$: **for fixed accuracy, the number of cells grows exponentially with $d$.** With 10 points per axis, a 20-dimensional grid already has $10^{20}$ cells. This is the **curse of dimensionality**: volume grows exponentially with dimension, so any uniform covering of the space becomes sparse.

## The Monte Carlo approach

Monte Carlo methods (Metropolis, Ulam, von Neumann, early 1950s) replace sums over cells by sums over *random samples*.

::: {.example name="Area of a disc by throwing darts"}
Let $B$ be the disc of radius $1/2$ centred at $(1/2, 1/2)$; $\operatorname{Vol}(B) = \pi/4$. If $(X, Y) \sim \mathcal U([0,1]^2)$,
$$\operatorname{Vol}(B) = P\bigl((X, Y) \in B\bigr) = \mathbb E\bigl[\chi_B(X, Y)\bigr],$$
with $\chi_B$ the indicator function. Draw $N$ i.i.d. uniform points and let $M_N = \frac1N\sum_i \chi_B(X_i, Y_i)$ — the fraction of darts inside the disc. Then
$$\mathbb E[M_N] = \operatorname{Vol}(B), \qquad \operatorname{Var}[M_N] = \frac{\operatorname{Var}[\chi_B]}{N} = \frac{p(1-p)}{N},\quad p = \tfrac\pi4 .$$
The estimate is unbiased, with error $\approx 0.41/\sqrt N$. In two dimensions this is no better than the Riemann sum ($N^{-1/2}$ as well), but for the volume of a ball in $d$ dimensions the grid error degrades to $N^{-1/d}$ while the Monte Carlo error **stays $N^{-1/2}$**.
:::

::: {.definition name="Monte Carlo estimator"}
Given i.i.d. samples $X_1, \ldots, X_N \sim f$ and a function $g$ with finite variance, the **Monte Carlo estimator** of $\mathbb E_f[g] = \int d\mathbf x\,f(\mathbf x)g(\mathbf x)$ is
$$M_N = \frac1N\sum_{i=1}^{N} g(X_i), \qquad \mathbb E[M_N] = \mathbb E_f[g], \qquad \operatorname{Var}[M_N] = \frac{\operatorname{Var}_f[g]}{N}.$$
By the law of large numbers $M_N \to \mathbb E_f[g]$ almost surely; by the CLT the error is $\approx \sigma_g/\sqrt N$.
:::

The rate $1/\sqrt N$ is **dimension-free**. The price is that we must be able to *sample* from $f$ — and that is the hard part.

## Simple ways to sample a distribution

All samplers are built from a single primitive: a generator of uniform random numbers $U \sim \mathcal U(0, 1)$.

### Inverse-CDF sampling

::: {.proposition name="Inverse-CDF sampling"}
Let $X$ have a continuous, invertible CDF $F_X$. If $U \sim \mathcal U(0,1)$, then $X = F_X^{-1}(U)$ has CDF $F_X$.
:::

::: {.proof}
Let $Z = F_X(X)$. Then $F_Z(z) = P(F_X(X) \leq z) = P(X \leq F_X^{-1}(z)) = F_X(F_X^{-1}(z)) = z$ on $[0, 1]$, so $Z \sim \mathcal U(0, 1)$. Reading the argument backwards, $F_X^{-1}(U)$ is distributed as $X$.
:::

::: {.example name="Exponential and Cauchy variables"}
*Exponential.* $f(x) = \lambda e^{-\lambda x}$, $F(x) = 1 - e^{-\lambda x}$, so $X = -\tfrac1\lambda\log(1 - U)$ (or $-\tfrac1\lambda\log U$, since $1 - U \sim U$).

*Cauchy.* $F(x) = \tfrac12 + \tfrac1\pi\arctan x$, so $X = \tan\bigl(\pi(U - \tfrac12)\bigr)$.

The Gaussian has no closed-form inverse CDF; the Box–Muller transform $X = \sqrt{-2\ln U_1}\cos(2\pi U_2)$ works instead, using a 2-D change of variables.
:::

### Rejection sampling

When $F^{-1}$ is unavailable, we can sample uniformly under the graph of the density.

::: {.definition name="Rejection sampling (uniform envelope)"}
Let $f_X$ be (essentially) supported on $I = [a, b]$, and let $M \geq \max_x f_X(x)$.

1. Draw $Z_1, Z_2 \sim \mathcal U(0,1)$ and set $Y = a + (b - a)Z_1$ (uniform on $I$).
2. **Accept** $Y$ if $Z_2 \leq f_X(Y)/M$; otherwise **reject** it and start again.
:::

Values are accepted with probability proportional to $f_X(y)$, so the accepted values are distributed as $X$.

::: {.proof}
$$P(Y \leq x, \text{accept}) = \frac{1}{b - a}\int_a^x dy\int_0^1 dz_2\,\chi\Bigl(z_2 \leq \frac{f_X(y)}{M}\Bigr) = \frac{1}{(b-a)M}\int_a^x f_X(y)\,dy = \frac{F_X(x)}{(b-a)M},$$
and $P(\text{accept}) = \frac{1}{(b-a)M}$. Dividing, $P(Y \leq x \mid \text{accept}) = F_X(x)$.
:::

More generally, with any proposal density $q$ such that $f \leq Mq$, draw $Y \sim q$ and accept with probability $f(Y)/(Mq(Y))$; the acceptance probability is $1/M$. The method also works if $f$ is known only up to normalisation (then $M$ just absorbs the constant).

::: {.example name="Rejection sampling fails in high dimension"}
Sample $X \sim \mathcal N(0, \sigma^2)$ on $[-\kappa\sigma, \kappa\sigma]$ with $M = \max f = (2\pi\sigma^2)^{-1/2}$:
$$P(\text{accept}) = \frac{1}{2\kappa\sigma\,M} = \frac{\sqrt{2\pi}}{2\kappa}.$$
For $\kappa = 4$ this is $0.31$. In $d$ dimensions with $\Sigma = \sigma^2 I$, the box has volume $(2\kappa\sigma)^d$ and $M = (2\pi\sigma^2)^{-d/2}$, so
$$P(\text{accept}) = \Bigl(\frac{\sqrt{2\pi}}{2\kappa}\Bigr)^d,$$
which for $\kappa = 4$ is $9 \times 10^{-6}$ at $d = 10$ and $8 \times 10^{-11}$ at $d = 20$. **The acceptance rate decays exponentially with dimension.** The same happens for the darts example: the fraction of the unit cube occupied by the inscribed ball is $\pi/4 \approx 0.79$ in $d = 2$, $0.52$ in $d = 3$, but $0.0025$ in $d = 10$.
:::

::: {.remark}
In high dimension, almost all the volume of a box (or of any simple envelope) lies where the target has negligible mass — the "concentration of measure". Independent proposals are doomed. The way out is to make *local* moves from a point already in the high-probability region: Markov chains.
:::

## Markov Chain Monte Carlo

The MCMC idea: **construct a Markov chain whose stationary distribution is the target $\pi$**, run it until it reaches equilibrium, and use its trajectory as a (correlated) sample. By Chapter 6, an ergodic chain satisfies $p_{X_n} \to \pi$ for $n \to \infty$, so after a transient (**burn-in**) the states $X_n, X_{n+1}, \ldots$ are distributed according to $\pi$. Relabelling the first post-burn-in state as $X_1$, the ergodic theorem gives
$$G_n = \frac1n\sum_{i=1}^n g(X_i) \xrightarrow[n\to\infty]{} \mathbb E_\pi[g].$$
To compute posterior expectations, we need a chain with stationary distribution $\pi(\boldsymbol\theta, \mathbf z) = f(\boldsymbol\theta, \mathbf z \mid \mathbf y)$. The question is how to build one for an arbitrary $\pi$.

## The Metropolis algorithm

### Discrete state space

Let $X_n \in \{1, \ldots, K\}$ and let $\pi$ be the target. Choose a **symmetric proposal** matrix $T$, with $T_{ij}$ the probability of proposing a jump $j \to i$:
$$T_{ij} = T_{ji}, \qquad T_{ii} = 0, \qquad \textstyle\sum_i T_{ij} = 1.$$
A proposed jump $j \to i$ is **accepted** with probability
$$A_{ij} = \min\Bigl\{1, \frac{\pi_i}{\pi_j}\Bigr\}:$$
uphill moves (towards more probable states) are always accepted, downhill moves with probability $\pi_i/\pi_j < 1$. If rejected, the chain stays at $j$. The total rejection probability from $j$ is $R_j = 1 - \sum_k A_{kj}T_{kj}$, and the transition matrix is
$$P_{ij} = T_{ij}A_{ij} + R_j\,\delta_{ij}.$$

::: {.theorem name="Metropolis satisfies detailed balance"}
$P_{ij}\,\pi_j = P_{ji}\,\pi_i$ for all $i, j$. Hence $\pi$ is a stationary distribution of the chain, and if the chain is ergodic it is the limiting distribution.
:::

::: {.proof}
For $i = j$ there is nothing to prove. For $i \neq j$,
$$P_{ij}\pi_j = T_{ij}\min\Bigl\{1, \frac{\pi_i}{\pi_j}\Bigr\}\pi_j = T_{ij}\min\{\pi_j, \pi_i\} = T_{ji}\min\Bigl\{\frac{\pi_j}{\pi_i}, 1\Bigr\}\pi_i = P_{ji}\pi_i,$$
using the symmetry of $T$ and of $\min$. Stationarity follows from Chapter 6.
:::

::: {.example name="Metropolis on three states"}
Target $\pi = (0.5, 0.3, 0.2)$, proposal $T_{ij} = 1/2$ for $i \neq j$. Off-diagonal entries $P_{ij} = \tfrac12\min(1, \pi_i/\pi_j)$:

| $P_{ij}$ | from 1 | from 2 | from 3 |
|:---:|:---:|:---:|:---:|
| to 1 | $R_1$ | $\tfrac12$ | $\tfrac12$ |
| to 2 | $\tfrac12\cdot\tfrac{3}{5} = 0.3$ | $R_2$ | $\tfrac12$ |
| to 3 | $\tfrac12\cdot\tfrac{2}{5} = 0.2$ | $\tfrac12\cdot\tfrac{2}{3} = \tfrac13$ | $R_3$ |

with $R_1 = 1 - 0.3 - 0.2 = 0.5$, $R_2 = 1 - \tfrac12 - \tfrac13 = \tfrac16$, $R_3 = 1 - \tfrac12 - \tfrac12 = 0$. Check stationarity row by row: $0.5\cdot0.5 + 0.5\cdot0.3 + 0.5\cdot0.2 = 0.5$ $\checkmark$; $0.3\cdot0.5 + \tfrac16\cdot0.3 + 0.5\cdot 0.2 = 0.15 + 0.05 + 0.1 = 0.3$ $\checkmark$; $0.2\cdot0.5 + \tfrac13\cdot 0.3 + 0 = 0.2$ $\checkmark$. Detailed balance, e.g. $P_{21}\pi_1 = 0.3 \cdot 0.5 = 0.15 = P_{12}\pi_2 = 0.5\cdot 0.3$ $\checkmark$.
:::

### Continuous state space

The same construction works in $\mathbb R^d$. With a symmetric proposal density $T(\mathbf x' \mid \mathbf x) = T(\mathbf x \mid \mathbf x')$ and acceptance
$$A(\mathbf x' \mid \mathbf x) = \min\Bigl\{1, \frac{\pi(\mathbf x')}{\pi(\mathbf x)}\Bigr\},$$
the rejection probability is $R(\mathbf x) = \int d\mathbf x'\,T(\mathbf x'\mid\mathbf x)\bigl(1 - A(\mathbf x'\mid\mathbf x)\bigr)$ and the transition kernel is
$$P(\mathbf x' \mid \mathbf x) = A(\mathbf x' \mid \mathbf x)\,T(\mathbf x' \mid \mathbf x) + \delta(\mathbf x' - \mathbf x)\,R(\mathbf x).$$
Detailed balance $P(\mathbf x'\mid\mathbf x)\pi(\mathbf x) = P(\mathbf x\mid\mathbf x')\pi(\mathbf x')$ follows exactly as in the discrete case.

::: {.definition name="Metropolis algorithm (continuous)"}
From the current state $\mathbf x$:

1. propose $\mathbf x' \sim T(\cdot \mid \mathbf x)$, e.g. $\mathbf x' = \mathbf x + \sigma\boldsymbol\xi$, $\boldsymbol\xi \sim \mathcal N(0, I)$;
2. draw $u \sim \mathcal U(0,1)$; if $u < \pi(\mathbf x')/\pi(\mathbf x)$, move to $\mathbf x'$; otherwise stay at $\mathbf x$ (and **record $\mathbf x$ again** as the next sample).
:::

::: {.proposition name="Metropolis does not need the evidence"}
If $\pi(\mathbf x) = f(\mathbf x \mid \mathbf y) = f(\mathbf x, \mathbf y)/f(\mathbf y)$, then
$$A(\mathbf x' \mid \mathbf x) = \min\Bigl\{1, \frac{f(\mathbf x', \mathbf y)}{f(\mathbf x, \mathbf y)}\Bigr\} = \min\Bigl\{1, \frac{f(\mathbf y \mid \mathbf x')f(\mathbf x')}{f(\mathbf y \mid \mathbf x)f(\mathbf x)}\Bigr\}:$$
only the **unnormalised posterior** (likelihood × prior) is needed. The intractable marginal likelihood $f(\mathbf y)$ cancels.
:::

This is why Metropolis revolutionised Bayesian statistics (and, earlier, statistical physics, where the unknown constant is the partition function $Z$).

### Metropolis–Hastings

With a non-symmetric proposal $q(\mathbf x' \mid \mathbf x)$, detailed balance is restored by the Hastings correction:
$$A(\mathbf x' \mid \mathbf x) = \min\Bigl\{1, \frac{\pi(\mathbf x')\,q(\mathbf x \mid \mathbf x')}{\pi(\mathbf x)\,q(\mathbf x' \mid \mathbf x)}\Bigr\}.$$
The ratio of proposal densities compensates for the bias of proposing some moves more often than their reverses. Gibbs sampling (Chapter 8) and HMC (Chapter 11) are both special cases.

::: {.example name="Metropolis for a coin's bias"}
We observe $k = 7$ heads in $n = 10$ tosses of a coin with unknown bias $\theta$, and use a uniform prior. The unnormalised posterior is $\pi(\theta) \propto \theta^7(1-\theta)^3$ on $[0,1]$ (the exact answer is $\text{Beta}(8, 4)$, with mean $8/12 = 0.667$). Metropolis with $\theta' = \theta + 0.1\,\xi$: accept with probability $\min\{1, \pi(\theta')/\pi(\theta)\}$, with $\pi(\theta') = 0$ (always reject) if $\theta' \notin [0,1]$. Note that rejected proposals outside the support must still be counted as a repeated sample of $\theta$. A run of $10^5$ steps reproduces the Beta mean and variance ($8\cdot4/(12^2\cdot 13) \approx 0.0171$) to about two decimal places.
:::

::: {.example name="Metropolis for a 1-D Gaussian"}
Target $\pi(x) \propto e^{-x^2/2}$, proposal $x' = x + \sigma_p\xi$, acceptance $\min\{1, e^{(x^2 - x'^2)/2}\}$. Tiny $\sigma_p$: almost every move is accepted but the chain crawls (random walk with tiny steps). Huge $\sigma_p$: proposals land in the tails and are almost all rejected; the chain sits still. The optimum is $\sigma_p \approx 2.4$, with acceptance rate $\approx 44\%$.
:::

## Convergence and correlation

The Metropolis chain is guaranteed to converge to $\pi$. Two practical issues remain:

- **Convergence time:** how long is the transient before equilibrium?
- **Autocorrelation:** the samples are identically distributed but *not independent*, so they carry less information than an i.i.d. sample of the same size.

Both are controlled by the **spectrum** of the transition matrix. We work with a finite state space; the continuous case is analogous, though the operator theory is more delicate.

### Spectrum of a reversible chain

$\boldsymbol\pi$ is an eigenvector of $P$ with eigenvalue 1, but $P$ is not symmetric, so its spectrum is not obviously real. Detailed balance fixes this. Let $\Lambda = \operatorname{diag}(\sqrt{\pi_1}, \ldots, \sqrt{\pi_K})$ and
$$V = \Lambda^{-1}P\Lambda, \qquad V_{ij} = P_{ij}\sqrt{\pi_j/\pi_i}.$$
By detailed balance, $V_{ij} = P_{ij}\pi_j/\sqrt{\pi_i\pi_j} = P_{ji}\pi_i/\sqrt{\pi_i\pi_j} = V_{ji}$: **$V$ is symmetric**. Hence $V = WDW^\top$ with $D = \operatorname{diag}(\lambda_1, \ldots, \lambda_K)$ real and $W$ orthogonal (columns $\mathbf w_k$). Since $P = \Lambda V\Lambda^{-1}$ is similar to $V$, it has the same real eigenvalues, with

- right eigenvectors $\boldsymbol\phi_k = \Lambda\mathbf w_k$: $P\boldsymbol\phi_k = \Lambda V\mathbf w_k = \lambda_k\boldsymbol\phi_k$;
- left eigenvectors $\boldsymbol\psi_k = \Lambda^{-1}\mathbf w_k$: $\boldsymbol\psi_k^\top P = \mathbf w_k^\top V\Lambda^{-1} = \lambda_k\boldsymbol\psi_k^\top$;
- biorthonormality $\boldsymbol\psi_k^\top\boldsymbol\phi_l = \mathbf w_k^\top\mathbf w_l = \delta_{kl}$.

The powers of $P$ have the spectral decomposition
$$P^n = \Lambda V^n\Lambda^{-1} = \sum_k \lambda_k^n\,\boldsymbol\phi_k\boldsymbol\psi_k^\top .$$

::: {.proposition}
All eigenvalues satisfy $|\lambda_k| \leq 1$. The eigenvalue $1$ has left eigenvector $\mathbf 1 = (1, \ldots, 1)$ and right eigenvector $\boldsymbol\pi$; for an ergodic chain it is simple and all others satisfy $|\lambda_k| < 1$.
:::

::: {.proof}
From $P^n\boldsymbol\phi_k = \lambda_k^n\boldsymbol\phi_k$, for each component $j$: $|\lambda_k|^n|(\boldsymbol\phi_k)_j| \leq \sum_l (P^n)_{jl}|(\boldsymbol\phi_k)_l| \leq \gamma\sum_l (P^n)_{jl}$, with $\gamma = \max_l|(\boldsymbol\phi_k)_l|$. Choosing $j$ where $|(\boldsymbol\phi_k)_j| = \gamma$ gives $|\lambda_k|^n \leq \sum_l (P^n)_{jl} \leq K$ (entries of $P^n$ are probabilities). A bound uniform in $n$ forces $|\lambda_k| \leq 1$. The left eigenvector $\mathbf 1$ expresses $\sum_i P_{ij} = 1$; simplicity for ergodic chains is Perron–Frobenius.
:::

Order the eigenvalues as $1 = \lambda_1 > |\lambda_2| \geq |\lambda_3| \geq \cdots$.

### Convergence time

Start the chain from $\mathbf p^{(0)}$. Since $\boldsymbol\phi_1 = \boldsymbol\pi$ and $\boldsymbol\psi_1 = \mathbf 1$ (so $\boldsymbol\psi_1^\top\mathbf p^{(0)} = 1$),
$$\mathbf p^{(n)} = P^n\mathbf p^{(0)} = \boldsymbol\pi + \sum_{k \geq 2}\lambda_k^n\,\boldsymbol\phi_k\,(\boldsymbol\psi_k^\top\mathbf p^{(0)}) = \boldsymbol\pi + O(e^{-n/\tau_{\text{conv}}}),$$
with
$$\tau_{\text{conv}} = -\frac{1}{\log|\lambda_2|} = -\frac{1}{\log(1 - \delta\lambda)} \simeq \frac{1}{\delta\lambda}, \qquad \delta\lambda = 1 - |\lambda_2| .$$
**The convergence time is the inverse spectral gap**: the smaller the gap, the longer the burn-in.

::: {.example}
In the three-state Metropolis example, $\operatorname{tr}P = 2/3$ and $\det P = 0$, so the eigenvalues are $1$, $0$ and $-1/3$: $|\lambda_2| = 1/3$ and the chain equilibrates within a few steps (each step shrinks the deviation from $\boldsymbol\pi$ by a factor 3). For the two-state chain of Chapter 6, $\lambda_2 = 1 - a - b$: with $a = b = 0.01$, $\tau_{\text{conv}} \approx 50$ steps.
:::

### The step size of random-walk Metropolis

For a continuous Metropolis chain the transition operator splits as $V = K + M$, with
$$(Kf)(\mathbf x) = \int d\mathbf x'\,T(\mathbf x'\mid\mathbf x)A(\mathbf x'\mid\mathbf x)f(\mathbf x'), \qquad (Mf)(\mathbf x) = R(\mathbf x)f(\mathbf x).$$
The spectrum of $M$ is the range of the rejection probability, $[0, \max R]$, a continuum; $K$ contributes isolated eigenvalues. Which part sets the gap depends on the proposal width $\sigma$:

- **Small steps.** $T(\mathbf x'\mid\mathbf x) \to \delta(\mathbf x' - \mathbf x)$ as $\sigma \to 0$, so $Kf = f + O(\sigma^2)$: the top eigenvalues of $K$ are $1 - O(\sigma^2)$ and the gap closes as $\sigma^2$. The chain is a slow random walk: covering a distance $L$ takes $\sim (L/\sigma)^2$ steps.
- **Large steps.** Most proposals land in low-probability regions; $R(\mathbf x) \to 1$, the top of the spectrum of $M$ approaches 1, and the chain gets stuck.

In $D$ dimensions, Taylor-expanding $A(\mathbf x'\mid\mathbf x)$ around $\mathbf x' = \mathbf x$ inside $R(\mathbf x) = 1 - \int d^D\mathbf x'\,A(\mathbf x'\mid\mathbf x)\,\mathcal N(\mathbf x'; \mathbf x, \sigma^2 I)$ gives
$$R(\mathbf x) = O(D\sigma^2):$$
each of the $D$ directions contributes a term of order $\sigma^2$. To keep the rejection rate bounded away from 1 we need $\sigma^2 \lesssim 1/D$. **The optimal step size shrinks as $\sigma \propto D^{-1/2}$**, and the number of steps needed to traverse the distribution grows as $\sim D$.

::: {.proposition name="Optimal scaling (Roberts, Gelman and Gilks 1997)"}
For random-walk Metropolis on a $D$-dimensional target with i.i.d. components, as $D \to \infty$ the optimal proposal is $\sigma = 2.38/\sqrt D$ (in units of the target's standard deviation), and the corresponding acceptance rate is $\alpha^* \approx 0.234$.
:::

The rule of thumb "aim for 20–40% acceptance" (about 44% in one dimension) comes from this result and works surprisingly well in practice.

### Autocorrelation and effective sample size

After burn-in, $X_n, X_{n+1}, \ldots$ are distributed according to $\pi$ but are **autocorrelated**. For any (not necessarily independent) identically distributed sample,
$$\operatorname{Var}\Bigl[\frac1n\sum_i g(X_i)\Bigr] = \frac1{n^2}\Bigl[\sum_i\operatorname{Var}[g(X_i)] + \sum_i\sum_{j\neq i}\operatorname{Cov}[g(X_i), g(X_j)]\Bigr].$$

- **Independent samples:** covariances vanish and the variance is $\operatorname{Var}[g]/n$, the familiar $1/\sqrt n$ error.
- **Perfectly correlated samples:** all covariances equal $\operatorname{Var}[g]$ and the variance is $\operatorname{Var}[g]$ — **no improvement with $n$ at all**: it is as if we had a single sample.

A stationary chain lies in between. Its covariance depends only on the lag, $\operatorname{Cov}[g(X_i), g(X_j)] = c_{|i-j|}$, and typically decays to zero beyond some lag $\tau$, so the covariance matrix is banded around the diagonal.

::: {.definition name="Integrated autocorrelation time"}
$$A_g = \frac{1}{\operatorname{Var}[g]}\sum_{j=-\infty}^{\infty}\operatorname{Cov}[g(X_i), g(X_{i+j})] = 1 + 2\sum_{j=1}^\infty\frac{c_j}{c_0}.$$
:::

Summing the banded covariance matrix row by row, rows away from the boundaries contribute $c_0A_g$ each; boundary rows contribute $O(\tau)$ in total. Hence
$$\operatorname{Var}\Bigl[\frac1n\sum_i g(X_i)\Bigr] = \frac{\operatorname{Var}[g]\,A_g}{n} + O\Bigl(\frac{1}{n^2}\Bigr) = \frac{\operatorname{Var}[g]}{n_g^{\text{eff}}} + O\Bigl(\frac1{n^2}\Bigr), \qquad n^{\text{eff}}_g = \frac{n}{A_g}.$$
**A correlated chain of length $n$ is worth $n/A_g$ independent samples** — the effective sample size.

::: {.example name="AR(1) process"}
Let $X_{t+1} = \rho X_t + \sqrt{1 - \rho^2}\,\xi_t$ with $\xi_t \sim \mathcal N(0,1)$ — a Markov chain with stationary $\mathcal N(0, 1)$ and $c_j = \rho^{|j|}$. Then
$$A = 1 + 2\sum_{j\geq1}\rho^j = \frac{1 + \rho}{1 - \rho}.$$
For $\rho = 0.9$, $A = 19$: $10^4$ steps are worth only about 530 independent draws. For $\rho = 0.99$, $A = 199$.
:::

### Autocorrelation from the spectrum

Standardise $h = (g - \mu_g)/\sigma_g$, so $\mathbb E_\pi[h] = 0$, $\operatorname{Var}[h] = 1$. At equilibrium, $P(X_n = i, X_0 = j) = (P^n)_{ij}\pi_j$, so
$$\operatorname{Cov}[h(X_n), h(X_0)] = \sum_{ij}h_ih_j\pi_j(P^n)_{ij} = \sum_{k}\lambda_k^n\sum_{ij}h_ih_j\pi_j(\boldsymbol\phi_k)_i(\boldsymbol\psi_k)_j .$$
The $k = 1$ term is $\sum_{ij}h_ih_j\pi_i\pi_j = (\mathbb E_\pi h)^2 = 0$. Summing the geometric series $\sum_{n \geq 1}\lambda_k^n = \lambda_k/(1 - \lambda_k)$,
$$A_g = 1 + 2\sum_{n\geq1}\operatorname{Cov}[h(X_n), h(X_0)] = \sum_{k \geq 2}\frac{1 + \lambda_k}{1 - \lambda_k}\sum_{ij}h_ih_j\pi_j(\boldsymbol\phi_k)_i(\boldsymbol\psi_k)_j ,$$
where we used $1 = \operatorname{Var}[h] = \sum_{k\geq2}\sum_{ij}h_ih_j\pi_j(\boldsymbol\phi_k)_i(\boldsymbol\psi_k)_j$. In terms of the orthonormal eigenvectors of $V$, the weights are $a_k^2 = \bigl(\sum_i\sqrt{\pi_i}\,h_i(\mathbf w_k)_i\bigr)^2 \geq 0$ with $\sum_{k\geq2}a_k^2 = 1$, so
$$A_g = \sum_{k\geq 2}a_k^2\,\frac{1 + \lambda_k}{1 - \lambda_k}.$$
**The autocorrelation time is a weighted average of $(1 + \lambda_k)/(1 - \lambda_k)$**: eigenvalues close to 1 (small gaps) inflate it, and the observable "feels" a slow mode only to the extent that it overlaps with it. The AR(1) result $A = (1 + \rho)/(1 - \rho)$ is the single-mode case. (Negative eigenvalues give $A_g < 1$: antithetic, "better than independent" samples are possible.)

## Practical MCMC

- **Burn-in.** Discard the transient (several $\tau_{\text{conv}}$); check that discarding more does not change the estimate.
- **Trace plots** of $g(X_t)$ vs $t$ should look like stationary noise around a constant mean.
- **Effective sample size**: estimate $A_g$ from the empirical autocorrelation (truncating the sum when it becomes noisy) and report $n/A_g$, not $n$.
- **Gelman–Rubin $\hat R$**: run several chains from over-dispersed starting points and compare within-chain and between-chain variances; $\hat R \approx 1$ (in practice $< 1.01$) indicates convergence.
- **Thinning** (keeping one sample every $k$) reduces storage but never increases the information in the chain.

## Exercises

::: {.exercise}
Prove that with a symmetric proposal the Metropolis–Hastings acceptance reduces to $\min\{1, \pi(y)/\pi(x)\}$, and verify detailed balance for $x \neq y$.
:::

::: {.solution}
With $q(y\mid x) = q(x\mid y)$ the $q$'s cancel in the Hastings ratio. Then $\pi(x)q(y\mid x)\min\{1, \pi(y)/\pi(x)\} = q(y\mid x)\min\{\pi(x), \pi(y)\}$, which is symmetric in $x \leftrightarrow y$ because $q$ is symmetric: this is $\pi(y)P(x \mid y)$.
:::

::: {.exercise}
Using the inverse-CDF method, give an algorithm to sample from $f(x) = 2x$ on $[0, 1]$. Then design a rejection sampler for the same density using the uniform envelope and compute its acceptance rate.
:::

::: {.solution}
$F(x) = x^2$, so $X = \sqrt U$. For rejection: $M = \max f = 2$, $b - a = 1$, so $P(\text{accept}) = 1/((b-a)M) = 1/2$: draw $Y \sim \mathcal U(0,1)$, accept if $U_2 \leq Y$.
:::

::: {.exercise}
A Metropolis chain has $A_g = 25$ for the observable $g$. How long must the chain be (after burn-in) to estimate $\mathbb E[g]$ to within $0.01\sigma_g$ (one standard error)?
:::

::: {.solution}
Standard error $= \sigma_g\sqrt{A_g/n} = 0.01\sigma_g \Rightarrow n = A_g/10^{-4} = 2.5 \times 10^5$ steps, versus $10^4$ for i.i.d. sampling.
:::

::: {.exercise}
For the two-state chain with $P(0\to1) = a$, $P(1\to0) = b$ and the observable $g(x) = x$, compute $A_g$.
:::

::: {.solution}
Only one non-trivial eigenvalue, $\lambda_2 = 1 - a - b$, and the centred $g$ lies entirely along its eigenvector, so $A_g = (1 + \lambda_2)/(1 - \lambda_2) = (2 - a - b)/(a + b)$. For $a = b = 0.5$ ($\lambda_2 = 0$, i.i.d.) $A_g = 1$; for $a = b = 0.01$, $A_g = 99$; for $a = b = 0.9$ ($\lambda_2 = -0.8$, alternating) $A_g = 1/9$.
:::

## Callouts

::: {.callout-note}
Metropolis is not the fastest MCMC algorithm; it is the most general. It needs only pointwise evaluations of the unnormalised target. Specialised samplers (Gibbs, HMC) exploit more structure and do much better.
:::

::: {.callout-warning}
The MCMC estimator is biased by the initial transient. Always discard a burn-in. And the error bar is $\sigma_g\sqrt{A_g/n}$, not $\sigma_g/\sqrt n$: forgetting $A_g$ gives wildly overconfident results.
:::

::: {.callout-caution}
A chain that "looks converged" may still be missing modes of a multimodal target: trace plots detect within-mode stationarity, not between-mode mixing. The spectral gap of a chain with well-separated modes is exponentially small in the barrier height.
:::

::: {.callout-important}
Effective sample size per unit of computation is the right figure of merit for comparing samplers.
:::
